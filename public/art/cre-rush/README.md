# Cre Rush front sprite

`front-source.png` is an original generated transparent frontal crested-gecko jumping illustration made for this feature. It is not an external copyrighted image, a concept-art crop, or an enlargement of the existing side-view gecko. The generated working original remains in the cloud workspace; this checked-in copy is the runtime source.

SHA-256: `95e278e7a30ef047dc1e3b80677bea5f3b772080626479a69650abe0e8e9d1db`.

`src/components/hardcore/rush-sprite.tsx` samples it onto a 96×96 canvas with smoothing off, quantizes alpha to transparent/opaque, caches four warm skin color grades, and preserves the approximate iris regions and original shading. CSS scales each square sprite uniformly with pixelated rendering. This is a generated high-resolution source sampled to 96px, not professionally authored native 96px frame-by-frame art. The original is a single frontal pose. V2 caches three subtle procedural toe/tail poses, leaving the central face and eyes unchanged. These are not new artist-authored animation frames; the source PNG and its hash stay unchanged. Motion and capture effects are procedural.

Cafe geckos are anonymous minigame characters. Their colors do not claim a genetic morph, create collection individuals, or alter the game's genotype/phenotype adapter. All existing `gecko-v2` PNGs and masks remain unchanged.
