# 인큐베이터 환경 에셋

`scene.png`는 2026-10-14에 첨부 인큐베이터 레퍼런스를 기준으로 별도 생성한 환경 원화입니다. 열대식물·금속/유리 인큐베이터·주황색 조명·빈 흙 바닥·숫자 없는 검은 표시판만 포함합니다. 화면 전체 캡처나 정보·버튼·알을 포함하지 않습니다. 원본 생성 PNG를 수정 없이 복사했으며 자동 준비 스크립트로 덮어쓰지 않습니다.

인큐베이터 대표 장면은 이 환경 원화를 사용하고 카드 배경은 CSS로 유리 내부 영역을 표시합니다. 알·숫자·진행 바·부모 정보·버튼은 독립 UI입니다. 알은 `src/components/hardcore/incubator-egg.tsx`에서 고정 시드·48×56·스무딩 없는 Canvas로 그립니다. 알 장식은 유전형이나 수정 여부를 표현하지 않습니다.

실제 원본과의 차이 및 브라우저 비교는 `docs/incubator-reference.md`를 참고하세요.
