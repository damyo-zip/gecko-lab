# gecko-lab

## 폴더 구조

```text
gecko-lab/
├── references/
│   ├── gecko-morph-concept.png
│   └── gecko-mobile-ui.png
├── src/
├── public/
├── AGENTS.md
└── README.md
```

- `references/`: 게코 모프 콘셉트와 모바일 UI 참고 이미지 원본.
- `src/`: 애플리케이션 소스 코드.
- `public/`: 정적 파일.
- `AGENTS.md`: 저장소 작업 안내.

`src/`와 `public/`에는 빈 폴더를 Git에 유지하기 위한 `.gitkeep`이 있습니다.
