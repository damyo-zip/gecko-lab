# GECKO LAB v1.2

모바일 세로 화면용 로컬 크레스티드 게코 브리딩 게임입니다. **플레이어가 턴을 마쳐야 진행되며, 1턴은 게임 시간 7일입니다.** 기존 멘델 유전·혈통·턴 규칙·PNG 원화를 보존하고, 새 개체는 상속된 60개 가상 좌위로 실제 무늬와 한국어 명칭을 계산합니다. 이전 개체의 외형과 가격 모델은 그대로 유지합니다.

## 실행

Node.js 24 LTS와 npm을 사용합니다.

```bash
npm ci
npm run dev
```

프로덕션은 `npm run build` 후 `npm run start`로 실행합니다.

- `/`: 컬렉션 홈. 하단 컬렉션·인큐베이터·혈통도·상점 탭과 큰 **턴 넘기기** 버튼.
- 성체 상세의 **부모로 선택**, 또는 인큐베이터의 교배 탭에서 브리딩 화면을 엽니다.
- `/lab`: 96×96·8레이어·6모프·고정 시드 스프라이트 연구실. v1/v2 비교와 PNG 출력.
- `/lab/patterns`: 유전형 기반 14개 실제 무늬·한국어 자동 명칭 비교. [구현·판정·근거·한계](docs/inherited-patterns.md).
- `/lab/breeding`: 별도 `phase2-lab` 슬롯의 이전 브리딩 회귀 시뮬레이터. 정식 `active` 게임과 분리됩니다.
- 개발 포트 3000, E2E 프로덕션 포트 3100. PWA 셸과 IndexedDB는 브라우저 로컬 저장입니다.

## 확정 턴·성장·급여 규칙

| 항목 | v1.2 동작 |
| --- | --- |
| 시간 | 버튼 1회 = 1턴 = 7일. 현실 시간·새로고침·재접속은 진행하지 않음 |
| 성장 | 부화 시 0턴, 6턴 아성체, **정확히 12턴 성체**. 성장 난수 없음 |
| 급여 | 턴 시작 시 보유 생존 개체 모두에게 사료 1개. 성장·번식 상태·하트와 무관 |
| 알 | 사료를 소비하지 않음. 해당 턴에 부화한 새끼는 다음 턴부터 소비 |
| 충분한 사료 | 자동 급여. 하트 최대 5까지 1 회복 |
| 사료 부족 | 턴 종료 전 경고·취소/사료 관리/진행 확인. 하트가 적은 개체부터 ID 순으로 급여 |
| 미급여 | 기존 컨디션 하트 −1, 0이면 영구 폐사. 판매 개체는 플레이어 사료 소비에서 제외 |

상단 먹이 +의 관리 창에서 사료를 확보하고 홈에서 턴을 넘깁니다. 수동 추가 급여는 v1.2에서 사용하지 않습니다. 6턴의 아성체 구분, 하트 회복·부분 급여 순서는 게임용 보조 규칙이며 실제 사육 지침이 아닙니다.

## 교배·산란·부화

- **12~59턴 성체**가 신규 교배할 수 있습니다. 유전 건강 위험과 가까운 근친 교배는 기존 검사로 차단합니다.
- 교배 성공 시 부모 스냅샷과 시즌의 자손 유전형·다유전자 값·성별·고유 외형 시드를 결정적으로 저장합니다. 부모의 외형 시드를 복사하지 않습니다.
- 교배 **+2턴에 정확히 2알을 한 번만 산란**합니다. 추가 산란은 없습니다.
- 교배 시작 시 인큐베이터 빈 슬롯 **2칸**을 예약합니다. 빈 슬롯 0·1칸에서는 실행을 차단하고 부족한 수를 표시합니다. 산란 즉시 예약 2칸을 실제 알 2개의 예약으로 전환하여 자동 배치하고 해당 산란 일정을 종료합니다. 다른 교배나 구매는 예약 공간을 사용할 수 없습니다.
- 산란 후 4턴 휴식: 교배 **+6턴부터** 다시 교배할 수 있습니다.
- 모든 알은 산란 후 **정확히 4턴**에 판정합니다. 무정란은 알마다 독립적으로 5%, 수정란의 부화 성공률은 95%입니다. 전체 알 기준 부화 확률은 90.25%입니다.
- 부화 시 기존에 확정한 유전형을 그대로 상속합니다. 무정란·실패 알은 개체나 보상으로 등록하지 않고 유전 관찰 증거에서 제외합니다.
- 60턴에 은퇴해도 이미 시작한 산란 시즌은 생존하는 동안 완료합니다. 산란 전 암컷 사망 시 남은 산란만 취소하고 기존 알은 계속 판정합니다.
- 첫 산란의 자손은 교배 +6턴 부화, +18턴 성체입니다. 부화한 자손의 이름·급여·성장·다음 세대 교배·영구 혈통 조회가 가능합니다.

## 노령·은퇴·수명

나이는 `현재 턴 − 부화 턴`입니다. 50턴부터 노령, 60턴부터 신규 번식 은퇴입니다.

| 도달 나이 | 해당 턴 자연사 확률 |
| --- | --- |
| 0~64턴 | 0% |
| 65~69턴 | 1% |
| 70~74턴 | 3% |
| 75~79턴 | 8% |
| 80~84턴 | 18% |
| 85~89턴 | 40% |
| 90턴 이상 | 100% |

성체 그래픽은 노령에도 그대로 사용합니다. 무작위 질병·돌연사는 없습니다. 자연사는 개체 ID·게임 시드·해당 나이로 재현하며, 처리 턴을 저장해 급여·자연사 중복 처리를 막습니다. 사망 개체는 보유 공간에서 제외하고 혈통·부모·자손·유전형·표현형·번식 기록을 유지합니다. 자연사 확률과 수명은 게임 규칙입니다.

## 저장 v8·이전 데이터

IndexedDB `active` 슬롯을 자동 저장하고 JSON 백업·복원과 원본 아카이브를 지원합니다. **저장 완료 전 진행을 화면에 반영하지 않으며** 저장 충돌 시 덮어쓰기를 차단합니다.

v2·v3·v4·v5·v6·v7의 구조·체크섬·유전 기록을 먼저 검증한 뒤 v8/규칙 버전 4로 이전합니다. 실제 `active` 이전은 같은 IndexedDB 트랜잭션에서 원본 `archive-vN-…`과 새 저장을 함께 기록합니다.

- 유전체·공개 지식·잠재 외형·ID·외형 시드·부모·세대·판매 가격 기록을 재생성하지 않습니다. 미확인 가상 대립유전자도 임의로 복원하지 않습니다.
- 기존 게임 턴·현재 날짜를 유지하고 수동 턴으로 일시 정지합니다. 이전 자체로 과거 급여·사망·산란을 재실행하지 않습니다.
- 이미 성체인 개체는 성체를 유지하도록 부화 턴을 최소 12턴 나이로 맞춥니다. 미성숙 개체는 기존 턴 나이와 고정 6/12턴 단계로 재분류합니다. 기존 출생 날짜와 완료 이력은 보존합니다.
- 산란 전 교배는 첫 산란의 확정 자손 2마리와 예정일을 유지하고 예약을 2칸으로 줄입니다. 이미 한 번 이상 산란한 교배는 완료로 전환하고 아직 산란하지 않은 추가 일정·예약만 해제합니다. 이미 산란한 알·부화한 자손·부모 유전 관찰 기록은 보존하며, 암컷 휴식은 마지막 실제 산란 +4턴입니다. 이전은 한 번만 적용되고 원본 v6도 `archive-v6-…`에 남깁니다.
- v2~v5의 대기 알 유전 결과는 보존합니다. 이전까지의 경과를 0~3턴으로 적용하고, 산란~판정 간격을 4턴/28일로 정규화합니다. 이미 수정된 알을 무정란으로 다시 추첨하지 않습니다. 판정 시 새 95% 부화 규칙을 사용합니다.
- 이전 현실 시간 어댑터·일일 규칙·v5 검증 경로는 호환 및 회귀 검사 코드로 보존합니다. v1.2 UI에서는 한국 자정 옵션을 비활성화합니다.

## 구조·유전학과 아트 한계

- `src/game/hardcore/lifecycle.ts`: 고정 규칙·나이·자동 급여·노령 확률.
- `season.ts`, `offspring.ts`: 수정 시 자손 확정·산란 시즌·알 판정·공통 유전 어댑터.
- `calendar.ts`, `time-source.ts`: 7일 턴 처리와 보존된 이전 시간 어댑터.
- `migrate-lifecycle.ts`, `migrate-single-clutch.ts`, `migrate-album.ts`, `save.ts`, `validation.ts`, `src/storage/hardcore.ts`: v8 이전·무결성·원자적 저장.
- `src/genetics/advanced`: 기존 멘델·보인자 추론·게임용 60개 가상 좌위. 렌더러·유전 계산·가격 공식은 변경하지 않습니다.

Lilly White·동일 라인 Axanthic과 잠정 복합 좌위의 근거/한계, 공개 지식 기반 가격·예측, 별도 가족의 주변확률 근사도 기존과 같습니다. 가상 외형 좌위·성별 50:50·급여·일정·수명은 실제 생물학의 확정 확률이 아닌 게임 모델입니다.

아트는 기존 실제 PNG·마스크·팔레트 v2의 결정적 96×96 출력입니다. 레퍼런스 원화와 같은 품질이나 포즈라고 주장하지 않습니다. [아트·눈 주변 팔레트 기록](docs/phase6.md), [홈 레퍼런스 비교](docs/reference-home.md), [이전 UI 테마 비교](docs/ui-tone.md)는 보존하며 해당 이미지는 당시 버전 캡처입니다.

## 검증

```bash
node scripts/compile-gecko-art.mjs --check
npm run typecheck
npm test
npm run build
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
```

기존 회귀 테스트는 삭제하거나 건너뛰지 않습니다. 이전 v5 규칙의 단위 검증은 명시적인 legacy fixture를 사용하며, 실제 앱의 E2E는 새 규칙에 맞춰 자동 급여·7일 턴·4턴 부화·12턴 성체를 검증합니다. v1.2 테스트에는 빈 슬롯 0·1·2개 경계·동시 교배 예약·단일 산란과 실제 구버전 진행 중 저장 이전, 12·50·60·65·90턴 경계, 독립 알 확률, 재현성·중복 방지·5세대·저장 이전/복원을 포함합니다.

최종 실행 결과와 실제 모바일 캡처는 [v1.2 검증 기록](docs/v1.2-lifecycle.md)에 기록합니다. 모바일 검증은 Chromium 터치 에뮬레이션(360×800)이며 실물 iOS/Safari 검사는 포함하지 않습니다.

## 인큐베이터 화면

인큐베이터는 [첨부 레퍼런스에 맞춘 실제 슬롯 UI](docs/incubator-reference.md)를 사용합니다. 대표 장면·3열 슬롯·남은 일수/턴·녹색 턴 버튼·4개 탭을 실제 저장 데이터와 연결합니다. 빈 슬롯의 +는 부모 선택이며 구매 기능이 아닙니다. 산란 전 예약과 부화 결과·번식 기록을 구분하고, 기존 2알/2슬롯·4턴 부화 규칙을 유지합니다.

## 상점 화면

[실제 가족 매물 상점](docs/shop-reference.md)은 레퍼런스의 2×2 카드·부모 팝업·녹색 구매/턴 버튼을 실제 데이터에 연결합니다. 고정 시드로 기존 유전 엔진에서 부모→자손을 생성하고 기존 가격표로 평가합니다. 확인 후 ₩2,000 발품팔기, 구매 금액 차감·컬렉션 등록·구매 완료 표시, 기존 턴 기반 재고 갱신과 저장 복원을 지원합니다. 외부 부모는 혈통 기록으로 보존하지만 급여·사육 공간을 소비하지 않습니다.

저장 v7은 부모 원본·매물 배치 번호·구매 상태를 추가합니다. 기존 보유 개체·유전·알·산란·거래 기록은 유지하며 이전 원본은 아카이브에 보존합니다. 부모 기록이 없는 기존 매물은 기록 없음으로 표시하고, 이전 미구매 재고는 최대 4개 유지 후 부족분을 생성합니다. 과거 v5/v6 회귀 테스트는 명시적인 해당 버전 fixture를 유지하고, 현재 상점/저장/다세대 동작은 v7 단위 및 실제 브라우저 테스트로 검증합니다.

최신 전체 검증: 타입 검사·빌드·아트 해시 통과, 단위 **210개**, 모바일/데스크톱 E2E **120개** 통과. 360·390·430px 실제 Chromium 터치 화면, 구매/발품팔기/부모/턴/재저장·다세대 교배, 14패턴의 픽셀/명칭 일치, 관심 혈통 관리·7노드 가족도·판매/폐사 비교·v8 이전·오프라인 앨범을 확인했습니다. [상점 기록](docs/shop-reference.md), [신규 무늬·선택교배·캡처·주요 파일·한계](docs/inherited-patterns.md)에 상세 결과를 기록합니다. 혈통도의 캡처와 호환성은 [혈통 앨범 기록](docs/lineage-reference.md)에 있습니다.

상점은 배너·매물 설명을 제거한 간결한 화면으로 표시합니다. 360×800·390×844·430×844에서는 상점 탭을 누르면 매물 4개와 턴 넘기기 버튼을 스크롤 없이 함께 볼 수 있습니다. 부모/구매 버튼의 44px 터치 영역과 실제 데이터·기능은 유지합니다.

## 혈통 앨범

[혈통도 구현·비교 이미지·저장·한계](docs/lineage-reference.md): 관심 혈통을 실제 시조 ID로 등록·이름 변경·해제하고, 선택 개체의 부모/조부모 7노드와 실제 후손을 탐색합니다. 시조와 후손의 같은 크기 스프라이트를 비교하며 양쪽 개체를 검색해 바꿀 수 있습니다. 판매·폐사·상점 외부 부모도 같은 기록으로 보존합니다. 컬렉션 상세에서 해당 혈통도를 바로 열고 상단 버튼으로 공통 턴을 진행합니다. 통계/유전 연구 영역은 두 개체의 외형 비교로 교체했습니다.

저장 v8은 기존 혈통 이름에 `founderId`·`favorite`만 추가합니다. 이전 v7 개체·유전·알·교배·상점·가격 기록은 그대로이며, 실제 시조가 불명확한 예전 이름은 미확인으로 보존합니다. 관심 등록 해제는 기록을 삭제하지 않습니다. 360~430px에서는 페이지 세로 스크롤과 가족도 내부 가로 스크롤로 카드와 44px 터치 영역을 유지합니다.
