# 코드·아트 출처와 추출 기준

원본: https://github.com/damyo-zip/gecko-lab

- 게임 기준 커밋: **c934363f854b47c154d8d8127d6d23abbe692e9e**.
- 최초 Forge 기준 커밋: **bfd9504cb5a086318b894513e41aa34b70c08e81**.
- 최초 B 원본 커밋: **c9cb231db4afacaffc52b6e9655d57bc9f5a6f26**.
- 기준 외형: **patterns-1 / 2.1.0**, regional 프로토타입과 혼합하지 않음.

`source-manifest.json`은 현재 프로젝트 내부 경로, 원본 저장소 경로, 기준 커밋, 원본 바이트 SHA-256을 기록한다. 해당 원본은 `https://github.com/damyo-zip/gecko-lab/blob/<commit>/<sourcePath>`에서 추적할 수 있다. 이것은 출처 정보이며 실행·설치·테스트는 이 URL이나 원본 체크아웃을 사용하지 않는다.

멘델·60좌위·표현형·렌더링의 전이 의존성 **25개 TypeScript 파일**을 내부 `src/core/`로 옮겼다. 파일 본문과 유전/렌더 알고리즘은 바꾸지 않았다. 원본의 `@/` import는 프로젝트 로컬 `src/core/` 별칭으로 해석한다. 독립 저장소용 스냅샷이므로 실행 시 원본과 동기화하거나 원본 파일을 읽는 기능은 없다.

렌더러의 `art-data.ts`와 실제 원화 PNG·12개 런타임 채널을 모두 포함했다. 생성 당시 작업 원화 `source-art.png`도 보존했다. 이 큰 작업 원화는 96×96 네이티브 원화가 아니며, 기존 준비 과정을 거친 런타임 출력이 96×96이다. 최초 B는 96×96 원본 파일 그대로다. 이번 작업에서 새로운 그림을 만들지 않았다.

컴파일 스크립트는 원본 `scripts/compile-gecko-art.mjs`에서 **입력 디렉터리와 출력 파일 위치 두 곳만** 프로젝트 내부로 바꿨다. 컴파일 결과는 원본 `art-data.ts`와 바이트 단위로 같다. PNG 코덱은 원본을 그대로 포함했다. 파일별 해시는 `npm test`로 검사한다.

## 원본 출력 기준

`fixtures/baseline-v1/manifest.json`에 캡처 출처·수량·파일 해시를 기록했다. **추출 전 원본 게임 함수**로 생성한 기대값이며, 추출 후 복사본에서 새로 만든 기대값이 아니다.

- 최초 개체 6마리의 전체 유전체.
- 세 부모 조합의 교배 확률표와 자손 96마리의 전체 유전체. Lilly·아잔틱·C/S/H 사본 상속과 비생존 결과 포함.
- 멘델 유전형 60조합 × 파이어 2상태 = 120조건의 표현형·렌더 형질·무늬 관찰값·RGBA SHA-256.
- 기존 렌더러로 출력한 노멀/릴리화이트/아잔틱/카푸치노/하이웨이/세이블의 96×96 투명 PNG 6장. 고유 C/S/H 외형이 추가됐다는 의미가 아니다.

캡처에 사용한 원본 진입점은 `founderRecord`, `offspringRecord`, `cross`, `phenotype`, `patternTraits`, `specimen`, `renderSprite`다. 게임에 의존하는 임시 캡처 도구는 최종 프로젝트에 포함하지 않았다. 검증은 보존된 입력·기대값을 로컬 엔진으로 재실행한다. 기준 JSON·PNG는 테스트에서 읽기만 하며 자동 갱신 명령은 제공하지 않는다.

원본 소스의 사용 조건을 새 라이선스로 임의 변경하지 않았다. 추출 결과에 별도 오픈소스 라이선스를 덧붙이지 않았다.
