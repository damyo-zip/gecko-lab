# 완전 독립 추출 검증 — 2026-10-17

- 실행 의존성을 가진 원본 순수 TypeScript **25개**와 렌더 원화/채널을 프로젝트 내부에 포함했다. 원본 파일은 SHA-256으로 바이트 일치를 검사한다. 게임 UI·상점·경제·턴·게임 저장 모듈은 포함하지 않았다.

- `npm test`: **21개 / 4파일 통과**. 원화 컴파일 일치, 63좌위 사본 상속, 유전·픽셀 고정 기준, JSON 복원, 캐시 보호, 프로젝트 내부 전이 의존성, 원본 코드/아트 해시 등을 검사한다. 별도 디렉터리 실행 약 **1.27초** (원화 확인 단계 제외).
- 소스 압축을 풀어 원본 저장소 밖에 프로젝트를 만들었다. 그 폴더 자체에서 **`npm ci`**, 타입 검사, **`npm test`**, **`npm run build`**, `npm run build:engine` 통과. Next/React가 설치되거나 해석되지 않으며 각 원본 코드/아트의 실제 파일 경로가 모두 해당 프로젝트 내부임을 검사했다.
- 추출된 프로젝트의 개발 서버를 전용 **5184 포트**에서 새로 띄워 데스크톱 Chromium / Pixel 7 에뮬레이션 **6개** 브라우저 테스트 통과 (**13.9초**). 다른 개발 서버는 재사용하지 않는다. 랜덤/설정 생성·형질 편집·정확한 재현·PNG·JSON/새로고침 복원·32자손 배치·3세대 교배·페이지 분할·B 원본·비생존 표시 확인. 실제 Android 단말은 미검증.
- 단일 ES 모듈을 DOM 없는 Node에서 불러와 부모·자손 생성 및 **96×96 RGBA 36,864바이트** 출력을 확인했다. 최종 앱 JS 약 **167.6kB / gzip 29.0kB**, 엔진 약 **160.8kB / gzip 24.2kB**. 아트·기준 JSON은 테스트/참고 자료이며 앱 JS에 추가되지 않았다.
