# 월 단위 시간·성장 규칙

규칙 버전 5는 1턴을 정확히 1개월로 계산합니다. 나이의 기준은 `turn - birthTurn`이며 일수를 30으로 나누어 개월을 추정하지 않습니다. 화면의 공통 표시는 `0개월`, `7개월`, `1년`, `1년 6개월`, `3년 2개월`, `12년`처럼 0인 나머지 개월을 생략합니다.

| 항목 | 규칙 |
|---|---|
| 유체 | 0~5개월 |
| 아성체 | 6~17개월 |
| 성체·교배 | 18개월 이상, 180개월 미만 |
| 노령 | 144개월(12세)부터 |
| 번식 은퇴 | 180개월(15세)부터, 암수 모두 신규 교배 불가 |
| 자연사 | 216개월(18세)에 확정. 이전의 확률 자연사 없음 |
| 산란 | 신규 교배 다음 턴, 알 2개 한 번 |
| 인큐베이션 | 수거 후 3턴. 수거 대기·수령·실패 알 제거는 기존 수동 규칙 유지 |
| 암컷 휴식 | 산란 후 2턴 |

하트·자동 급여·자동 사료 구매·공간 예약·상점 가격·번식 성공 확률·유전 및 외형 엔진은 그대로입니다. 사료 부족에 따른 폐사는 나이와 별도로 기존대로 적용됩니다. 산란은 은퇴 이전에 시작한 예약을 계속 처리하지만 자연사 등으로 어미가 사라지면 기존 취소 규칙을 적용합니다.

해칭 개체의 애칭은 수정 시 기존 애칭 목록에서 독립된 이름 RNG로 결정합니다. 유전체·성별·부화 결과의 RNG를 소비하거나 재추첨하지 않습니다. 같은 게임의 기존 개체와 확정된 다른 배아 이름을 피해 정하고, 알 수거·수령·성장·저장 후에도 유지합니다. 플레이어의 이름 변경 기능은 유지합니다.

## 이전 저장

기존 저장을 체크섬·구조·유전 상속 검증한 뒤 production 경계에서 한 번만 이전합니다. IndexedDB 버전과 저장 envelope 버전은 그대로이며, `rulesVersion:5`와 `monthlyCalendar`를 추가합니다. 기존 원본은 같은 IndexedDB 트랜잭션으로 아카이브합니다. `newGame`/`newForgeGame`와 역사 reader는 이전 규칙의 회귀 검증용으로 남기고, 새 정식 게임은 `newMonthlyGame`, 정식 복원은 `readMonthlySave`/`parseMonthlyBackup`을 사용합니다.

- 턴·자금·사료·개체 ID·유전체·외형 시드·부모·거래·도전 보상·Rush 기록을 재생성하지 않습니다.
- 기존 숫자 턴 나이를 개월 나이로 이어받습니다. 생존 보유 개체와 현재 매물의 성장 단계만 재분류하므로 이전의 12~17턴 성체는 아성체가 됩니다. 사망 개체를 되살리거나 과거 거래·완료한 부화 기록을 바꾸지 않습니다.
- 진행 중인 기존 교배의 산란 예정 턴과 알의 남은 턴을 유지합니다. 기존 알은 4턴 인큐베이션 계약을 유지하고, 신규 월 규칙 교배의 알부터 3턴을 씁니다. 확정 배아의 유전체·성별·수정·부화 판정은 유지합니다. 아직 부화하지 않은 알의 날짜·성체 예정 메타데이터만 월 규칙에 맞춥니다.
- 날짜는 게임용 고정 30일 달력입니다. 이전 기준점 전의 날짜 기록은 7일/턴으로 보존하며 이후 30일/턴으로 전진합니다. 나이 판정은 항상 정수 개월이고, 브라우저 현실 시간이나 달 길이는 성장에 영향을 주지 않습니다.
- 판매·사망 개체의 나이는 실제 거래·사망 시점에 멈춥니다.

## 도전 예시 확대

목표 대표 예시와 인정/불인정 예시의 이미지를 한 번 터치·클릭하거나 키보드로 실행하면 기존 확대 관찰창을 엽니다. 96×96 실제 스프라이트와 공통 nearest-neighbor 확대를 그대로 사용합니다. 게임 상태와 보상은 변경하지 않습니다.
