# 본게임 대표 모프명

B-ORIGIN-01을 사용하는 정식 게임에서는 여러 발현명을 이어 붙이지 않고, `forge-display-name.ts`의 `FORGE_MORPH_PRIORITY`에서 가장 먼저 해당하는 이름 하나만 표시합니다. 이 순서는 게임의 표시 정책이며 유전적 우열이나 시장 가치 순위가 아닙니다.

1. 이미 판정된 복합폼: 설악, 프라푸치노, 루왁, 세이블/하이웨이, 카푸치노/하이웨이
2. 슈퍼 카푸치노, 슈퍼 세이블, 슈퍼 하이웨이
3. 아잔틱, 릴리화이트, 카푸치노, 세이블, 하이웨이, 팬텀
4. 화이트아웃, 슈퍼스트라이프, 리버스 핀스트라이프, 쿼드스트라이프, 엠티백, 화이트월
5. 트라이컬러 익스트림 할리퀸, 트라이컬러 할리퀸, 익스트림 할리퀸, 고밀도 달마시안, 풀 핀스트라이프
6. 할리퀸, 브린들, 타이거, 하이 플레임, 플레임, 달마시안, 포트홀, 파셜 핀스트라이프, 패턴리스

예: 릴리화이트·달마시안·풀 핀 → **릴리화이트**. 아잔틱·세이블 → **아잔틱**. 카푸치노+릴리화이트로 엔진에서 이미 판정한 프라푸치노 → **프라푸치노**.

현재 렌더러가 관찰한 무늬와 실제 발현 파라미터에서 후보를 구합니다. 숨은 열성 보인자는 후보가 아닙니다. 여러 구성 요소를 별칭으로 새로 합성하지 않습니다. 미검증 C/S/H 조합의 제한과 건강 관련 정보는 상세·위험 안내에 보존합니다.

컬렉션·상점·교배·인큐베이터·혈통도의 공통 `visualName`에만 적용합니다. 상세정보의 전체 외형 분류, 추가 특징, 공개 유전 정보, 생략된 특징의 검색·필터는 유지합니다. 유전형·교배·렌더링·가격·저장 데이터와 플레이어가 정한 개체 이름은 바꾸지 않습니다. 과거 렌더러의 재현 경로와 연구실의 상세 분류도 보존합니다.

우선순위를 바꾸려면 `src/game/hardcore/forge-display-name.ts`의 배열만 조정하면 됩니다.

## 상점 애칭

새 게임과 이후 재고 갱신에서 생성되는 매물은 모프·성별을 이름에 붙이지 않고 모찌·두부·구름 같은 임시 애칭을 받습니다. `shop-nicknames.ts`의 별도 고정 시드 추첨을 쓰므로 교배·성별·재고 유전 추첨에 영향을 주지 않습니다. 같은 배치와 기존 개체 이름과의 중복을 피하고, 후보를 모두 사용했으면 숫자 접미사로 구분합니다. 모프·성별·성장 단계는 기존 전용 항목에 표시합니다.

애칭은 구매 후 개체 이름으로 이어지며 직접 변경할 수 있습니다. 기존 저장의 개체 이름과 이미 생성된 매물은 보존하고, 기존 게임은 다음 재고 갱신부터 새 애칭을 적용합니다.
