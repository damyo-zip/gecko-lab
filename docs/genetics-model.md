# 유전 모델 / 규칙 v2 (Phase 3)

정식 게임은 저장 v3 / 규칙 v2입니다. 기존 멘델 계산 API와 Lilly 모델을 보존하고 별도 `genetics/hardcore.ts` 레지스트리에서 동일 계통 Axanthic을 추가했습니다. 아래 Phase 2 규칙 v1 기록은 `/lab/breeding`의 기존 테스트 모델 설명으로 보관합니다.

## Phase 3 열성 작업 모델의 범위

Ax 좌의 `A/A`는 일반형, `A/ax`는 외형에 나타나지 않는 보인자, `ax/ax`는 발현입니다. 서로 호환되는 단일 계통이라는 가정입니다. 일반형 × 발현은 보인자 100%, 보인자 × 보인자는 일반형 25% / 보인자 50% / 발현 25%를 계산합니다. 후대의 발현은 부모가 실제 전달한 두 `ax` 대립유전자에 의해 결정하며 별도의 조부모 외형 추첨은 없습니다. 게임에서 혈연 없는 보인자 매물을 구매해 교배할 수 있습니다.

브리더 관찰 기반 작업 모델이며 모든 실제 Ax 계통의 호환성, 분자 검사 또는 복합 모프의 독립성을 입증한 결과가 아닙니다. 이번 환경에서는 공개 브리더 자료 접근이 네트워크 403으로 차단되어 새 실증 자료를 독립적으로 확인하지 못했습니다. 따라서 유전 법칙의 계산 테스트 통과를 실제 생물학의 검증 완료로 표현하지 않습니다. Lilly와 Ax 좌의 독립 유전, 두 계통의 동일성은 명시적인 모델 가정입니다. Cappuccino와 복잡한 복합 관계는 포함하지 않습니다.

기존 v2 Lilly-only 개체는 유전 데이터를 그대로 저장하고 새 좌 계산 시 `A/A`로 취급합니다. 이는 이전 게임에 Ax 정보가 없었기 때문에 추가한 게임 호환 가정이며 실제 기존 개체의 보인자 검사를 의미하지 않습니다.

수정 90%·알별 부화 90%는 독립 게임 난수입니다. Day 0 교배 때 부모 유전형·잠재 형질·성공률을 캡처하고 Day 1 수정 판정, Day 2 유전형·잠재 형질·내부 성별·고유 외형 시드 확정, Day 3 부화 판정을 합니다. 부화 판정은 알 시드의 독립 도메인으로 계산하며 저장·재접속에 따라 다시 바뀌지 않습니다. 해칭의 내부 성별은 성체 때까지 화면에 공개하지 않습니다.

하트와 한국 자정 관리, 4일의 번식 일정, 부화 후 1일 성체 성장, 배란 6일/2일·회복 4일은 현실 생존·성장·배란 통계가 아닌 압축 게임 규칙입니다. 기본 일정은 아성체 표시 기간을 생략하며 별도 기간 설정이나 이전 v2 게임에는 아성체 단계가 유지됩니다.

## 보존된 Phase 2 모델 기록

## 계산 대상으로 채택한 범위

이번 구현은 프로젝트 요청에서 지정한 Lilly White 모델만 채택합니다.
유전자좌 이름은 모델 내부 식별자이며 특정 분자 유전자나 실제 DNA 검사 결과를 의미하지 않습니다.
브리더 관찰에서 쓰는 단일 우성·동형접합 비생존 모델을 멘델 분리 법칙으로 계산합니다.
이번 실행 환경에서는 외부 브리더 사이트의 최신 자료를 독립적으로 열람하지 못했습니다.
따라서 새로운 실증 결과나 정확한 사망 시점을 검증했다고 주장하지 않습니다.

| 부모 | 수정 시점의 이론적 유전형 확률 | 생존 개체만 고려한 조건부 확률 | 게임 실행 |
| --- | --- | --- | --- |
| n/n × n/n | n/n 100% | n/n 100% | 혈연·성장·대기 검사 후 가능 |
| n/n × n/Lw | n/n 50%, n/Lw 50% | 각각 50% | 혈연·성장·대기 검사 후 가능 |
| n/Lw × n/Lw | n/n 25%, n/Lw 50%, Lw/Lw 비생존 25% | n/n 33.3%, n/Lw 66.7% | 차단 |

비생존은 컬렉션·희귀 보상으로 등록하지 않습니다. 교배 전에 위험률이 0보다 크면 차단합니다.
두 알은 독립 결과이며, 한 클러치에서 표의 비율을 정확히 재현하지 않을 수 있습니다.
분석용 샘플러는 비생존 결과도 반환할 수 있지만 게임의 알 생성 경로는 위험 조합을 먼저 거부합니다.
실제 개체의 불완전한 표현·변동 사망률·환경 효과를 추정하는 모델은 아닙니다.

## 계산하지 않는 모프

Axanthic과 Cappuccino는 등록하지 않습니다. 그 밖의 복합 형질도 확률을 부여하지 않습니다.
Phase 1의 이름이 붙은 프리셋은 외형 참고 자료이며 실제 유전형으로 해석하지 않습니다.
할리퀸·반점 등 새 게임의 시각적 분류도 추가 유전자좌를 뜻하지 않습니다.
새 유전자좌를 추가할 때는 대립유전자 관계, 생존성, 연관·상호작용과 근거를 검토하고 모델 버전 및 저장 마이그레이션을 함께 갱신해야 합니다.
현재 범용 계산 API의 여러 유전자좌 결합은 **독립 유전을 전제**합니다.

## 명시적인 게임용 가정

- 기본 체색, 적색 강도, 크림 면적, 등·측면 무늬, 반점 밀도는 각각 0~1의 잠재 수치입니다.
- 자손 수치 = 부모 평균 + 형질별 설정 폭의 균등 변이, 이후 0~1로 제한합니다.
- 변이 폭을 0으로 두면 부모 평균입니다. 이는 확정된 실제 유전 확률이나 육종 예측이 아닙니다.
- 성별은 개체별 시드로 50:50 생성합니다. 실제 성 결정 원리를 모델링한 결과가 아닙니다.
- 시작 성체 6마리는 서로 혈연이 없는 것으로 가정합니다.
- 기본 교배는 알 2개, 부화 2턴, 아성체 3턴, 성체 6턴, 교배 대기 2턴입니다.
  실제 번식·부화·성장 기간이 아닌 게임 시간입니다. 새 게임에서 설정할 수 있습니다.
- 시작 성체의 출생 턴은 성체 나이만큼 게임 시작 이전으로 기록합니다.
- 성장 단계별 그림은 아직 없습니다. 모두 Phase 1 성체 그림을 사용하고 단계는 데이터와 배지로 구분합니다.

## 혈연 검사 정책

직계 조상·자손 관계는 거리와 무관하게 차단합니다.
그 밖에는 두 부모 모두로부터 2세대 이내인 공통 조상이 있으면 차단합니다.
부모·자손, 전·반형제자매, 조부모, 삼촌·이모 관계, 사촌이 포함됩니다.
더 먼 공통 조상은 표시된 정책 밖이며 정확한 근친계수를 계산하지 않습니다.
혈통 ID는 삭제하거나 이름으로 대체하지 않고 모든 세대에 유지합니다.

## 결정성과 버전

유전형, 연속 수치, 성별, 무늬 시드의 난수 스트림을 분리합니다.
각 알의 결과는 게임 시드·클러치 번호·알 순번·부모 ID로 생성하고 산란 시 저장합니다.
부화는 그 기록을 공개하며 난수를 다시 뽑지 않습니다.
게임 저장 v2, 게임 규칙 v1, 유전 모델 v1, 그래픽 엔진 v1.0.0을 구분합니다.
저장에 게임 시드와 다음 클러치 번호, 설정한 변이 폭을 포함하므로 복원 후 다음 교배도 재현됩니다.
