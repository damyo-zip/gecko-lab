모든 모프에 같은 단계의 60좌위 유전 배경과 같은 시드를 사용합니다. 저·일반·고는 기존 합법 fixture 유전체의 비교 표본이지, 현실의 품질 등급이나 가격 판정이 아닙니다. 저발현도 B의 눈과 크레스트, 원화의 밝기 군집을 남겨 중간 단계의 개체로 감상할 수 있게 했습니다.

명도 비교는 brightness 6좌위만 바꿉니다. 기존 엔진의 명도→대비 상호작용도 그대로 남습니다. 무늬 비교는 cream/dorsal/flank/harlequin/pinstripe 좌위만 바꾸며 체색·명도 좌위와 시드는 고정합니다. '다른 배치'는 같은 유전체에 시드만 달리하므로 패턴의 위치는 바뀌어도 유전된 강도는 바뀌지 않습니다. 이 세 비교와 독립적인 유전 배경 4마리를 UI에서 전환할 수 있습니다.

## 부모·자손과 선택교배

부모 표본은 독립적인 합법 유전체이고, 자손은 정식 `inherit` + `inheritPoly`를 그대로 호출합니다. 각 자손은 멘델 좌위와 60개 가상 다유전자 좌위에서 부모별로 한 대립유전자를 받습니다. 명칭 자체를 상속하거나 자손 수치를 평균내지 않습니다. 부모의 시드와 유전체는 고정이고 '다른 자손 조합 보기'는 자손 추첨만 바꿉니다. 첫 네 결과를 그대로 보여주므로 원하는 결과가 나올 때까지 골라내지 않습니다. 네 표본으로 정확한 교배 확률을 주장하지 않습니다.

릴리 × 노멀은 릴리 여부와 피복·체색의 분리를, 아잔틱 × 아잔틱은 명도와 패턴의 중간 발현을, 카푸치노 × 하이웨이는 같은 C/S/H 좌위의 분리·복합 표현을 살펴보는 예시입니다. 기존 Lw/Lw 비생존 규칙을 우회하지 않으며 이 샘플은 Lw × 노멀을 사용합니다. 이 화면은 외형 비교용이므로 부모와 자손을 같은 성체 표시 크기로 정규화합니다. 실제 게임의 부화 나이나 성장 규칙을 변경하지 않습니다.

선택교배는 상단 입력과 별개의 고정 시드 실험입니다. G0에서 기존 `founderPoly`로 만든 12마리를 시작으로, 이후 매 세대 실제 자손 48마리를 만들고 기존 점수의 `cream×.35 + dorsal×.25 + pinstripe×.25 + contrast×.15`가 높은 두 마리를 다음 부모로 선택합니다. 표시 개체의 하이웨이 상태는 모두 n/H로 유지해 동형접합 전환을 발현 개선처럼 보이지 않게 했습니다. 대립유전자 수정·변이·이미지 덮어쓰기는 없습니다.

| 세대 | 전체 표본의 평균 형질 점수 | 대표 선별 개체의 등 백색 픽셀 |
| --- | ---: | ---: |
| G0 | .449 | 251 |
| G1 | .515 | 258 |
| G3 | .631 | 297 |
| G5 | .702 | 316 |

숫자는 코드 검증을 위한 기록이며 UI에는 점수표 대신 실제 외형을 보여줍니다. 개선은 고정 표본에서 확인한 경향으로, 모든 자손이 개선되거나 자연계의 실제 유전률과 일치한다는 뜻은 아닙니다. 이 예시에서는 등 띠 폭의 변화가 점진적이며, 전체 자세나 얼굴을 바꿔 극적인 차이를 만들어내지 않았습니다.

## 렌더링과 격리

- `src/lab/appearance/b-breeding/anatomy.ts`: B 원화 인덱스에서 눈·윤곽·입선·피부·등·옆구리·사지·꼬리 공간을 읽습니다. 원본 B PNG는 수정하지 않습니다.
- `phenotype.ts`: 기존 `regionalPhenotype` 및 60좌위 점수를 읽는 얇은 어댑터입니다. 부위별 표현 계수는 **잠정 시각 모델**입니다.
- `render.ts`: 원형 색소와 명암을 분리하고 6단계 재질 램프, 고정 시드의 픽셀 군집으로 합성합니다. 결과는 96×96, 알파는 0/255, 블러·보간·반투명 덮어씌우기 없이 생성합니다. 눈은 원화 그대로 보존합니다. 아잔틱의 눈 주변 피부·구조선은 무채색화하되 눈 자체는 보존합니다.
- `samples.ts`: 독립 유전체·실제 상속·선별 표본입니다. 게임 개체를 생성·조회·저장하지 않습니다.
- `src/lab/appearance/pixels.tsx`: 기존 베이스 연구실 Canvas 어댑터를 공유합니다. 기본 96px와 288px 정수 확대는 `imageSmoothingEnabled=false`, CSS `pixelated`입니다. 모바일의 좁은 2열 카드에서는 확대 캔버스의 표시 폭을 줄이되 96px 원본을 별도로 항상 제공합니다.
- 픽셀 캐시는 최근 48개로 제한합니다. 모프·시드·비교 조건이 바뀔 때만 표본 데이터를 만들고 동일한 입력의 결과를 재사용합니다. 정식 개체 수와 저장 상태를 구독하지 않습니다.

게임·유전 엔진·저장·가격·브리딩 도전 모듈은 실험 코드를 import하지 않습니다. 정식 게임은 기존 regional-2를 계속 사용합니다. `/bases` 변경은 공유 Canvas 추출과 새 실험 링크 추가뿐입니다.

## 검증 및 남은 한계

2026-10-17 검증: 타입 검사·프로덕션 빌드·기존 아트 두 종류의 해시 검사 통과. 전체 단위 **409개** 통과(신규 11개 포함). 기존 관련 브라우저 **22개**와 신규 모바일/PC **12개**를 확인했습니다. 최초 신규 E2E의 6건은 Canvas effect 이전 빈 픽셀 조회와 select의 정확한 라벨 매칭 때문에 실패했으며, 출력 대기·셀렉터를 수정한 뒤 신규 12개 재실행이 모두 통과했습니다. 이 수정은 게임이나 그림 코드를 변경하지 않았습니다.

브라우저에서 18개 발현 표본의 네이티브·확대 출력과 Node 픽셀, 모든 모프의 4가지 다양성 조건, 실제 가족 3조합, 부모 고정·자손 재추첨, 선택교배·복합 표본, 플레이어 저장 미접근을 확인했습니다. 360·390·430px에서 페이지 가로 넘침 없이 표 영역만 스와이프하며 6칸 카드가 유지됩니다. 실제 Android 기기 검증은 수행하지 않았고 Chromium 모바일 에뮬레이션 기준입니다. 브라우저 캡처: [390px 컬렉션 크기](collection-390.png), [390px 부모·자손](family-390.png), [전체 모바일 화면](browser-390.png), [데스크톱](browser-desktop.png).

이 실험은 여섯 모프의 지역별 표현과 그 조합을 살펴보는 단계입니다. 핀의 실제 연속선, 달마시안 점 수, 드리피·화이트월 전체 표현과 성장별 자세 차이를 완성하지 않았습니다. 꼬리의 기존 줄무늬 전체를 새로 상속하는 구조도 아니며, 카푸치노 기부·끝부분의 강도와 일부 배치만 연결했습니다. C/S/H 복합 외형은 생물학적으로 입증된 전용 외형이 아닌 잠정 게임 모델입니다.

현재 유전형의 모든 차이가 이 B 실험에서 서로 다른 픽셀을 만드는 것은 아닙니다. 눈과 기본 자세는 공통이고, 시드별 위치는 개체의 변동성으로 남겨두었습니다. 가격·도전·저장·정식 화면 적용과 새로운 유전 규칙은 이번 작업 범위에 포함하지 않습니다. 예쁨과 브리딩 욕구는 비교 이미지를 보고 판단할 부분이며, 테스트 통과를 미적 품질의 증거로 삼지 않습니다.
