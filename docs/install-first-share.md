# GECKO LAB 앱 설치 우선 공유 페이지

카카오톡 공유용 주소는 현재 배포 도메인 뒤에 `/start`를 붙여 사용합니다. 예: `https://<배포 도메인>/start`.

- `/start`: 처음 공유받은 사용자를 위한 설치 우선 진입 화면. 로컬 게임 저장을 읽거나 생성하지 않습니다.
- `/`: 기존 게임 진입 주소. 기존 UI·저장·E2E의 기준이므로 바꾸지 않았습니다.
- Chrome/Edge 등에서 `beforeinstallprompt`가 제공되면 실제 브라우저 설치창을 요청합니다.
- 카카오톡 내부 브라우저에서는 강제 외부 앱 이동을 시도하지 않습니다. 브라우저 전환 및 설치 방법을 안내하고 주소 복사를 제공합니다.
- iOS는 Safari의 공유 메뉴 → 홈 화면에 추가 안내를 보여 줍니다.
- 설치된 앱으로 `/start`에 진입한 경우 `/`로 이동합니다.
- 모든 환경에서 설치 없이 웹에서 플레이할 수 있습니다.
- 기존 `manifest.ts`, `sw.js`, IndexedDB 저장 및 게임 엔진은 수정하지 않았습니다.

> 중요: 카카오톡 내부 브라우저와 외부 브라우저/PWA 간에는 저장 데이터가 자동으로 이전되지 않을 수 있습니다. 설치부터 시작하도록 유도하되 강제하지 않습니다.

## 확인
- `npm run typecheck`
- `npm run build`
- `npx playwright test e2e/install-first-share.spec.ts`
- 실기기 확인: 카카오톡 Android/iOS 공유 열기, Chrome 설치 prompt 또는 수동 설치, Safari 홈 화면 추가, 설치 앱 독립 실행, 웹 플레이 우회.
