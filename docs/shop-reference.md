# 상점 화면과 실제 가족 매물

상점은 첨부 화면의 남색 금속 패널, 정글 배너, 오늘의 매물, 부모 버튼이 있는 2×2 카드, 금색 가격과 녹색 구매 버튼, 기존 픽셀 헤더와 4개 탭을 재현합니다. 하단 턴 넘기기는 기존 게임 행동을 호출하며 발품팔기와 별개입니다. 전체 스크린샷을 UI 배경으로 사용하지 않습니다. 배너는 별도 생성한 환경 아트이고, 개체·부모는 기존 96×96 PNG V2 Canvas 렌더러입니다.

## 실제 동작

- 매물 4마리를 상태에 저장합니다. 화면 이동·현실 시간·새로고침은 재고를 바꾸지 않습니다.
- 발품팔기는 확인 후 정확히 ₩2,000을 소비하고 새 매물 4마리를 생성합니다. 취소·자금 부족은 데이터를 바꾸지 않습니다. 일반 턴 진행은 기존 주기대로 재고를 갱신하며 발품팔기 비용을 청구하지 않습니다.
- 가격은 기존 `valueGecko`의 표현형·공개 보인 가능성·성장 단계·성별·혈통 평가를 사용합니다. 국내 시세가 검증되지 않은 임시 게임 가격입니다.
- 실제 `Gecko` 원본을 구매하고 부모 ID·출생·유전체·잠재 형질·외형 시드를 유지합니다. 현재 배치에서 구매한 카드는 구매 완료로 남으며 다시 구매할 수 없습니다. 공간 예약과 자금 부족도 기존 구매 엔진이 검사합니다.
- 상점은 게코만 판매합니다. 기존 사료 구매·사육장 확장은 헤더의 먹이 + 버튼이 여는 별도 관리 창으로 옮겼습니다. 사료 부족 경고에서도 이 창으로 연결됩니다.
- 모든 턴은 기존 7일/자동 급여/2턴 산란/2알/4턴 부화/12턴 성장/노령·수명 엔진과 저장 잠금을 사용합니다. 연속 클릭을 실제 브라우저에서 검사합니다.

## 부모와 유전 정보

`shop-family.ts`는 부모를 만든 뒤 기존 `createEmbryo` → `offspringRecord` → Mendelian/60좌위 다유전자 상속 경로로 매물을 생성합니다. 부모 외형만으로 공개 지식을 구성하며 숨은 Aa의 실제 값에서 보인 확률을 꾸며내지 않습니다. 위험 부모 조합은 생성 전에 안전한 조합으로 바꿉니다. 각 자손은 고유 시드와 원본 부모 두 마리를 갖습니다.

부모 팝업은 실제 부모 스프라이트·표현형·성별·교배 당시 나이와 자손 정보를 표시합니다. 숨은 대립유전자·유전형 코드·조부모는 표시하지 않습니다. 구매 시 외부 부모를 `status: pedigree`로 혈통에 보존합니다. 이들은 플레이어 생축이 아니므로 급여·공간·매각·교배·자연사 처리 대상이 아닙니다. 이후 혈통도·근친 차단은 기존 부모 ID 그래프를 그대로 사용합니다.

초기 매물과 이전 후 첫 신규 배치는 기존 브리딩 시작 경험을 위해 서로 관련 없는 성체 노멀 수컷·암컷을 포함합니다. 성별을 덮어쓰지 않고 해당 성별이 유전·시드 경로로 생성되는 후보를 선택합니다. 나머지와 이후 배치는 실제 시드로 나이·성별·외형을 달리 생성합니다. 초기 판매자 부모 후보는 기존 Normal/Lilly White/Ax 보인/Ax 발현 모델 범위이며, 복합 좌위의 상속 엔진 자체는 유지합니다. 새 질병·유전 확률·성별 공개 규칙은 추가하지 않습니다. 해칭·아성체 성별은 기존 규칙대로 성체 때 공개합니다.

## 저장 호환

저장 v7 / 규칙 4: `shop.batch`, `offer.purchased`, `offer.family`를 저장합니다. 부모 원본과 매물 유전체·시드의 상속 결과, 구매 원본, 기존 달력·혈통 구조를 검증합니다. 시장 가격표 교체 시 구매 완료 가격은 보존합니다.

v2–v6는 먼저 기존 구조·체크섬·유전·산란 규칙을 검증한 뒤 이전합니다. 실제 IndexedDB에서는 원본 아카이브와 active 교체를 한 트랜잭션에 기록합니다. 기존 보유·판매·폐사 개체와 알·번식·혈통·시장 거래 기록을 보존합니다. 이전 재고는 기존 순서의 최대 4개 매물을 유지하고 빈 자리를 새 매물로 채웁니다. 4개를 초과했던 미구매 매물은 이전 재고 원본 아카이브에 남습니다. 부모가 없던 매물에는 부모를 임의로 추가하지 않습니다. 다음 재고 갱신부터 새 가족 매물을 사용합니다.

검증은 실제 Chromium 모바일 터치 에뮬레이션(360/390/430px)과 데스크톱 브라우저입니다. 실물 iOS/Safari는 검사하지 않았습니다. 최종 실행 결과는 아래와 같습니다.

브라우저에서는 360·390·430px 가로 넘침 없음, 실제 부모의 Canvas, 구매·취소·정확한 비용·중복 클릭 잠금·부모 혈통·새로고침·v6 원본 아카이브를 확인했습니다. 상점 턴 버튼에서 실제 첫 교배→2알 산란→부화→이름 지정→성체→다음 세대 교배까지 수행했습니다. 생존 외부 부모 기록은 급여/공간에서 제외되고 보유 자손은 정상 급여·성장합니다. 단위 테스트는 새 부모 매물의 실제 유전체 상속과 5세대 추가 교배, 근친 차단 및 백업 일치를 검증합니다. 기존 유전학·브리딩·수명·인큐베이터·아트 회귀 테스트를 삭제하거나 건너뛰지 않았습니다.

구형 v5/v6 단위 시뮬레이션은 해당 버전의 고정 매물 fixture를 사용하고, 기존 앱 브라우저 시나리오는 v7로 이전한 실제 과거 매물 데이터를 사용합니다. 새 상점 브라우저 검증은 현재 `newGame`의 실제 부모 매물을 직접 사용합니다. 렌더링 원화와 유전 상속 엔진, 가격 산식 파일은 변경하지 않았습니다.

남은 제약: 실물 iOS/Safari 미검증, 초기 판매자 유전자 프로필은 기존 Normal/Lilly/Ax 범위, 어린 개체 성별은 기존 정책대로 성체 공개, 기존 게코 원화와 레퍼런스 원화·새 배너 사이의 아트 차이, 임시 시장 가격입니다. 좁은 모바일 화면은 세로 스크롤을 사용하며 하단까지 스크롤한 실제 화면에서 턴 버튼과 탭 바가 겹치지 않음을 확인했습니다.
