# 개체 카드 이름 수정·분양

컬렉션의 앞 6마리와 전체 개체 관리 목록이 같은 `CollectionCard`를 사용합니다. 이름을 누르면 입력창·취소·저장만 있는 이름 수정 창, 분양 예상가를 누르면 실제 판매 전용 창을 엽니다. **컬렉션 메인에는 판매가격을 노출하지 않으며**, 가격 표시와 가격 터치 판매는 전체 개체 팝업에서만 제공합니다. 이름·가격·상태·더보기는 중첩 버튼이 아닌 독립 버튼이며, 이름과 가격은 개체 선택을 실행하지 않습니다.

이름 수정은 공통 `Dialog`의 헤더 없는 모드로 열립니다. 화면 읽기 프로그램에는 창 이름을 제공하되 시각적 제목은 표시하지 않습니다. 모달을 여는 layout effect에서 입력창에 포커스하고 기존 이름 전체를 선택합니다. `enterKeyHint="done"`과 form 제출로 완료 키를 지원합니다. `visualViewport`의 높이·상단 위치를 따라 키보드가 차지한 공간 위에 창을 배치합니다. 기존 이름의 공백 제거·1~24자 검증을 `validatedGeckoName`으로 공유하며, 기존 rename 액션으로 저장 완료 후 반영합니다.

분양 창은 기존 `Sprite`의 성장 비율을 한 번 적용하고 `valueGecko(...).sell`을 표시합니다. 실제 판매도 기존 sell 액션과 IndexedDB 커밋을 사용합니다. 동기 입력 래치와 기존 게임 액션 잠금, 보유 상태 재검증으로 중복 지급을 막습니다. 산란 전 암컷의 분양 제한을 공통 함수로 재사용합니다. 판매 기록과 부모·자손·유전체는 삭제하지 않습니다.

## 가격 태그의 근거

가격식을 바꾸지 않고 기존 수치 항들을 `valuationFactors`로 분리해 가격 계산과 표시가 공유합니다. 기준값과 같은 중립 항은 태그를 생성하지 않습니다.

| 실제 항 | 표시 | 색상 기준 |
| --- | --- | --- |
| 모프별 기준가 | 릴리화이트 기준가, 아잔틱 기준가 등 | **현재 가격표의 노멀 기준가**보다 높으면 녹색, 낮으면 적색 |
| 외형 계수 | 외형 가산 / 외형 감산 | 기존 패턴·연결도·점·대비 또는 이전 외형 수치의 **최종 계수**가 1보다 큰지/작은지 |
| 공개 보인 정보 계수 | 공개 보인 정보 | 실제 공개 확률과 판매자 신뢰도를 적용한 계수가 1보다 클 때만 녹색 |
| 성별 계수 | 성체 암컷 | 성체 암컷의 실제 1.08배 가산만 녹색 |
| 성장 단계 계수 | 아성체 단계 / 해칭 단계 | 실제 0.8배 / 0.65배 감산만 적색 |
| 문서화된 부모 계수 | 부모 기록 | 실제 1.05배 가산만 녹색 |

작은 패턴 기여만으로 ‘우수한 패턴’이라 부르지 않고 외형의 순계수를 설명합니다. 모프 이름에 따른 별도 중복 프리미엄은 없습니다. 모든 개체에 공통인 매입/매도 배율·천 원 단위 반올림은 개체 특성 태그로 나열하지 않습니다. 현재 가격식에 없는 노령·번식 은퇴·건강·근친·교배 가능 상태는 태그로 만들지 않습니다. 숨은 보인자 진실을 조회하지 않습니다.

전체 개체 관리 창을 유지한 채 위에 공통 작업 창 한 개만 열며, 작업 후 필터·정렬·기존 스크롤을 유지합니다. 가상 목록의 카드마다 모달을 만들지 않습니다. 이름 변경으로 현재 필터에서 제외되거나 판매로 항목이 사라지면 실제 목록을 즉시 갱신합니다.

## 검증 및 한계

2026-10-16 검증: 전체 단위 **369개 / 33파일**, 관련 모바일·데스크톱 E2E **44개 / 5파일**, TypeScript 검사, 프로덕션 빌드, 아트 PNG/runtime 해시 검사 통과. 수정 전 확보한 450개 견적의 SHA-256 기준값으로 가격·반올림·반환 형태 불변성을 확인합니다. 새 E2E는 모바일 Android Chrome 에뮬레이션과 데스크톱 Chromium에서 입력 전체 선택 후 덮어쓰기, 완료 키 저장, 취소, 공백/24자 검증, 분양 취소, 실제 가격·금액 반영, 같은 프레임의 중복 판매, 산란 전 제한, 저장 후 재접속, 목록 유지·스크롤/필터 보존을 확인합니다. 360·390·430px와 키보드의 visual viewport 축소를 모사합니다.
