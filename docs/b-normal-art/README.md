## 8종의 독립적인 큰 구성

| 번호 | 아트 | 새로 그린 구조 | 감상 및 보완점 |
| --- | --- | --- | --- |
| 01 | B 원본형 | 최초 원본을 그대로 사용 | 얼굴·그림체·원본 완성도 비교 기준 |
| 02 | 넓은 등무늬형 | 넓은 안장, 아래쪽 깊은 홈, 좁은 측면 여백, 분리된 꼬리 띠 | 작은 카드에서도 등 중심 배치가 읽힘 |
| 03 | 측면 대형 패턴형 | 가는 등 띠와 서로 떨어진 큰 측면 섬 세 개, 굵은 꼬리 띠 | 덩어리 배치 차이를 보기 좋은 후보 |
| 04 | 세밀한 분리형 | 등 조각과 작은 꽃잎형 측면 무늬, 짧은 꼬리 사슬 | 96px에서는 구분되지만 더 작은 카드에서는 조각이 뭉쳐 보일 수 있음 |
| 05 | 강한 할리퀸형 | 넓은 측면 무늬·갈색 창·어깨와 허벅지 확장 | 넓은 피복과 사지 확장이 뚜렷함. 일부 밝은 면의 세부 질감은 추가 다듬기 가능 |
| 06 | 연결형 | 등에서 내려오는 가지, 측면 갈고리, 꼬리의 길게 이어지는 선 | 02와 크림 면적은 비슷하지만 연결과 갈색 창 배치가 다름 |
| 07 | 저패턴형 | 짧은 등 끊김, 작은 측면 흔적, 꼬리 반달 | 원본의 패턴을 제거한 부분은 새 피부 명암이므로 원본 질감과 완전히 같지는 않음 |
| 08 | 빗살 창작형 | 기울어진 가지 세 줄과 엇갈린 꼬리 띠 | 구조 차이는 분명하나 규칙적인 빗살 느낌을 더 자연스럽게 다듬을 여지가 있음 |

02·03·05·06은 큰 배치의 차이를 검토하기 좋은 초안이다. 04·07·08은 위 보완점을 가진 비교 후보로 제공한다. 자동 수치로 ‘8종 모두 아름답다’고 판정하지 않는다. 원본보다 모든 면에서 우수하다는 의미도 아니다.

### 실제 패턴 참고와 창작의 구분

[Pangea의 Harlequin 설명](https://www.pangeareptile.com/collections/harlequin)을 2026-10-17 직접 확인했다. 배 쪽 패턴이 등 방향으로 퍼지는 분포와 측면 중간선을 넘는 발현의 설명을 참고했다. 기존 프로젝트의 [패턴 자료](../inherited-patterns.md)에 기록된 플레임·할리퀸·패턴리스·타이거/브린들의 일반적 감상점도 참고했다.

02는 등 중심 분포, 05는 측면·사지의 풍부한 크림 패턴, 07은 저패턴의 여백, 08은 횡무늬 리듬에서 착안했다. 이 그림들이 실제 브리더의 정확한 모프 판정을 충족한다고 확정하지 않는다. ‘측면 섬’·‘연결형’·‘빗살’은 **아트 배치 설명**이며 새 모프명이 아니다. 이번에는 다른 유전 모프를 작업하지 않는다.

## 수작업 윤곽과 공유 명암

`src/lab/appearance/b-breeding/normal-art/art.ts`에 후보별 전체 윤곽을 **정수 픽셀 좌표**로 각각 그렸다. 큰 무늬·갈색 창·짙은 악센트가 완성형 구성을 이룬다. 좌표를 네이티브 격자에 채우며 랜덤 노이즈, 이전 family 맵의 팽창/침식, 무늬 조각의 확률 배치, 기존 피복·연결 선택기를 호출하지 않는다. 원본 무늬를 모든 후보에 남긴 채 넓이만 조절하지 않는다.

새 7종의 몸통·꼬리에서는 원화의 고정 색 무늬를 대체한다. 다음을 분리해 처리한다.

1. **원본 고정 영역**: 얼굴 전체(좌표 x<36, y<38), 눈·콧구멍·입선·잉크·실루엣은 그대로다. 일반 후보의 사지는 원본이며, 05만 직접 지정한 상부 사지 무늬를 추가한다. 알파와 자세는 전 픽셀에서 동일하다.
2. **구조 명암 가이드**: 등 윗면, 몸통 옆면, 하복부, 꼬리 바깥면과 안쪽 그림자를 직접 지정한 작은 명암 지도로 처리한다. 이 가이드는 무늬의 윤곽과 독립적이다. 피부·크림 모두 7단계 팔레트로 출력하여 넓은 밝은 면도 단색이 되지 않는다.
3. **원본 미세 질감**: 원화의 같은 재질 안에서 국소 중앙값 대비 ±1단계인 작은 밝기 차이를 읽는다. 원본 크림의 큰 덩어리를 조명으로 잘못 남기지 않기 위해 재질을 구분한다. 출력에 필터·블러·색 평균·안티앨리어싱은 적용하지 않는다. 새 질감 노이즈를 생성하지 않는다.

새 몸통의 명암은 원본의 색 패턴을 대체하기 위해 다시 그린 근사다. 얼굴과 잉크·실루엣은 정확히 보존하지만 **몸통의 모든 원본 픽셀을 보존했다고 주장하지 않는다.** 특히 저패턴형에서 원화에 있었던 질감 일부가 사라지는 한계가 있다. 이 부분은 사용자 선택 후 전용 픽셀 아트로 더 다듬을 영역이다.

원본 PNG SHA256은 `487aa44664d047f20a6875c48715f3a083ee876ddc524d5c01150ac9f03959de`, 원본 RGBA는 `8ebf9695758b0f95e93e0c2c4d0426917283a7d61949f507534ad2c83cdc51ad`로 동일하다. 원화·컴파일러·기존 실험 아트는 덮어쓰지 않았다. 결과 캐시는 고정된 8개뿐이다.

## 기존 60좌위와 연결할 때의 초안

**이번에는 자동 선택을 구현하지 않았다.** 실제 부모나 자손에 아트 ID를 상속시키지 않는다. 좋은 아트를 고른 다음 아래 다차원 특징으로 후보를 제한하는 구조가 자연스럽다.

| 관찰 특징 | 기존 모델에서 참고할 수 있는 데이터 | 설명하기 어려운 차이 |
| --- | --- | --- |
| 총 무늬 면적 | `cream`, `dorsal`, `flank`, `harlequin` | 면적이 같아도 무늬 구조는 다름 |
| 등·측면·사지의 분포 | `dorsal`, `flank`, `harlequin`, 기존 파생 `limbs` | 정확한 위치와 전신의 분지는 독립 형질이 아님 |
| 연결성 | `pinstripe`는 실제 핀선에만 적용. 기존 `side` 파생값은 측면 선 참고 | **크림 덩어리 연결 ≠ 핀스트라이프**. 06을 높은 pinstripe 하나로 선택하면 부정확함 |
| 덩어리 크기·개수 | 기존 `complexity`는 harlequin 앞 3좌위의 파생값 | 크기·개수의 독립 좌위 없음. 현재 값은 대략적 선호도만 설명 가능 |
| 경계 복잡성 | 기존 `complexity`, 횡무늬에는 `tiger`·`brindle` 파생값 참고 | 잎/빗살의 각도, 위치, 방향, 창 배치 자체는 설명하지 못함 |
| 무늬 대비 | `contrast`, `brightness`와 기존 발색 점수 | 이 화면은 비교를 위해 기본 체색을 고정했으므로 실제 유전 발색 시뮬레이션이 아님 |

`spots`는 달마시안 점 형질이므로 크림 무늬 개수로 전용하지 않는다. 현재 complexity·tiger·brindle·limbs 등은 **기존 좌위에서 파생되는 게임용 값**이며 독립 유전자가 아니다. 부족한 부분을 임의의 신규 좌위로 채우지 않았다.

향후 방식은 (1) 기존 점수로 분포·대비·면적 경향을 정하고 (2) 그 경향에 맞는 완성형 아트 여러 개를 후보로 남긴 후 (3) 기존 파생값과 고정 외형 시드로 후보 간 배치를 선택하는 방향이다. 큰 구성을 먼저 사람이 검토하므로 완전 절차 생성보다 96px에서 균형을 지키기 쉽다. 단, 정확한 덩어리 개수·모양의 유전성을 현재 데이터만으로 보장할 수 없다. 사용자 선택 전에는 이를 정식 유전 규칙으로 확정하지 않는다.

## 관찰값과 검증

`evidence.json`은 실제 픽셀 해시와 무늬 마스크 면적·부위 분포·4방향 연결 덩어리·최대 덩어리 비율·경계 길이를 기록한다. 경계 복잡도는 `외곽 픽셀 변의 수 / sqrt(면적)`이다. 보호된 잉크나 가려진 부분이 연결을 나눌 수 있다. 원본의 마스크는 밝은 크림 팔레트 픽셀을 읽은 근사이며, 새 후보는 명시된 재질 마스크이므로 원본의 어두운 패턴 그림자까지 정확히 분리한 실측값은 아니다. 관찰값은 유전·가격·품질 점수에 사용하지 않는다.

02와 06은 크림 면적 527px·539px로 비슷하지만 경계 복잡도가 13.5·17.0으로 다르다. 04는 3px 이상 분리된 덩어리 23개다. 가장 가까운 두 새 마스크(05·06)도 합집합의 **53.1%**가 서로 다르다. 이는 새로운 구조를 그렸다는 보조 증거이며 미적 품질을 증명하지 않는다.

주요 변경 파일:

- `src/lab/appearance/b-breeding/normal-art/art.ts`: 8종 정의·독립 윤곽·유전 연결 검토.
- `render.ts`: 공유 바디·명암·질감·패턴 합성, 96px 및 마스크 출력.
- `measure.ts`: 실제 마스크의 설명용 관찰값.
- `src/app/lab/appearance/b-breeding/normal-art/`: 개발용 비교 화면.
- `scripts/b-normal-art-report.mjs`: 원본 크기·확대·마스크·관찰값 내보내기.
- `tests/b-normal-art.test.ts`, `e2e/b-normal-art.spec.ts`: 원본 보존·구조 차이·화면 격리·모바일·보간 및 저장 불변성 검증.

`npm run typecheck`, `npm run build`, 단위 검사 **42파일·432개**, 신규 모바일/PC 브라우저 검사 **8개**가 통과했다. 원본 베이스·기존 패턴군·정식 아트의 컴파일러 `--check`도 통과했다. 전체 브라우저 회귀 검사 328개는 실행 중이며 종료 후 결과를 갱신한다.

브라우저 검증은 로컬 프로덕션 빌드의 Chromium 모바일 에뮬레이션이다. Android 실기기 검증은 아니다.
