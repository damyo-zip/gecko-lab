# regional-prototype-2 — 원화 질감과 구조적 명암

개발용 **`/lab/appearance`**에서 정식 → 기존 `regional-prototype-1` → 명암 개선 `regional-prototype-2`를 비교합니다. 동일한 유전체·시드·파이어 상태이며, **정식 게임·저장 형식·유전 확률·상속·가격·도전 판정은 변경하지 않았습니다.**

## 노멀에서 먼저 확인한 합성 손실

문제는 Canvas의 보간이 아니었습니다. 정식 `drawSprite`도 기존 실험 출력도 smoothing을 끕니다. 출력 픽셀이 이미 평평해진 상태에서 확대되고 있었습니다.

1. **`phenotype.ts`는 원인이 아니었습니다.** 유전체를 재질과 지역 발현 강도로 바꾸는 로직·임계값은 그대로 유지했습니다.
2. **`anatomy.ts`의 v1 조명:** 원화 밝기에서 같은 부위 5×5 평균을 빼면서 넓은 갈색 무늬뿐 아니라 턱·목·사지의 실제 넓은 음영도 제거했습니다. 남은 값을 약한 머리/몸통 기울기, 사지의 `y % 12`, 꼬리 전체 상수 조명으로 보충해 입체적인 원화 음영을 복원하지 못했습니다.
3. **`render.ts`의 v1 재질 조명:** 백색 재질을 거의 같은 백색 하이라이트와 혼합하니 차이가 반올림으로 사라지고, 짙은 피부와 짙은 잉크도 값이 가까워 그림자 차이가 작았습니다. 그 위에 파이어다운의 20% 혼합이 적용되어 국소 대비가 더 줄었습니다.
4. **8레이어의 가림:** 등/측면 재질은 불투명한 상위 레이어입니다. 아래의 shadow/highlight가 있어도 상위 재질이 동일한 약한 shader로 다시 칠해지면 명암을 되살릴 수 없습니다. 레이어 수를 늘려 해결할 문제가 아닙니다.
5. **정식 `renderSprite`와 차이:** 정식은 원화의 절대 밝기로 재질을 조절해 넓은 대비와 픽셀 군집을 더 남깁니다. 다만 원래 노멀의 갈색 색소 무늬까지 명암으로 복사할 위험이 있어 그대로 복제하지 않았습니다. 기존 아트의 shadow 마스크도 밝기 임계값에서 생성된 것이므로 실제 그림자 정답으로 취급하지 않았습니다.

일반 노멀 예제의 동일 재질 내 인접 밝기 차이는 정식 **17.7**, v1 **8.9**였습니다. 실루엣이 같아도 내부 픽셀의 구분이 절반 가까이 줄어든 것입니다. 이 수치에는 재질 분류 오차가 있고, 값이 높다고 무조건 좋은 그림은 아닙니다.

## 변경한 마감 단계

기존 **표현형 → 지역 재질/무늬 → 조명 → 8레이어 합성**을 재사용합니다. `renderRegional` 하나에서 기존/새 마감을 선택합니다. 모프별 무늬 생성, 난수 스트림, 재질과 백색/암색 마스크는 공통입니다. v1의 shader·조명 계산은 유지해 과거 결과를 정확히 다시 그립니다.

- **원화 재질군의 질감:** 현재 원화의 팔레트를 크림/갈색 색소/따뜻한 바탕/아랫면 재질군으로 주석 처리하고 각 군의 기준 밝기를 분리했습니다. 갈색 덩어리 전체를 그림자로 복사하지 않고, 군 내부의 밝고 어두운 픽셀 군집을 이용합니다. 새로운 랜덤 노이즈는 넣지 않았습니다.
- **구조 경계:** 턱·눈 뒤·목·어깨·배 접촉·뒷다리의 실제 원화 위치를 주석 처리했습니다. 해당 영역에서도 원화의 어두운 픽셀을 확인하여 접힘을 배치합니다. 좌표 선 전체를 어둡게 칠하면 밝은 입술 반대편에 가짜 경계가 생기므로 피했습니다. 원화 내부의 가장 짙은 관절 픽셀도 재질에 상대적인 접힘 명암으로 처리합니다.
- **부위별 입체감:** 머리·몸통의 부피, 멀리 있는 다리, 사지 단면, 기존 꼬리 spine의 횡단 방향을 사용합니다. 무늬 좌표와 꼬리 길이 좌표는 그대로이며, 기존 상수 꼬리 조명과 사지 반복 기울기만 새 마감에서 교체합니다.
- **재질별 밝기 램프:** 백색의 중간 밝기를 조금 낮춰 밝은 부분이 모두 255에 붙지 않게 하고, 어두운 재질에는 작은 반사광 여유를 둡니다. 0.1 단위로 양자화한 조명으로 명암 단계를 만듭니다. 파이어다운은 재질에 먼저 적용하여 마지막에 구조를 씻어내지 않게 했습니다. 아잔틱의 피부는 무채색을 유지합니다.
- **상위 무늬에도 같은 조명 적용:** 백색·크림·암색 영역을 결정한 뒤 각 레이어에서 새 shader를 사용합니다. 원래 구조를 가릴 별도의 평면 색상 덮개를 추가하지 않았습니다.

눈·홍채·동공·입선·콧구멍과 기존 외곽선은 새 shader의 대상이 아닙니다. 실루엣·알파·픽셀 해상도도 그대로입니다. 전체 대비 필터, 새 검정 테두리, 블러, 보간, 새로운 이미지 에셋은 사용하지 않았습니다.

`quality.ts`의 7쌍 좌표는 원화의 턱·눈 뒤·목·어깨·배·뒷다리·꼬리입니다. 원화와 각 출력에서 **밝은 쪽 − 접힘 쪽**의 부호 있는 명도차를 계산합니다. 재질 안의 이웃 차이와 서로 다른 재질 사이의 경계 차이도 분리해 측정합니다. 외곽선·눈 등 보호 픽셀은 제외합니다. 좌표와 모든 결과를 공개하며 해시만으로 품질 개선을 판단하지 않습니다.

고정 시드 `regional-review-01`, 파이어업의 일부 결과 (0–255 명도차):

| 대상·부위 | v1 | v2 |
| --- | ---: | ---: |
| 일반 노멀 턱 | 10.2 | 50.4 |
| 일반 노멀 어깨 | 43.3 | 82.7 |
| 일반 노멀 꼬리 단면 | 1.5 | 10.0 |
| 극단 릴리 턱 | 24.6 | 81.9 |
| 극단 릴리 눈 뒤 | 17.6 | 41.1 |
| 극단 릴리 꼬리 단면 | 0.0 | 10.0 |
| 어두운 아잔틱 어깨 | 16.9 | 31.7 |

일반 노멀의 동일 재질 내 인접 차이는 **8.9 → 12.4**이며 정식의 17.7과 같아졌다는 뜻은 아닙니다. 극단 릴리의 얼굴 백색은 **702/702** 그대로이고 피부 백색은 **2458/2591** 그대로입니다. 얼굴 명도 p90−p10은 **37.5 → 92.1**로 넓어져 백색 안에서도 형태가 구분됩니다.

**모든 수치가 증가하지는 않습니다.** 노멀 목의 차이는 34.2 → 21.2로 줄어도 원화와 같은 방향을 유지합니다. 무늬 경계 평균은 노멀 67.5 → 55.5, 극단 릴리 24.3 → 19.5입니다. 구조적 조명이 색소 대비에 겹치기 때문이며 경계를 검게 강조해 수치를 맞추지 않았습니다. 12 이상 차이가 나는 경계의 비율은 노멀 99.7% → 98.0%, 극단 릴리 63.3% → 51.0%입니다. 특히 극단 백색 안의 작은 옅은 색소 섬은 여전히 분리가 약해 추가 검토가 필요합니다. 실제 96px 및 확대 이미지를 함께 보고 판단해야 합니다.

```sh

```

- 수정 전에 저장한 **100조건**(5배경×10모프×2파이어 상태)의 정식/v1 픽셀 해시를 fixture에 고정했습니다. 두 출력이 전부 일치하며 v1 비교 자료를 새 결과로 바꾸지 않았습니다.
- 같은 100조건에서 새 마감의 백색·암색·재질 마스크와 발현 강도가 v1과 일치합니다. 알파·눈·입선·콧구멍·외곽선 손상, 보호 영역에 무늬가 침범한 경우는 0건입니다.
- 6모프×12시드×2파이어 상태 **144개 출력**에서 모프별 24개 고유 출력, 보호 픽셀 오류 0, 마스크 불일치 0을 확인했습니다. JSON 직렬화 후에도 같은 입력은 같은 픽셀입니다.
- 실제 부모 사본으로 만든 형제 32마리의 발현과 상속이 유지되고, 기존/새 마감 호출 전후 구세이브·대기 배아·정식 픽셀·가격 견적·5개 도전 판정이 같습니다.
- 전체 단위 테스트: **36파일 388개 통과**. 관련 외형 테스트 17개도 먼저 통과했습니다.

## 현재 한계

한 장의 그림에서 빛과 색소를 완전히 분리하지는 못합니다. 해부학 주석·팔레트 참조는 현재 단일 자세용이며 사진으로 검증한 노멀맵이 아닙니다. 원화가 바뀌면 다시 검토해야 합니다. 새로운 원화와 동등한 완성도를 보장하지 않습니다.

기존 모프 발현 모델의 근거·미구현 범위는 [기존 설계](appearance-prototype.md)와 같습니다. 백색 얼굴에도 구조를 남기는 처리를 추가했지만 실제 번식 개체를 생물학적으로 검증한 결과는 아닙니다. 정식 통합은 별도 작업입니다.
