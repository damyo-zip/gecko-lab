# 최초 B · 모프별 전체 패턴군

개발 경로: `/lab/appearance/b-breeding/families` · 버전 `B-pattern-family-1`.

선택한 최초 B · 브리딩 감상형의 **원본 픽셀을 캔버스로 유지**하고, 등·측면·꼬리가 함께 설계된 패턴 계열을 선택하는 실험이다. 이전 중립 바디·조각 라이브러리·랜덤 무늬 생성기를 사용하지 않는다. 정식 게임·유전 상속·저장·가격·도전 판정은 변경하지 않는다.

## A. 모프당 4계열을 시작점으로 제안

1. **좁은·분리형:** 원본의 큰 갈색 창문을 넓히고 크림 연결을 제한.
2. **B 기본 흐름형:** 최초 B의 무늬를 기준으로 해당 모프의 핵심 특징만 적용.
3. **넓은·창문형:** 넓은 피복 속에서도 갈색 창문과 원래 질감을 남김.
4. **연결·등줄기형:** 목·등·측면·꼬리의 큰 흐름을 연결.

밝은형·어두운형은 별도 그림 계열로 늘리지 않고 유전된 명도·재질 팔레트로 처리한다. 피복 범위와 연결성은 서로 다른 축이므로 넓은형과 연결형을 구분했다. 각 계열에는 기본 흐름 A와 측면 계단·창문 배치 B의 두 **전신 구성**을 두었다.

이번 결과는 **6모프 × 4계열 = 24개 모프/패턴군 조합과 48개 전신 아트 맵**이다. 원본 B에서 파생한 전체 경계와 재질 설계이며, 서로 독립된 새 원화 48장을 손그림으로 제작했다는 뜻은 아니다. 노멀·아잔틱은 색소 체계가 다른 같은 형태 계열을 공유한다. 각 모프의 4개 최종 이미지는 실제로 서로 다르다.

| 모프 | 기본형의 감상 포인트 | 계열 변화 | 부모에게서 이어질 요소 |
| --- | --- | --- | --- |
| 노멀 | 원본의 크림 등 띠·큰 측면 창문·꼬리 무늬 | 창문 크기, 피복 폭, 전체 연결 | 체색·등/측면 성향·대비·연결 |
| 릴리화이트 | 원래 크림의 흐름을 잇는 화이트 피복 | 좁은 측면 → 넓은 피복 → 얼굴·코까지 연결 | 크림·측면·할리퀸·등과 명도 |
| 아잔틱 | 원본 밝기 단계와 무늬 대비를 가진 무채색 재질 | 같은 형태의 좁음/넓음/연결, 밝고 어두운 피부 | 아잔틱 상태와 별개인 명도·대비·무늬 점수 |
| 카푸치노 | 갈색 피부 흐름, 밝은 꼬리 기부·어두운 끝 | 측면 억제와 기부/끝의 넓이, 연결 | 기존 C 상태, 피복·등·대비·체색 |
| 하이웨이 | 원래 등 띠의 안쪽으로 이어지는 경계 | 분리된 등 표현 → 물결 → 넓은 중앙 연결 | 기존 H 상태, 등·크림·연결 성향 |
| 세이블 | 원본의 입체감을 가진 어두운 바탕과 밝은 크라운·군집 | 작은 크라운 → 등 군집 → 큰 피복/창문 | 기존 S 상태, 크림·등·대비 |

‘정석’은 아트 방향을 검토하기 위한 표현이며 업계에 합의된 수치 분류가 아니다. 특히 하이웨이·세이블·복합 모프는 브리더의 실물 검토가 필요하다. 기존 관찰 자료와 열람 한계는 [이전 근거 기록](../appearance-prototype.md#근거-확인-2026-10-16)에 남아 있다. 이번 단계에서 새 유전 법칙이나 실제 발현 빈도를 주장하지 않는다.

## C. 선택·변형 규칙 초안

```text
기존 멘델 유전형 → 표현 모프에 맞는 전체 아트 계열
기존 60좌위 → 피복·연결·부위 강조 성향 → 가까운 패턴군/전신 배치
기존 명도·체색·대비 점수 → 원본의 색 단계와 질감을 보존하는 팔레트
개체 시드 → 가까운 후보의 동점 해소
```

유전 점수 계산과 상속 함수는 변경하지 않았다. 계열 이름·아트 ID·완성 그림을 부모에게서 직접 상속하지 않는다.

- 피복 성향 = 크림 40% + 측면 25% + 할리퀸 20% + 등 15%.
- 연결 성향 = 기존 핀스트라이프 다유전자 점수. 이 수치가 높다고 정식 풀핀으로 판정하지 않는다.
- 계열의 피복/연결 기준점은 좁은형 (0.12/0.20), 기본형 (0.34/0.50), 넓은형 (0.85/0.45), 연결형 (0.65/0.92).
- 거리 = 피복 차이 65% + 연결 차이 35%. 최단 거리 +0.015 이내의 후보만 시드가 고를 수 있다. 저발현 개체를 시드만으로 반대편 고발현 계열에 보내지 않는다.
- 등/측면 강조와 꼬리 성향(등·크림·대비의 평균)으로 전신 배치 A/B의 선호를 정한다. 경계 구간에서만 시드가 두 후보를 선택한다. 부위를 독립적으로 무작위 조합하지 않는다.
- 명도·레드·오렌지·대비는 선택한 경계를 바꾸지 않고 피부와 밝은 무늬의 색 단계에 적용한다. 아잔틱은 재질 역할에 따라 별도 무채색 팔레트를 사용하며 보인자는 노멀 외형이다.

모든 계수·임계값은 **게임용 미술 선택 기준**이다. 모프별 전용 가중치의 추가 보정은 아트 검토 뒤에 필요하다. 실제 모프의 독립 유전자나 침투율로 해석하지 않는다. 밝기만 바꾼 통제 비교에서는 패턴군·배치를 고정하여 두 축을 분리했다. 자동 모드에서는 기존 다유전자 모델의 명도→대비 상호작용이 연결된 점수에도 영향을 줄 수 있다.

### 픽셀 아트 처리

`art-source.ts`에 원본 B의 큰 띠·창문·곡선을 따라 전체 경계를 직접 지정했다. 컴파일러가 이를 **완성된 96×96 전신 변경 맵**으로 고정한다. 런타임은 한 맵을 선택하여 원본 B 위에 적용한다. 랜덤 윤곽·잡음·타원 패턴이나 무늬 조각 배치 코드는 없다.

맵의 0은 원본 유지, 1은 피부 창문, 2는 크림, 3은 어두운 재질, 4는 화이트다. 원래 크림을 줄이는 창문은 같은 부위의 가까운 원본 피부 픽셀을 참조한다. 색을 평균하거나 블러로 메우지 않는다. 변경하지 않는 피부·크림은 원본 픽셀을 그대로 사용한다. 새로 넓힌 피복은 원본의 재질별 밝기 단계로 칠한다. 별도 중립 바디나 새로운 기하 조명 지도를 만들지 않는다.

눈과 눈 주변, 콧구멍·입선·기존 잉크 보호선, 알파 실루엣은 모든 샘플에서 고정한다. 최종 출력은 항상 96×96이고 확대 보간은 끈다. 원본 아트와 컴파일러는 덮어쓰지 않는다. 결과 캐시는 32개로 제한하고 전체 맵은 48개로 유한하다.

## D. 브리딩 게임에 더 적합한 이유와 남는 한계

완전 절차 생성은 자유도가 높지만 매 개체에서 큰 무늬의 균형과 96px에서 읽히는 경계를 보장하기 어렵다. 작은 조각의 독립 조합도 등·측면·꼬리가 서로 어울리는 큰 흐름을 놓치기 쉽다. 이 방식은 큰 구성을 먼저 검토해 두고 유전자가 그 안에서 방향을 선택한다. 따라서 원본 B의 얼굴·질감과 큰 무늬를 지키면서 혈통의 밝기·피복·연결 경향을 볼 수 있다.

가족 비교는 기존 상속 함수가 만든 **첫 네 자손**을 골라내지 않고 보여준다. 무늬 비교를 위해 모두 성체 기준의 96px 캔버스에 표시하며 게임의 성장 규칙은 건드리지 않는다. 릴리 여부·아잔틱 발현·C/H 조합도 실제 사본 상속 결과다. 각 자손의 점수로 패턴군과 팔레트를 새로 고른다. 선택교배는 이전 실험의 실제 선별 표본을 그대로 읽으며 유전자를 강화하거나 생성 결과를 다시 추첨하지 않는다. 실제 G0는 기본 흐름형, G5는 연결형을 선택한다. 초기의 +0.035 동점 허용폭은 축적된 형질을 시드가 가리는 문제가 보여 +0.015로 줄였다.

현재 4계열은 방향 검증에 적합한 최소 초안이다. 계열이 유한하므로 같은 경향의 개체가 닮아 보이고, 유전 점수가 경계를 넘으면 외형이 단계적으로 바뀐다. 같은 유전체의 시드만 12개 바꿨다고 반드시 12개의 서로 다른 그림이 되지 않는다. 시드가 유전적 경향을 압도하지 않게 한 의도적인 제한이다.

**복합 모프 전용 아트는 미완성**이다. 기존 C/H·C/S 등은 유전적으로 그대로 상속되지만 현재는 주된 아트 계열 하나와 재질 효과를 사용하므로 모든 부위의 복합 특징을 충분히 보여주지는 않는다. 가족 예시에 이 한계를 표시했다. 향후 아트 검토를 거쳐 모프 조합별 전체 계열을 추가해야 한다.

넓은 화이트의 새 영역과 일부 접합부는 원본의 수작업 디테일과 완전히 같지 않다. 실제 물체·사진 전체를 재현한 ‘확정 정석’으로 보지 않는다. 특히 세이블의 넓은형과 연결형 차이는 작은 카드에서 약할 수 있다. 이 결과를 보고 좋은 계열을 고른 뒤 전용 96px 아트를 더 다듬는 것이 우선이다. 정식 유전·가격·명칭·도전 연결은 이번 범위가 아니다.
