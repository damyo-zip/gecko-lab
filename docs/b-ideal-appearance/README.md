## A. 대표 이상형 6종

| 계열 | 이번에 선택한 미적 방향 | 다른 개체에서 달라질 특징 |
| --- | --- | --- |
| 노멀 | 원본의 따뜻한 등 띠, 측면 창, 꼬리 흐름 | 크림 범위, 갈색 창, 등·측면 연결, 꼬리 띠 |
| 릴리화이트 | 넓은 아이보리 측면, 얼굴·코 확장, 갈색 여백 | 피복 범위, 연결 단절, 얼굴 도달, 앞뒤 분포, 사지 |
| 아잔틱 | 은빛 무늬와 검정 안장의 분리, 원본의 명도 단계 | 회색 명도, 검정 분포, 밝은 면적, 연결·대비 |
| 카푸치노 | 커피색 바탕과 절제된 크림, 밝은 꼬리 기부·어두운 끝 | 꼬리 두 표식의 범위·대비, 등 무늬, 발색·명도 |
| 하이웨이 | 안쪽으로 넓어지는 중앙 등무늬, 적은 측면 | 등 폭·중앙 단절, 약한 등에서 남는 측면 무늬 |
| 세이블 | 짙은 브론즈 바탕, 밝은 크라운·크림 군집 | 크라운 범위, 군집 크기·연결·분포·대비 |

근거 구분은 기존 [관찰 자료](../../src/engine/regional/evidence.ts)에 따른다. 릴리의 얼굴 확장 수치, 세이블의 군집 형태, 카푸치노의 꼬리 경계, 하이웨이의 옆모습 투영은 **게임용 아트 해석**이다. 해당 표식 하나만으로 실제 유전형을 판정하지 않는다. C/S/H의 같은 좌위 해석은 기존 잠정 모델을 유지하며 새로운 치사율을 만들지 않았다. 이전 자료의 원문 접근 한계도 그대로다. 이번 작업에서 모든 출처를 새로 열람했다고 주장하지 않는다.

각 모프의 이상형은 하나의 미적 방향이다. 패턴이 적거나 덜 대비되는 개체를 낮은 가치로 규정하지 않는다. `IDEALS`의 아트 ID·모프·의미 영역을 분리하여 같은 모프에 다른 미적 방향을 추가할 수 있게 했다.

이 갤러리의 ‘노멀’은 별도 핵심 멘델 모프가 없는 기준 계열이다. 정식 게임의 패턴 분류·대표 명칭 판정은 이 실험에 연결하지 않았다.

### 이상형과 유전적으로 가능한 범위

이상형 아트 자체는 확률 표본이 아니다. 다만 **기존 모델에서 유효한 대립유전자 조합**을 넣어 각 이상형과 정확히 같은 픽셀을 생성할 수 있음을 검사했다. 모프의 핵심 유전형은 노멀 n/n, 릴리 n/Lw, 아잔틱 ax/ax, C/S/H는 각각 n/C·n/S·n/H를 사용한다. 다유전자 표현의 상한을 쓰는 통제 예는 기존 0~4 대립유전자 범위 안에 있다.

게임 모델 안에서 가능하다는 사실은 현실 개체군의 정확한 발현 빈도나 ‘최고의 개체’라는 생물학적 정의가 아니다. 실제 선별 집단은 관련 대립유전자를 잃을 수 있고, 돌연변이가 없는 기존 모델에서 모든 이상형에 항상 도달한다고 보장하지 않는다.

## B. 역방향 변형의 구현

`ideal/art.ts`에 픽셀 정수 좌표로 모프별 완성형과 의미 있는 변형 윤곽을 그렸다. 등·측면·얼굴·사지·꼬리의 패치마다 어떤 형질이 어떤 경계에서 작동할지 명시한다. 예를 들어 넓은 백색을 늘리는 윤곽과 백색 사이 갈색 틈을 만드는 윤곽은 다른 형질로 제어한다.

1. 기존 멘델 유전형을 읽어 핵심 모프와 재질을 정한다.
2. 기존 60좌위 점수 및 기존 방식의 좌위 하위군에서 각 표현값을 계산한다.
3. 표현값에 따라 손으로 그린 코어·확장·갈색 창·분리 경계를 적용한다.
4. 필요한 영역의 색소만 바꾸고 원본 밝기 단계·질감·보호선을 유지한다.

패턴을 줄일 때는 같은 해부학적 부위에 실제로 존재하는 원본 피부 픽셀을 참조하여 색소를 복원한다. 크림 옆의 베이지 경계도 구분해 원본 무늬의 밝은 흔적을 남기지 않도록 했다. 이 분해는 완벽한 물리 재질 추출은 아니며 넓은 영역에서 원본 패턴의 흔적이 일부 남을 수 있다.

픽셀마다 무작위로 지우거나 투명도를 섞지 않는다. 외형 시드는 일부 **완성된 분리 윤곽을 같은 부위 안에서 1px 옮기는 배치 선택**에만 사용한다. 유전 형질의 강도나 모프를 바꾸지 않는다. 실제 윤곽의 종류와 넓이는 유전체가 정한다. 동일한 유전체·시드는 항상 같은 결과이며 결과 캐시는 32개로 제한한다.

### 다섯 통제 단계

패턴 관련 기존 형질 6종(`cream`, `dorsal`, `flank`, `harlequin`, `contrast`, `pinstripe`)에 순서대로 `[4,4]`, `[3,4]`, `[3,3]`, `[2,3]`, `[1,2]`의 유효한 대립유전자 쌍을 넣는다. 체색·명도와 외형 시드는 고정한다. 모프마다 다른 ‘예쁜 시드’를 고르거나 자손 유전자를 이 값으로 덮지 않는다. 5단계는 설명용 통제 샘플이며 자연 개체군의 분위수는 아니다.

30개 샘플 모두 서로 다른 출력이다. 각 모프는 네 가지 이상의 서로 다른 실제 재질 지도를 사용한다. 색만 흐려진 한 그림이 아니다. 낮은 단계에서도 원본 얼굴·크레스트·입체감과 정돈된 큰 무늬를 남겨 지저분한 실패 그림이 되지 않도록 했다.

## C. 형질별 연결과 독립성

| 표현 채널 | 현재 데이터에서의 입력 | 해석의 한계 |
| --- | --- | --- |
| 크림 피복 | 기존 `cream` | 유전된 게임용 점수이며 실제 백색 면적의 공식이 아님 |
| 등·측면 | `dorsal`, `flank` | 정확한 패턴 윤곽은 아트가 결정 |
| 사지 | `harlequin`·`flank`의 기존 결합 | 부위별 인자는 미확정 |
| 등선 연결 | `pinstripe` | 핀선과 크림 덩어리 연결을 같은 값으로 취급하지 않음 |
| 군집 연결 | 기존 harlequin 앞 3좌위의 파생값 | 군집 연결 유전자가 밝혀졌다는 뜻이 아님 |
| 얼굴·크라운 | 기존 cream 앞/뒤 3좌위와 dorsal의 파생값 | **잠정적인 시각적 다면 발현 가정** |
| 꼬리 대비 | 기존 contrast 뒤 3좌위와 dorsal | 꼬리 표식의 원인 유전자로 확정하지 않음 |
| 앞뒤 분포 | 기존 flank 뒤 3좌위 | 옆모습에 대한 아트 분포 변수 |
| 명도·재질 대비·발색 | 기존 brightness·contrast·red·orange | 기존 명도→대비 공유 효과도 유지 |

어떤 새 좌위도 추가하지 않았다. 렌더러에는 단일 ‘이상형 거리’나 종합 점수가 들어가지 않는다. 같은 릴리에서 피복이 높고 연결만 약한 개체, 연결은 높지만 피복이 적은 개체, 윤곽은 같고 대비만 낮은 개체를 각각 실제 유효한 유전체로 만든다. 공유 좌위 때문에 일부 채널은 상관되며 모든 채널을 생물학적으로 완전 독립이라고 주장하지 않는다. `spots`를 크림 무늬로 전용하지 않았다.

`observe.ts`는 결과의 실제 재질과 픽셀에서 백색 면적·얼굴 피복·꼬리 암부·밝은 군집·명암 대비를 읽는 진단 전용 코드다. 가격·명칭·도전에는 사용하지 않는다.

## D. 실제 부모와 자손

`samples.ts`는 기존 `inherit`·`inheritPoly`를 그대로 호출한다. 각 자손은 모든 멘델 좌위와 60좌위에서 아비·어미의 실제 사본을 하나씩 받는다. 첫 여섯 결과를 그대로 보여주며 모프·아트·고발현 자손이 나오도록 골라내지 않는다. 이름이나 이상형 ID를 상속시키지 않는다.

릴리는 n/Lw × n/n, 다른 계열은 같은 핵심 모프의 부모로 비교한다. 다유전자 부모는 분리가 보이도록 유효한 이형접합 쌍을 갖는다. 이 실험은 번식·부화의 전체 경제·건강·턴 시뮬레이터가 아니라 **기존 유전 사본 전달을 사용하는 외형 실험**이다. 실제 게임의 교배 제한·알·건강·급여에는 영향을 주지 않는다. 비교를 위해 자손 이미지는 성체 기준으로 표시한다.

## E. 여섯 세대의 선택교배

모프별 20 창시 개체에서 시작한다. 기존 `founderPoly`로 만든 집단에서 부모 둘을 고르고, 다음 세대마다 48배아를 생성한다. 목표 모프이며 기존 규칙상 생존 가능한 개체 중 다음 부모를 선택한다. 릴리 동형접합 비생존은 기존 `LOCI.nonViable` 판정을 그대로 읽으며 다른 계열의 치사율을 추가하지 않는다.

선별 지표는 목표 채널의 `0.8 × 평균 + 0.2 × 최저값`이다. 이 스칼라는 **부모를 고르는 데만** 사용한다. 렌더링은 각 채널을 따로 읽는다. 표의 평균·최저·최고는 선별하기 전 목표 모프 집단의 지표다. 전체 배아·목표 모프·비생존 수를 함께 표시한다. 미선별 첫 6배아도 세대별로 확인할 수 있다.

기본 시드 `b-ideal-inverse-01`의 관찰:

| 목표 계열 | G0 집단 평균 | G6 집단 평균 | 6세대 동안 더 좋은 부모보다 지표가 낮은 목표 자손 |
| --- | ---: | ---: | ---: |
| 노멀 | 0.377 | 0.742 | 171 |
| 릴리 | 0.353 | 0.772 | 102 |
| 아잔틱 | 0.395 | 0.814 | 173 |
| 카푸치노 | 0.461 | 0.842 | 146 |
| 하이웨이 | 0.490 | 0.905 | 174 |
| 세이블 | 0.357 | 0.827 | 150 |

이 고정 표본에서는 평균이 매 세대 증가했다. **이는 결과 관찰이며 증가를 강제한 코드가 아니다.** 실제로 부모보다 약한 자손이 각 계열에 남았고, 릴리 288배아 중 73개는 기존 규칙상 비생존이었다. 다른 시드·부모·선별 기준에서 세대 평균이나 개별 자손이 나빠질 수 있다. 돌연변이·유전자 강화·성공 보정은 없다. 모든 개체가 이상형에 도달한다는 약속이나 미적 품질 향상의 객관적 증명도 아니다.

## 시각적으로 남은 한계

- 릴리의 얼굴·피복 차이, 아잔틱의 명암·검정 분포, 세이블의 크라운은 작은 카드에서도 비교하기 좋다.
- 하이웨이와 카푸치노의 서로 가까운 중간 단계는 카드에서 차이가 작다. 더 넓은 등 변형과 꼬리 아트의 추가 수작업 다듬기가 유용하다.
- 한 모프에 아직 이상형 하나다. 같은 경향의 유전체가 같은 큰 구성을 공유할 수 있다. 유전자 변화가 수작업 경계를 넘을 때 표현이 단계적으로 바뀐다.
- 구조 명암과 원화의 색 패턴이 완벽하게 분리된 원본은 아니다. 일부 넓은 재질 변환에는 기존 무늬의 흔적이 남을 수 있다. 현재 방식을 최종 품질로 확정하지 않는다.
- 복합 모프와 C/S/H 동형접합의 전용 이상형은 그리지 않았다. 합성 유전형은 보존하고 주요 아트와 기존 핵심 색소를 적용하지만 모든 복합 특징을 완성했다고 보지 않는다. 추가적인 생존 규칙은 없다.
- 부모 두 마리만 계속 선별하는 시범 집단이므로 다양성을 빠르게 잃을 수 있다. 현실적인 집단 관리 모델이나 새 유전 이론을 추가하지 않았다.
