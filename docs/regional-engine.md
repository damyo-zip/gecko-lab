# 정식 외형 엔진 regional-2

**명암 개선 실험본 v2**를 정식 채택했습니다. v1 마감과 섞지 않습니다. 공식 버전은 `regional-2`, 저장은 v11입니다. 새 게임에서 컬렉션·전체 목록·상세·상점/부모·교배/선택·인큐베이터·가족/세대 비교·도전 미리보기 모두 같은 `SpriteCanvas`를 사용합니다.

## 실제 경로

`game/hardcore/adapter.specimen(실제 Genome, visualSeed, fire)` → `engine/render.renderSprite` → `engine/regional/index.regionalAppearance` → `engine/regional/render.renderRegional` → `lighting.shadeRelief` → 96×96 8레이어.

`engine/regional/phenotype.ts`는 멘델·60좌위 유전체를 읽어 재질/발현을 계산합니다. `anatomy.ts`는 기존 PNG의 실루엣·보호 구조·등 깊이·꼬리 좌표를 사용하고, `lighting.ts`는 v2의 재질군 질감·해부학적 접힘·횡단 조명·단계 밝기를 그대로 적용합니다. 기존 v2의 **100조건(5배경×10모프×2파이어)과 픽셀이 일치**합니다. 원화 PNG를 바꾸지 않았습니다.

기존 1.0/2.0/patterns-1 스프라이트 구현과 실험용 이중 마감은 제거했습니다. 무늬의 실제 생성에 필요한 `pattern-plan.ts`, 래스터·팔레트·난수·합성 함수, 기존 유전 상속·건강 위험·게임 규칙은 공통 코드로 보존합니다. `/lab`·`/lab/appearance`·`/lab/patterns`에도 같은 정식 엔진만 있으며 렌더러 선택 기능은 없습니다. 별도 정면 아트의 크레 러시 카페 크레는 보유 개체가 아니며 기존 미니게임을 유지합니다.

## C/S/H 복합 표현

기존 동일 좌위의 실제 두 사본을 그대로 상속합니다. n/C, n/S, n/H와 C/C, C/S, C/H, S/S, S/H, H/H를 모두 처리합니다. 단일 사본의 v2 출력은 그대로입니다. 동형접합은 기존 발현 강도에 `min(1, strength×1.12+0.12)`를 적용하며 혼합 조합은 C 꼬리 표식 → H 등 확장 → S 머리/등 군집 순으로 같은 재질 계획을 구성합니다. Lilly의 백색 확장과 Ax의 무채색 재질은 기존 v2 순서로 작용합니다.

이는 잠정적인 시각 게임 모델입니다. 대립유전자 전파·보인자 추론·교배 경고·비생존 판정·부화율은 변경하지 않았습니다. C/S/H에 새 치사율을 부여하지 않으며 기존 Lw/Lw 비생존 배아는 정상 개체 이미지로 만들지 않습니다. 색상·패턴을 가짜 모프명이나 결과 이름에서 역생성하지 않습니다.

## 화면·명칭·가격·도전의 단일 관찰

`engine/regional/observe.ts`의 `regionalObservation`은 **실제로 그려진** 재질과 픽셀을 읽습니다. `appearanceProfile`은 이 관찰을 한국어 명칭에 연결합니다. 동일한 관찰을 상세 특징·필터·가격·도전에서 사용합니다. 렌더링은 공개되지 않은 유전 데이터를 시각화하지만 숨은 열성 보인자를 명칭/검색 조건으로 공개하지 않습니다.

- 모든 면적의 모수는 눈·입선·콧구멍·외곽선을 제외한 실제 피부입니다. `whiteArea`는 백색 재질만, `creamArea`는 실제 크림+백색, `baseArea`/`secondaryArea`는 살아남은 각 색소 영역입니다. 반점은 별도라 세 영역의 합은 반점 면적을 뺀 값입니다.
- 등·측면·사지 분모는 현재 자세의 해부학 영역으로 따로 정합니다. 원래 무늬 의도가 다른 재질로 덮였다면 분류에 세지 않습니다. 트라이컬러는 실제 영역 비율과 최종 평균 재질 색상 차이를 함께 사용합니다.
- 핀은 원래 선 경로가 최종 크림 재질로 남았는지, 주변 색소와 구별되는 구간이 충분한지 확인한 뒤 좌우 연결/끊김을 측정합니다. Lilly의 넓은 백색 피복은 핀이 아닙니다. 풀핀은 기존처럼 양쪽이 완전히 이어져야 합니다.
- 반점은 최종 반점 재질의 실제 분리된 연결 성분을 세고 부위별 분포도 기록합니다. 드리피·줄무늬는 의도한 모양의 65% 이상이 실제 해당 재질로 살아남았는지 검사합니다. 드리피는 옆 경계의 25% 이상이 실제 다른 색소와 구별되는지도 검사하여 넓은 백색 피복을 흘러내린 무늬로 오인하지 않습니다. 화이트월은 측면 벽 영역에 살아남은 밝은 재질 면적입니다. 하이웨이·릴리가 원래 크림 모양을 체색으로 바꾼 부분은 크림 면적에 포함하지 않습니다. 명칭·가격·도전 관찰은 표준 파이어 업 상태를 기준으로 합니다.
- 가격은 기존 시장 기준가·외형 가중치·공개 보인 정보·성별/성장/부모 계수·매입/매도 수수료·천원 반올림을 유지합니다. 이름 프리미엄을 추가하지 않습니다. 외형 항만 새 관찰의 면적/연결/반점/재질 대비를 사용합니다. `report.json`에 동일 조건 30개 가격 외형 계수의 변화 범위를 기록합니다. 평균 +1.1%, 범위 −18.5%~+7.2%입니다. 가장 큰 감소는 고발현 하이웨이로, 실제로 줄어든 측면 무늬와 가려진 선에 이전처럼 가산하지 않은 결과입니다. 이는 전체 시장 가격 분포가 아니라 통제된 외형 계수 비교입니다.

도전 임계값은 새 관찰 정의에 맞춰 별도로 조정했습니다. 잠금 10턴·부화 순간 달성·수동 새끼 수령·최초 1회 보상은 같습니다.

| 도전 | regional-2 판정 |
| --- | --- |
| 칠흑 | 다크 분류, Lilly/Ax 제외, 최종 기본 피부 평균 명도 ≤64, 기본 피부 ≥72% |
| 태양 | 오렌지 분류·발색 점수 ≥0.75, 기본 피부 ≥70%, 실제 반점 ≤5 |
| 별 | 실제 분리 반점 ≥65, 머리·몸통·꼬리에 각각 ≥3 |
| 순백 | Lilly, 지역 발현 강도 ≥0.85, 백색 재질/피부 ≥72% |
| 흑백 | 위 순백 조건 + 실제 아잔틱 유전형 |

이전 명도 58은 조명 전 팔레트 값이었고 현재 64는 반사광까지 합성된 기본 피부 평균입니다. 이전 크림 계획 48%와 현재 백색 피부 72%는 다른 값입니다. 다섯 목표 모두 합법적인 부모 사본의 실제 상속·해칭으로 달성하는 테스트를 유지합니다. 임계값은 업계 등급·분자 유전학의 정의가 아닙니다.

## 저장·성장·성능

새 개체·외부 부모·매물·배아는 유전체·고유 시드·`appearanceVersion: regional-2`를 기록하고 v11 검증에 포함합니다. 저장·불러오기에서 외형이나 RNG를 다시 추첨하지 않습니다. 이전 active/JSON은 새 게임 안내를 내고 그대로 둡니다. 명시적 새 게임 확정만 원본을 아카이브한 뒤 새 active를 기록합니다. 원래 거래 영수증을 재계산하거나 구형 유전체를 조작해 변환하지 않습니다.

모든 출력은 96×96이고 Canvas smoothing=false, CSS pixelated와 원래 카드 크기/배치·해칭50%/아성체75%/성체100%를 유지합니다. 인큐베이터의 부화 당시 해칭 이미지에도 50%를 한 번만 적용합니다.

큰 픽셀/8레이어 캐시는 32개, 작은 관찰 레코드는 4096개로 제한합니다. 이름·성별·게임 턴은 캐시 키에 들어가지 않으며 유전체+시드+파이어가 키입니다. 보유 상한 3000마리를 필터링해도 관찰 캐시가 순환 소진되지 않게 했습니다. 공개 렌더러의 반환 버퍼는 복사하여 외부 편집이 공유 캐시를 손상시키지 않습니다. 기존 전체 개체 창의 가상 목록·크레 러시 배경 동결/Worker 저장 최적화는 유지합니다.

Node 24 클라우드에서 300개 서로 다른 외형의 최초 관찰은 6,847ms, 캐시 조회는 2.61ms였습니다. 별도의 새 시드 24개 렌더는 최초 504ms, 재조회 0.25ms였습니다. 전체 개체 창은 동시에 보이는 카드만 렌더링하므로 최초 전체 관찰 시간과 화면 열기 시간은 다릅니다. 이 수치는 실제 Android 기기 측정이 아닙니다.

## 검증 결과

- 타입 검사·프로덕션 빌드·PNG/런타임 아트 해시 검사 통과.
- 전체 단위 테스트 36파일 **382개 통과**. v2 픽셀 기준100·C/S/H 전 조합·보호 구조·형제 상속·여러 세대·목표 해칭·가격·공개 정보·새 저장·구형 안내·중복 수령/급여를 포함합니다.
- 전체 모바일·PC E2E 274개 실행에서 262개가 먼저 통과했습니다. 카드 터치 보정을 제거하고 Next 경로 안내와 겹치던 alert 선택자를 수정한 최종 빌드에서 실패 12개와 연속 관리 2개를 재실행해 **14개 모두 통과**했습니다. 미해결 실패·건너뛴 시나리오는 없습니다. 전체 단일 실행 로그가 모두 녹색이었다고 주장하는 대신, 전체 실행과 수정 영역 재검증을 구분해 기록합니다.
- GitHub CI의 30개 가족 콜드 렌더 검증이 기본 5초 제한에 걸려, 해당 테스트만 30초로 조정했습니다. 검증할 가족 수·상속·가격 assertion은 그대로이며 해당 파일 11개도 재검증 통과했습니다. GitHub 전체 CI 상태는 [PR 검사](https://github.com/damyo-zip/gecko-lab/pull/31/checks)에서 확인할 수 있습니다.

## 남은 기술적 제한

96×96 단일 옆모습이므로 양쪽 핀·신체 부위는 투영 근사입니다. 조명/색소 분해와 C/S/H 복합 발현은 실제 동물의 조직·성장 중 발색을 정확히 재현한 모델이 아닙니다. 고백색의 옅은 색소 섬은 여전히 구분이 약할 수 있습니다. 장기간의 실제 브리더 관찰을 통한 표현 검증과 새로운 포즈 원화는 후속 작업입니다. 모바일 브라우저 검증은 Chromium 에뮬레이션이며 실제 Android 기기 성능과 같다고 보장하지 않습니다.
