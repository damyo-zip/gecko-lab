# 장기 플레이 기록과 전체 상점 풀

이 정책은 전체 혈통 추적을 종료하고 기록 축소를 승인한 플레이어 요청을 적용합니다. 기존 유전/외형 엔진과 이미 태어난 개체의 DNA·시드·출생·성장 규칙, 상점 가격과 급여 경제는 변경하지 않습니다.

## 활성 데이터와 완료 이력

정식 생성은 `newCurrentGame`입니다. 동결한 기존 생성기와 v2~v10 reader는 그대로 둡니다. production load/import는 먼저 원본 체크섬·스키마·상속을 검증하고, 월 규칙 이전 후 compact v1을 적용합니다. 최초 이전의 원본을 같은 IndexedDB 트랜잭션에 보관합니다.

- 보유 개체, 진행 중 교배/예약, 수거 대기·부화 중·미수령 새끼·미제거 실패 알, 구매 완료된 현재 매물은 보존합니다.
- 모든 도전 트로피와 대표 교체 후보의 알 증거를 보존합니다. 부화·판정·보상은 재실행하지 않습니다.
- 완료된 번식에서 중복 배아·관찰 로그를 제거합니다. 생존/트로피 자손에는 수정 당시 부모 유전 입력과 출생 증거를 남기고 기존 엔진으로 실제 DNA·성별·외형 시드를 재현 검증합니다. 부모의 현재 공개 지식과 진행 중 관찰 업데이트는 유지합니다.
- 필요 없는 분양·폐사 전체 개체와 먼 조상을 제거합니다. 직계 부모가 필요하면 정확한 유전 사실을 유지하되 그 조상의 부모 추적은 종료합니다. 이 사실은 보유·급여·사육장 점유에 포함하지 않습니다.
- 완료 교배·알·개체·분양은 날짜·이름·결과의 작은 요약으로 별도 키에 저장합니다. 활성 상태에는 최근 24개와 누적 수만 남깁니다. 인큐베이터의 기존 도움말/기록 창과 JSON 내보내기에서만 전체 요약을 읽습니다.
- compact 게임은 전체 혈통 F를 계산/경고하지 않습니다. Lilly·건강·잠정 복합 조합 검증과 성별·성체·은퇴·회복·예약 규칙은 유지합니다. 남아 있는 가족 정보는 불완전한 기록입니다.

완료 이력 자체는 삭제하지 않으므로 디스크 총량이 완전히 일정해지는 정책은 아닙니다. 도전 대표 후보와 많은 실제 보유 개체 역시 증가할 수 있습니다. 이전 원본/복원 아카이브는 복구용으로 유지합니다.

## DNA와 저장·Worker

한 스냅샷 안에서 동일한 불변 DNA·수정 부모 입력을 공유합니다. 공개 지식·컨디션은 독립 상태입니다. IndexedDB의 structured clone은 공유 참조를 보존합니다. 내부 active는 읽을 수 있는 v10 game+compact 형태이며 체크섬은 결정적 DNA 풀 표현으로 계산합니다. 내보내기 v11은 중복 DNA 풀과 완료 요약을 포함합니다. 모든 참조·순환·미사용 DNA·재계산한 체크섬을 가진 손상 유전체도 검사합니다. 구형 백업을 계속 읽으며 신형 백업은 이번 버전 이후에서 복원해야 합니다.

일반 load/게임 행동/전체 검증/자동 저장은 전용 Worker가 수행하고 변경 필드만 UI로 전송합니다. CAS와 게임별 크레 러시 수령 장부는 같은 트랜잭션에서 검사합니다. 확정 전 UI를 갱신하지 않으며 Worker 응답 유실 시 행동을 재실행하지 않고 새로고침을 요구합니다. Worker가 처음부터 지원되지 않으면 기존 경로를 사용합니다. 러시의 프레임 체크포인트 Worker는 유지합니다.

교배별 알 목록은 한 번 인덱싱합니다. 모프명·필터 분류·가격은 전체 입력을 키로 하는 최대 512개의 작은 결과만 캐시하며 변조 검증을 건너뛰는 캐시는 만들지 않습니다. 동일 스프라이트 픽셀의 불필요한 Canvas 재출력을 줄이고 성장 CSS 크기는 유지합니다.

## 상점

기존 부모 풀 13개를 84개 계통·무늬 후보의 결정적 순환 풀로 넓힙니다. 현재 엔진의 패턴·계통·측면 프리셋, 화이트월/화이트아웃/슈퍼스트라이프/리버스 핀/패턴리스/브린들/타이거/트라이컬러, C/S/H 동형·복합과 릴리 조합을 포함합니다. 무작위 다른 계통 부모와 독립 대립유전자 추첨으로 프리셋 밖의 조합도 열어 둡니다.

부모 유전자를 설정한 뒤 기존 `createEmbryo`가 실제 상속·성별·발달을 결정합니다. 매물의 DNA/무늬를 사후 수정하거나 이름만 붙이지 않습니다. 비생존 배아는 제외하며 잠정 복합 표현형을 단지 고급이라는 이유로 제거하지 않습니다. 고우선순위 형질이 있으면 기본 무늬는 복합 설명으로 표시될 수 있습니다. 모든 외형이 같은 빈도나 정해진 턴 안에 반드시 등장한다는 보장은 없습니다.

기존 저장의 매물은 교체하지 않고 다음 정상 재고 갱신부터 적용합니다. 최초 두 노멀 성체의 성별·가격·시드 생성은 기존과 같고 family v3만 새 풀을 사용합니다. 기존 family v1/v2는 원래 검증 계약을 유지합니다.

## 검증

단위 테스트에는 실제 완료/진행 클러치, 구형 v5/v6 백업, 분양 부모/구매 후 재분양 매물, 출생 증거 변조, DNA 풀 참조 손상, 모든 84개 상점 후보의 실제 상속/가격, Worker 변경 패치·CAS 실패·불확실 쓰기 재실행 방지를 추가합니다. 전체 기존 검증을 유지합니다. 최종 실행 결과와 측정은 PR 검증 기록에 덧붙입니다.
