# 혈통 앨범 구현

상단 혈통도 배너를 제거하고 혈통도 탭을 관심 혈통 앨범 → 선택 개체 → 3세대 가족도 → 세대 비교로 정리했습니다. 부모·조부모·후손·외형은 `game.individuals` 한 곳에서 읽습니다. 상점 구매 시 이미 보존하던 외부 부모, 판매·폐사 개체도 같은 ID로 탐색합니다. 유전 계산·표현형·가격·턴 규칙·PNG 원화는 변경하지 않습니다.

## 실제 플레이

- 컬렉션의 개체 상세에서 **영구 혈통 기록 보기**로 해당 개체를 바로 엽니다.
- **관심 혈통 등록**은 선택한 실제 개체를 시조로 지정합니다. 1~40자 가문 이름을 입력하며, 같은 시조의 중복 등록은 차단합니다.
- 관심 카드의 연필 버튼에서 이름 변경·등록 해제·해제 취소가 가능합니다. 해제는 앨범 표시만 없애며 기존 개체·알·교배의 혈통 ID를 삭제하지 않습니다. 같은 시조를 재등록하면 기존 혈통 ID를 다시 사용합니다.
- 관심 카드는 한 줄에서 두 개씩 보입니다. 세 개 이상이면 옆으로 슬라이드하며, 끝에 가까워지면 다음 카드가 자동으로 이어집니다. 목록 끝에서 새 관심 혈통을 등록해도 바로 이어서 탐색할 수 있습니다.
- 관심 카드는 시조 모습, 실제 후손 수와 최고 세대를 표시합니다. 시조 미확인 이전 이름은 후손 수 대신 보존된 기록 수를 표시합니다. 카드를 누르면 그 가문의 가장 최근 최고 세대 후손을 중심으로 엽니다. 모프·색상이 같은 다른 개체를 자동으로 가문에 넣지 않습니다.
- 가족 카드 터치로 부모·조부모로 이동하고, 아래 후손 카드로 다음 세대로 이동합니다. 화면에는 중심 개체와 부모 2마리·조부모 4마리만 표시합니다. 부모 기록이 없으면 **정보 없음**이며 허위 부모를 만들지 않습니다.
- 개체 선택 목록은 24개와 현재 개체로 제한합니다. **다른 개체 보기**의 이름/ID 검색은 보유·판매·폐사·외부 부모를 포함하며 페이지당 최대 24개만 그립니다. 후손 검색과 더 보기도 제공합니다.
- 세대 비교는 관심 시조와 선택 후손을 기본으로 사용합니다. 가문이 없다면 확인 가능한 부모와 비교합니다. 양쪽을 독립적으로 바꿀 수 있으며 수동 선택은 혈연 관계를 새로 선언하지 않습니다. 비교 개체가 부족한 쪽은 안내 상태로 표시합니다.
- 비교의 두 캔버스는 같은 크기·구도·파이어업 상태입니다. 판매·폐사 시점 이후 기록도 그대로 비교합니다. 보유/외부 부모의 나이는 교배·수명 엔진과 동일한 `현재 턴 − 부화 턴`이며, 판매/폐사 기록의 나이는 실제 당시 날짜에서 멈춥니다. 이전 시간 모델에서 보존한 부화일이 성장용 턴으로 정규화된 경우에도 현재 성체의 나이는 엔진과 일치합니다.
- 혈통도 상단 **턴 넘기기**는 공통 `EndTurnButton`과 같은 엔진을 호출합니다. 사료 부족 경고와 중복 클릭 잠금, IndexedDB 저장 후 반영을 유지합니다.
- 상세 공개 유전 정보는 기존 상세 창에서 확인합니다. 앨범에는 대표 외형 명칭과 가족 기록을 우선하며 연구 통계·진행률·잠재 형질 점수는 표시하지 않습니다. 성체 전 성별 미공개 규칙도 유지합니다.

## 저장 v8

기존 `lineages` 레코드에 `founderId`와 `favorite`만 추가했습니다. 새 개체·부모 관계나 별도 가계도 저장을 만들지 않습니다. 규칙 버전은 4를 유지합니다.

v2~v7 백업을 먼저 원래 구조와 체크섬으로 검증하고 기존 이전 경로를 거친 뒤 v8로 이전합니다. v7의 개체·유전체·외형 시드·표현형 수치·거래·매물·알·교배 기록은 그대로 보존합니다. 예전 이름의 구성원에서 실제 단일 시조가 확인되면 그 ID를 연결합니다. 복수의 무관한 시조가 있거나 확정할 수 없다면 `founderId:null`로 보존하고 **시조 기록 미확인**으로 표시합니다.

실제 IndexedDB 활성 슬롯 이전은 같은 트랜잭션으로 원본 `archive-v7-…`와 v8 활성 저장을 기록합니다. 재접속은 다시 이전하거나 현실 시간을 진행하지 않습니다. v8 스키마는 잘못된 시조 ID·유형·관계 밖 구성원·체크섬 변조를 거부합니다.

기존 기준은 `b93dee773e210a86fedf00f3802df86f5e11e254`의 실제 화면입니다. `baseline-game.json`은 실제 상점 부모로 구매한 2세대 부모를 교배해, 게임의 5% 무정란·95% 부화 판정을 통과한 3세대 자손 2마리가 있는 v7 저장입니다. 새 캡처도 같은 생물학적 기록을 사용하며 유전형·색상·부화 결과를 레퍼런스 데이터에 맞춰 조작하지 않습니다. 비교 이미지는 별도 레이블만 밖에 붙이고 캡처를 확대·축소·재도색하지 않습니다. 레퍼런스 비교의 구현 쪽은 문서의 자연 높이로 브라우저 뷰포트를 확장해 고정 탭 바가 비교 패널을 가리지 않도록 실제로 다시 캡처했습니다. 390×844·720×1280 캡처도 별도로 제공합니다.

두 카드씩 보는 가로 관심 혈통 목록·식물 배경의 큰 개체/오른쪽 정보·5열 가족 관계·2개체 비교·초록 활성 탭·턴 버튼 구조와 남색 금속 패널을 구현했습니다. 전체 스크린샷을 배경으로 붙이지 않으며 버튼·선·텍스트·캔버스가 독립적으로 작동합니다. 기존 테라리움 에셋을 재사용하고 새 아이콘은 픽셀 격자의 SVG입니다.

차이는 다음과 같습니다.

- 추가 요청에 따라 상단 혈통도 배너를 제거했습니다. 관심 혈통도 세로로 늘어나는 그리드 대신 한 줄의 가로 슬라이드를 사용합니다.

- 레퍼런스의 이름·세대·날짜·재화는 예시이므로 실제 저장값을 표시합니다. 체중·성격·등록일 데이터가 없으므로 대신 실제 부화일·나이·상태·고유 ID를 표시합니다.
- 기존 96×96 스프라이트를 그대로 사용합니다. 레퍼런스 원화와 동일한 품질·방향·포즈를 구현했다고 주장하지 않습니다.
- OS 상태 표시줄은 브라우저 앱에서 만들어 넣지 않습니다. 비교 왼쪽에는 원본의 OS 표시줄이 포함되어 있습니다.
- 360~430px에서 충분한 터치 영역과 외형 크기를 유지하기 위해 페이지는 세로로 스크롤합니다. 가족도만 내부 가로 스크롤을 사용하고 선택 개체를 가운데 배치합니다. 넓은 화면은 레퍼런스처럼 친가 조부모 / 아버지 / 현재 / 어머니 / 외가 조부모를 한 줄로 표시합니다.
- 검색·등록·관리 컨트롤, 실제 긴 ID와 다중 가문, 정보 없음·비교 부족 상태 때문에 모든 픽셀의 크기/높이가 원본과 동일하지는 않습니다. 모바일에서는 이미지가 읽히도록 비교 카드를 더 높게 유지합니다.

## 검증

타입 검사·프로덕션 빌드·아트 원본/런타임 해시 통과, 단위 **210개 / 18개 파일**와 전체 모바일·데스크톱 E2E **122개** 통과했습니다. 마지막 나이 조회 보완 후 혈통도 대상 **14개**도 추가 통과했습니다. 새 단위 검증은 실제 부모/조부모, 시조와 무관한 모프 개체 제외, 중복 등록, 등록 해제/재등록, 진행 중 배아의 혈통 전파, v7 원본 보존, 애매한 시조, 저장 손상 거부, 판매·폐사 당시 나이 및 픽셀 일치, 2,500개 기록의 검색 제한과 깊은 혈통 탐색을 포함합니다.

모바일/데스크톱 실제 Chromium에서는 360·390·430px 넘침 검사, 카드·버튼 44px, 7노드의 렌더러 픽셀 해시, 가족 재선택, 관심 관리의 새로고침 유지, 조상/후손 비교 및 양쪽 검색, 컬렉션 바로 열기, 사료 경고·중복 턴, 실제 v7 원본 아카이브와 JSON 복원, PWA 오프라인을 확인합니다. 기존 유전학·교배·5세대·상점·인큐베이터·원화 검사는 유지합니다.

상단 배너 제거와 관심 카드 가로 슬라이드의 추가 검증은 실제 360·390·430px 터치 이동·카드 열기/관리, 화면 가로 넘침 없음, 8개 초과 자동 이어 보기 및 목록 끝에서 아홉 번째 등록, 스와이프 전후 저장 상태 일치를 포함합니다.
