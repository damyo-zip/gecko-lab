# 자동 브리더 칭호

컬렉션 대표 패널 좌상단의 기존 `Gen | 세대 | 연필` 상자를 플레이어의 브리더 칭호로 교체한다. 기존 픽셀 프레임·배경·위치·높이를 재사용하고 텍스트에 맞춰 폭만 결정한다. 선택 개체의 세대는 기존 상세 정보 행과 카드에 그대로 남는다. 이름 수정은 기존 이름/상세 버튼을 사용한다.

| 서로 다른 도전 완료 수 | 표시 칭호 |
| --- | --- |
| 0 | 견습 브리더 |
| 1 | 신예 브리더 |
| 2 | 모프 탐구가 |
| 3 | 혈통 설계자 |
| 4 | 모프 마스터 |
| 5 | 전설의 브리더 (금색) |

`game/hardcore/breeder-rank.ts`의 공통 함수는 기존 `breedingChallenges.completed`에 저장된 유효한 목표 ID를 Set으로 집계한다. 별도 등급/경험치/카운터/장착값을 새로 저장하지 않는다. 목표의 부화 성공 기록이 추가되면 현재 칭호도 즉시 재계산된다. 목표 선택/10턴 잠금/부화 판정/보상/유전 엔진은 변경하지 않는다.

개체 선택·판매·폐사·목표 변경은 완료 기록을 삭제하지 않으므로 칭호에 영향이 없다. 저장과 재접속은 기존 기록을 그대로 사용하며, 기존 새 게임 기능은 완료 기록이 없는 새 게임을 생성하므로 견습 브리더로 초기화된다.

과거 `equippedTitle`, 목표별 보상 `titleId` 및 호환 행동은 구세이브/기존 클라이언트와의 호환성을 위해 보존한다. 이 값들은 현재 브리더 등급에 영향을 주지 않는다. 과거 수동 장착 UI와 대표 이미지 아래쪽 칭호는 제거한다. 기존 도전 목록과 성공 팝업도 자동 승급 안내와 동일한 현재 칭호를 사용하며 별도 팝업을 만들지 않는다.

검증:
- 관련 단위 **19개 통과**: 실제 교배·수거·부화로 도전 0~5개를 완료한 유효 세이브, 중복 ID 집계 방지, 과거 장착값 무시, 저장·복원, 성공 개체 판매·실제 폐사, 목표 변경 및 새 게임 초기화.
- 관련 모바일·PC E2E **20개 통과**: 모든 등급의 360/390/430px 배치, 금색 강조, 잘림·패널/ID 겹침 없음, 대표 이미지 크기 유지, 실제 부화 직후 승급, 과거 기록/재접속/개체 선택/판매/실제 새 게임, 기존 목표 잠금·홈 관리·공통 UI 회귀.
- 타입 검사, 프로덕션 빌드, 원본 아트 PNG/런타임 해시 검사 통과. 변경과 무관한 전체 테스트는 반복하지 않았다.
- 브라우저의 모바일 터치 환경에서 확인했으며 실제 스마트폰 하드웨어 검사는 수행하지 않았다.
