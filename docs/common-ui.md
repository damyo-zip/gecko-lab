# 컬렉션 기준 공통 상·하단 UI

컬렉션·인큐베이터·혈통도·상점은 동일한 `HomeHeader`와 `HomeFooter`를 공유합니다. `HardcoreHub`에서 각 영역을 한 번 렌더링하고 중앙 콘텐츠만 전환합니다. 화면별 헤더·내비게이션 CSS와 개별 턴 버튼을 제거했습니다.

컬렉션의 기존 로고·자원 2행·프레임·폰트·아이콘·녹색 턴 버튼·활성 탭 스타일과 반응형 치수를 공통 CSS로 옮겼습니다. 턴 버튼은 콘텐츠 길이에 따라 움직이지 않도록 탭 바 위에 항상 배치합니다. 기존 혈통도 상단의 턴 버튼도 이 하단 영역으로 이동했습니다. 각 탭의 개체·슬롯·가족·매물 카드와 기능은 유지합니다.

## 레이아웃과 기존 동작

- `reference-chrome.css`: 컬렉션 기준 치수의 단일 원본. `100dvh` 높이의 3행 Grid, `minmax(0,1fr)` 중앙 스크롤, 상·하·좌·우 안전 여백.
- `home-footer.tsx`: 같은 턴 버튼과 4개 탭을 한 번 렌더링. 탭 전환 시 DOM을 유지하고 활성 표시만 갱신. 저장 로딩 중에도 같은 크기의 비활성 버튼을 표시.
- `hub.tsx`: 탭 변경 시 중앙 스크롤 위치만 초기화. 긴 컬렉션·혈통도·부화 기록은 중앙에서 스크롤하며 상·하단을 밀지 않음.
- `EndTurnButton`, `useHardcore`, 유전·교배·성장·경제·저장 모델은 그대로 사용. 사료 경고, 저장 전 비활성화, 중복 클릭 잠금, 동적 금액·먹이·턴·날짜와 JSON 복원을 유지.
- PWA 셸 캐시만 `shell-15`로 갱신. 저장 버전은 v9 그대로이며 데이터 마이그레이션은 추가하지 않음.

## 검증 범위

실제 Chromium 모바일 터치 에뮬레이션에서 360×800·390×844·430×932·360×640과 가로 844×390을 검사합니다. 상단 44px·하단 34px·좌우 20px 안전 여백을 CSS로 시뮬레이션하며, 긴 실제 콘텐츠 스크롤 전후에도 헤더·자원·로고·턴 버튼·탭과 아이콘의 좌표·치수·패딩·간격·글자 크기가 같아야 합니다. 데스크톱 720×1280·1280×900에서도 같은 검사를 수행합니다.

가로로 넓고 500px 이하로 낮은 화면에서는 공통 세로 배율만 줄여 안전 여백과 하단 버튼이 화면에 들어가게 합니다. 낮은 화면이나 긴 콘텐츠는 중앙 스크롤을 사용합니다. 실물 기기와 Safari는 이번 환경에서 검사하지 않았으며, 안전 영역 검사는 브라우저 CSS 시뮬레이션입니다.
