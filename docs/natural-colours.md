# 자연 발색 팔레트 v2

실제 게임에서 사용 중인 B-ORIGIN-01의 몸색·무늬색 범위를 넓힌다. 원화, 96×96 해상도, 명암, 보호 픽셀, 무늬 생성기와 달마시안의 검은 점은 그대로 사용한다. UI와 성장 단계별 크기도 유지한다.

## 색과 상속

- 몸색: 기존 다유전자 기록의 red·orange·brightness 점수를 버전 2의 어두운색/중간색/밝은색 팔레트에 연속 매핑한다. 차콜, 초콜릿, 회보라 기가 약한 회색, 올리브, 벅스킨, 노랑, 살구, 오렌지, 적갈색 계열이다. 기존 63좌위의 생성·상속·RNG는 바꾸지 않는다.
- 무늬색: `patternColour`의 게임 전용 정량 보정 사본 6쌍을 별도로 상속한다. 각 사본은 0~4, 미기록 사본은 null이다. 흰색/아이보리/크림/버터 옐로/살구/주황 사이에서 보간한다. 기존 cream은 면적, orange는 기존 삼색의 별도 주황 재질을 계속 담당한다.
- 새로운 시조의 보정 사본은 독립된 난수 도메인에서 생성한다. 자손은 좌위마다 아버지와 어머니에게서 한 사본씩 전달받으며 돌연변이나 부화 시 재추첨은 없다. RGB 자체나 모프 이름을 상속하지 않는다.
- 미기록 사본은 화면에서만 중립 크림 값(사본당 1.5, 전체 0.375)으로 표현한다. 저장·유전에서는 null을 보존하므로 예전 부모끼리의 새 자손에게 알려지지 않은 색 DNA를 만들어 넣지 않는다. 새로운 혈통과 교배하면 기록된 사본을 전달받는다.
- Lilly의 흰 베일, Axanthic의 색 억제, 복합 모프의 기존 재질 처리는 기존 합성기에서 마지막까지 적용한다. 발색 up/down도 같은 버전의 결정적 색 변환이다.

이 보정 사본과 수식은 **가상의 게임 모델**이다. 실제 크레스티드 게코에서 확인된 독립 유전자나 정확한 유전 확률이라는 뜻이 아니다. RGB 역시 실물 사진에서 계측한 값이 아니다.

참고한 실물 색 계열: [The Gecko Geek 가이드](https://thegeckogeek.com/blog/crested-gecko-morph-guide/), [LIL MONSTERS 가이드](https://lmreptiles.com/cg-img/). 라벤더·올리브는 낮은 채도로 제한하며 실제 발색은 조명·상태에 따라 달라진다.

## 저장 호환

`ForgeGenetics`의 선택적 `paletteVersion: 2`, `patternColour`와 교배 당시 `Mating.genetics.paletteVersion`만 추가한다. IndexedDB 구조·저장 버전은 변경하지 않는다.

- 버전 표시가 없는 기존 개체, 보유 개체, 매물, 부모 기록은 이전 재질 매핑을 사용한다. 로드 시 재색칠하거나 유전체를 변경하지 않는다.
- 이미 수정된 배아는 저장된 교배 버전으로 검증·부화한다. 업데이트 전 수정된 알은 업데이트 후에도 이전 색을 유지한다.
- 업데이트 후 새로운 매물과 새로 시작한 교배부터 v2를 사용한다. 예전 부모의 다음 교배도 몸색 매핑은 v2이며 무늬의 미기록 사본은 null을 상속한다.
- 부모 사본·교배 버전·확정 자손 기록을 기존 검증 경로에서 검사한다. 지원하지 않는 버전이나 잘못된 사본은 거부한다.
- 기존 거래 가격·시장 가격표·게임 규칙·시간·번식 성공률·건강 상속은 변경하지 않는다. 과거 도전 완료 기록은 원래 개체 버전으로 검증한다.

## 검토 자료와 재현

`tests/fixtures/natural-colours/previous-backup.json`은 변경 전 main(b7205bb)의 실제 게임 팩토리로 만든 합성 저장본이다. 보유 개체·실제 부모·매물·수정된 알을 포함하며 20개 고유 개체의 이전 픽셀 SHA-256을 함께 고정했다. 사용자 저장 데이터가 아니다.

`tests/natural-colours.test.ts`는 이전 저장본의 정확한 왕복·20개 픽셀 해시·업데이트 전 알의 부화·다음 교배의 버전·기존 유전체 상속·독립된 색 사본 상속·검은 점과 보호 픽셀을 검증한다. 기존 Forge 원본 62파일과 순수 렌더러 회귀 검증도 유지한다.

다음 명령은 실제 새 어댑터로 6모프 × 12시드의 전후 출력을 만든다. 비교용 패턴 프리셋에 실제 상점 부모의 합법적인 색 사본을 대입했으며, 재질 RGB를 수동 지정하지 않았다. 같은 원화·시드·무늬에서 색 변화만 비교한다.

```sh
PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node scripts/render-natural-colours-report.mjs
```

결과: [전후 비교 PNG](natural-colours/six-morphs-twelve-seeds.png), [72개 픽셀·재질 검증 기록](natural-colours/report.json). 모든 샘플의 알파·보호 픽셀·점/핀/흰색 마스크 및 검은 점 픽셀이 동일하다. 기존 Forge 코드·원화는 덮어쓰지 않는다.

`e2e/natural-colours.spec.ts`는 360/390/430px 및 PC에서 실제 컬렉션·상점·부모 팝업의 캔버스 픽셀, nearest-neighbor 표시, 터치, IndexedDB 백업 복원과 새로고침을 검증한다. 이전 실제 저장본의 브라우저 복원도 별도로 검사한다.

## 제한

기존 개체는 의도적으로 이전 색을 유지한다. 새 팔레트의 끝 색은 선별 교배로 강한 색 형질을 모았을 때 나타나며 매물마다 승인된 샘플 12색이 모두 즉시 출현하는 것은 아니다. 유전 억제 모프는 재질 색보다 해당 모프의 기존 표현이 우선한다. 사용자 실물 기기의 KakaoTalk WebView 색 재현은 자동 브라우저 검증 범위 밖이다.
