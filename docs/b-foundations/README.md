# B 바디 베이스 분리 실험

경로: **`/lab/appearance/b-breeding/bases`**. B 모프 비교 화면의 **현재·약한 패턴·패턴리스 바디 비교** 링크로도 접근합니다. 내부 바디와 최종 노멀 표현형을 구분하는 개발용 실험이며 정식 게임에는 적용하지 않습니다.

## 원인과 비교 조건

직전 B는 `A.cream`으로 표시한 원화 크림 픽셀을 초기 재질로 사용합니다. 노멀의 무늬가 원화 바디에 포함되어 있어, 아잔틱·카푸치노·세이블에서 팔레트를 바꿔도 그 모양이 공통으로 남습니다. 색을 낮추는 것만으로는 패턴 경계를 제거할 수 없고, 무늬 경계를 그림자로 재사용해도 비슷한 흔적이 남습니다.

이번 실험은 다음 세 바디를 비교합니다.

- **현재 방식**: 원화의 크림색 무늬를 그대로 포함한 바디.
- **약한 패턴**: 등·측면의 바탕 색소 대비를 재질 팔레트에서 26%로 낮추고, 분리한 구조 명암을 사용한 바디. 반투명 덮어씌우기는 사용하지 않습니다.
- **패턴리스**: 등·측면의 원화 색소 경계를 제거하고, 같은 구조 명암을 사용한 바디.

내부 바디 행은 같은 일반 체색으로 고정하며, 추가 일반 패턴과 모프가 없습니다. 아래 최종 모프 표는 같은 60좌위 배경·시드·모프 계수에 **동일한 별도 일반 패턴 레이어**를 사용합니다. 따라서 최종 노멀은 패턴리스로 강제되지 않습니다. 밝음·어두움·저/고발현·시드를 바꿔도 세 열의 비교 조건은 함께 변경됩니다. 내부 바디 행은 바뀌지 않습니다.

공정한 바디 비교를 위해 일반 패턴의 위치·범위를 세 열 모두 동일하게 적용하므로, '현재 방식' 열의 최종 출력이 직전 B의 최종 결과와 완전히 같지는 않습니다. 직전 결과를 현재 결과인 것처럼 바꾸어 놓지 않았으며, **직전 B 실험의 정확한 결과 확인**에서 수정하지 않은 경로를 같은 유전체·시드로 나란히 확인할 수 있습니다. 기존 B 화면의 18개 모프/발현 결과도 변경하지 않았습니다.

## 그림을 유지한 범위와 재구성한 범위

원본 B PNG에는 진짜 조명 전용 레이어가 없습니다. 단순한 역산으로 완벽하게 분리했다고 주장하지 않습니다.

몸통 색소 제거 마스크는 660픽셀입니다. 얼굴·눈·크레스트·몸통 외곽선·팔다리·꼬리는 마스크 밖에 두고 **픽셀 그대로** 유지합니다. 몸통 내부에서도 목/사지 접합부와 배 아래의 어두운 구조선은 보존합니다. 따라서 이 실험의 패턴리스는 '등·측면의 색소 무늬 제거'를 뜻하며, 얼굴·다리·꼬리 장식까지 없는 전신 패턴리스 분류를 뜻하지 않습니다.

몸통 내부에서는 등→배 깊이와 같은 색소 안의 미세 밝기 차이로 6단계 명암을 재구성합니다. 주변 밝기를 분석할 때도 크림과 갈색을 섞어 평균내지 않아, 색소 경계를 피부 요철로 잘못 남기지 않도록 했습니다. 이것은 출력 블러가 아니며 출력 픽셀은 모두 불투명/투명으로 결정됩니다. 원화와 동일한 모든 몸통 조명을 복구한 것은 아니고, 색소와 구조를 나누는 B 전용 근사입니다.

동일한 재구성 명암 단계끼리 원화 무늬 영역과 바탕 영역의 밝기 차이를 비교한 결과:

| 내부 바디 | 무늬·바탕 평균 명도 차이 | 몸통 명도 범위 |
| --- | ---: | ---: |
| 현재 | 75.27 | 173.14 |
| 약한 패턴 | 15.16 | 118.90 |
| 패턴리스 | 0.00 | 109.29 |

패턴리스에서도 명도 범위가 109이며 6개 명도 단계가 남습니다. 패턴 색소의 대비는 없지만 몸의 입체감까지 단색으로 없애지 않았습니다. 현재 바디의 더 큰 범위에는 크림색 무늬 자체의 대비도 포함되므로, 이 숫자를 단독으로 그림 품질 점수처럼 해석하면 안 됩니다.

## 관찰 및 판단

- **바탕 무늬 간섭**: 패턴리스가 가장 적습니다. 일반 발현 노멀에서 별도 패턴을 올린 뒤 남는 원화 몸통 무늬가 현재/약한 베이스는 138픽셀, 패턴리스는 0픽셀입니다. 약한 베이스는 그 138픽셀의 색소 대비가 낮을 뿐 모양 자체는 남습니다. 얼굴·사지·꼬리 무늬는 이 수치의 대상이 아닙니다.
- **모프별 차이**: 하이웨이는 옆구리의 기존 크림 덩어리가 줄면서 등 띠가, 세이블은 기존 할리퀸 흔적이 줄면서 밝은 머리·등 군집이 더 구분됩니다. 카푸치노도 몸통의 공통 무늬에 덜 끌리지만 꼬리 기부·끝은 세 베이스에서 같은 표현입니다. 릴리의 백색이 덮는 부위는 원래부터 바탕 차이가 작고, 남은 갈색 부분에서 차이를 봐야 합니다.
- **노멀 감상**: 패턴리스 내부 바디만 보면 기존보다 수수합니다. 최종 노멀에는 유전·시드에 따른 밝은 군집을 별도로 올려 감상 포인트를 남겼습니다. 현재 바디가 가장 익숙하고 풍성하게 느껴질 수 있고, 약한 바디는 그 흔적을 일부 보존하는 절충안입니다.
- **확장 방향**: 내부 구조로는 **패턴리스 바디 + 별도 일반 패턴 + 모프별 표현**이 가장 분리하기 쉽다고 판단합니다. 이미 그려진 원화 무늬를 상속된 무늬처럼 취급할 필요가 없어집니다. 다만 이것은 이번 비교에 근거한 방향 제안이지 정식 채택이나 객관적인 미적 우열 확정이 아닙니다.

일반 패턴을 꺼 보면 패턴리스의 최종 노멀은 내부 바디와 정확히 같아집니다. 켜면 다른 결과가 됩니다. 이 대조로 '내부 바디를 패턴리스하게 만들기'와 '플레이어의 노멀을 민무늬로 강제하기'가 분리되었는지 확인할 수 있습니다.

## 코드 및 검증

- `src/lab/appearance/b-breeding/foundation.ts`: 마스크·구조 명암 주석·세 바디 설정.
- `foundation-study.ts`: 동일 조건의 바디/최종 모프 비교 어댑터.
- `render.ts`: 기존 렌더링 커널의 실험용 인자. 인자 없는 기존 B 출력은 그대로이며 색소 기원 추적을 추가했습니다. 새 렌더러를 복제하지 않았습니다.
- `src/app/lab/appearance/b-breeding/bases/`: 비교 화면. 공유 Canvas와 기존 카드 스타일을 사용합니다.
- `scripts/b-foundation-report.mjs`, `tests/b-foundation.test.ts`, `e2e/b-foundation.spec.ts`: 산출물·회귀·브라우저 검증.

2026-10-17 검증: 타입 검사·프로덕션 빌드·두 종류의 원본 아트 해시 확인 통과. 전체 단위 **417개**(신규 8개 포함), 관련 모바일/PC E2E **44개**(신규 10개 포함)가 모두 통과했습니다. 직전 B의 사전 기록 18개 픽셀 해시, 6모프×3바디×12시드, 외부 부위 픽셀 불변, 색소 대비 감소와 몸통 명암, 모프별 발현 유지, 유전체/저장/가격/정식 픽셀 비변경을 확인했습니다.
