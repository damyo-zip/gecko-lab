# 모프 외형 생성 프로토타입 — regional-prototype-1

**후속 비교:** 현재 `/lab/appearance`는 이 문서의 v1 출력을 보존하면서 정식 / v1 / 명암 개선 v2를 함께 표시합니다. 아래는 최초 v1 개발 기록이며, 후속 변경·측정·최신 검증은 [regional-prototype-2 명암 개선](appearance-relief.md)에 정리했습니다. 기존 v1 PNG·JSON은 덮어쓰지 않았습니다.

개발 경로 **`/lab/appearance`**에서 확인합니다. 정식 `/`, 컬렉션·상점·교배·인큐베이터·혈통도에는 연결하지 않았습니다. 아직 정식 통합용 패치가 아닙니다.

## 비교 방법

- 6개 대조군(노멀, 릴리화이트, 아잔틱, 카푸치노, 하이웨이, 세이블)에 **같은 다유전자 60좌위·같은 외형 시드**를 공급하고 멘델 모프 좌위만 변경합니다.
- 각 쌍 왼쪽은 정식 `specimen → renderSprite`, 오른쪽은 독립 프로토타입입니다. 노멀 대조군에서도 새 재질·조명 분리의 영향을 확인할 수 있습니다.
- 공통 유전 배경에서 저발현·일반·극단 고발현·어두운 명도·밝은 명도를 선택합니다. 밝음/어두움 두 배경은 명도 사본만 다릅니다. 발현 단계는 직접 렌더러 강도를 덮어쓰는 슬라이더가 아니라 **기존 모델에서 허용되는 대립유전자 사본의 예제**입니다.
- 3단계 갤러리와 릴리 아잔틱·프라푸치노·릴리 세이블·아잔틱 하이웨이를 추가 비교할 수 있습니다. 모든 비교에 공통 시드·파이어 상태를 적용합니다.
- 예제의 사본 분포는 극단을 비교하기 위한 것이며 실제 개체군 분포, 발현 등급, 교배 확률을 뜻하지 않습니다. 예제 개체는 상점·자손·컬렉션에 등록하지 않습니다.

## 구조와 정식 경로 격리

`기존 Genome → prototypePhenotype → 부위별 재질/패턴 → 원화 질감·조명 → 96×96·8레이어`

`src/prototype/appearance`는 기존 멘델·다유전자 모델을 읽습니다. 상속·돌연변이·건강·공개 지식의 규칙을 바꾸지 않습니다. 단일 C/S/H 사본만 시각 모델링하며 두 복합 변이 사본은 미구현 오류를 반환합니다. 비생존 Lw/Lw를 정상 외형 예제로 렌더링하지 않습니다. 릴리 극단 예제도 n/Lw이며 몸통에 작은 색소 섬을 유지합니다.

정식 게임에서 프로토타입으로 향하는 import가 없으며 이를 테스트합니다. 저장소·IndexedDB·가격·명칭·브리딩 도전 함수는 프로토타입 렌더러가 호출하지 않습니다. `regional-prototype-1`은 실험 출력 버전일 뿐, 저장의 `appearanceVersion` 열거값에 추가하지 않았습니다. 계산된 강도를 별도 저장하지 않습니다.

## 원화·조명과 측정의 한계

원본 PNG·컴파일된 아트 데이터는 변경하지 않았습니다. 실제 눈 66픽셀은 원화 그대로이며, 콧구멍·입선은 현재 자세에 주석을 붙인 작은 마스크입니다. 원본 96×96의 단일 실루엣·해상도·자세 한계는 그대로입니다.

원화의 국소 픽셀 질감과 부위별 조명을 이용해 색소를 합성합니다. 원래 노멀의 어두운 패턴을 전부 그림자로 취급하는 문제는 줄였지만 완벽한 알베도/노멀맵 분해는 아닙니다. 정식 아트 수준의 새로운 손그림이나 정확한 해부학적 머리·꼬리 모델을 제작한 것은 아닙니다.

화면과 JSON의 백색 면적은 새 재질 마스크/구조 제외 피부 기준입니다. 정식 도전의 `creamArea`, 실제 전신 피복률, 업계 품질 등급과 동일하지 않습니다. 일반 크림 무늬와 이 프로토타입의 추가 백색 재질도 구분합니다.

## 정식 통합 전에 필요한 결정

1. 실제 브리더와 Highway/Sable·복합 모프·극단 Lilly의 외형 적절성을 검토하고 추가 사진 근거를 확보.
2. 실험 버전과 기존 `legacy-1`/`5.0`/`patterns-1`을 분리하는 정식 외형 버전 설계. 기존 개체·부모 스냅샷·이미 수정된 배아의 표현 경로는 보존.
3. 새 부위별 관찰값에 대한 명칭·가격·도전 기준을 각각 재검토. 현재 측정값을 기존 `creamArea` 자리에 그대로 넣지 않음.
4. 성장 중 색 변화, 현재 옆모습 투영의 한계, 꼬리·얼굴 주석을 개선할 원화/마스크 계약 검토.

통합은 별도 작업입니다. 이 프로토타입을 생성/열람하는 것만으로 기존 플레이어의 데이터나 정식 계산 결과가 바뀌지 않습니다.
