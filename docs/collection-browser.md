# 6마리 컬렉션 슬라이드와 전체 목록

컬렉션 중앙은 현재 화면 높이에 맞춰 대표 개체와 3열 × 2행의 카드 6개를 표시합니다. 아래로 스크롤하지 않아도 공통 턴 버튼과 하단 탭이 보입니다. 카드 영역을 좌우로 밀면 다음 6마리로 이동하며, 페이지 번호와 이전/다음 버튼으로도 이동할 수 있습니다. 마지막 페이지는 남은 실제 개체 수만 표시합니다. 모프·성장 단계·정렬 조건이 바뀌면 첫 페이지로 돌아갑니다.

기본순 오른쪽의 기존 보기 버튼은 **전체 개체 목록** 팝업을 엽니다. 팝업의 개체 목록만 세로로 스크롤하며 배경 컬렉션은 움직이지 않습니다. 실제 개체의 스프라이트·이름·모프·세대·성장 단계·공개 성별·분양 예상가를 표시합니다. 개체를 누르면 기존 상세 화면과 확인 후 분양 절차를 이용합니다.

## 검색·정렬·필터

- 이름 또는 고유 ID로 검색합니다.
- 기본순·이름순·세대순·하트순·가격 높은순·가격 낮은순을 지원합니다.
- 기존 모프/표현형 필터와 성장 단계, 공개 성별로 필터링합니다. 성별이 아직 공개되지 않은 새끼는 **미구분**이며 숨은 성별을 필터로 추측할 수 없습니다.
- 팝업을 열 때 홈의 모프·성장 단계·정렬을 복사합니다. 팝업 내부의 추가 검색·필터는 홈을 변경하지 않으며 **필터 초기화**로 전체 기본 목록을 봅니다.
- 분양 예상가는 기존 상세 화면과 동일한 `valueGecko(g).sell`입니다. 가격표나 거래 기록을 변경하지 않으며 실제 거래는 기존 확인 절차를 거칩니다.

## 구현과 보존 범위

| 파일 | 역할 |
| --- | --- |
| `src/components/hardcore/collection.tsx` | 기존 홈 데이터·대표 개체·관리 UI와 새 목록 연결 |
| `collection-pages.tsx` | 네이티브 가로 스크롤/스냅, 6마리 페이지, 활성 페이지 접근성 |
| `collection-catalog.tsx` | 세로 목록 팝업, 검색·필터·상세 진입 |
| `collection-query.ts` | 동일한 실제 명칭·공개 정보·정렬·분양가 조회 |
| `src/app/collection-browser.css` | 공통 헤더/하단을 유지하는 화면 높이 배분과 목록 스타일 |
| `public/sw.js` | PWA 셸 캐시 `shell-16` |
| `e2e/collection-browser.spec.ts` | 실제 터치, 목록 가격·필터, 기존 분양·저장 회귀 검사 |

홈에서는 활성 페이지와 인접 페이지의 Canvas만 유지하여 최대 18마리만 렌더링합니다. 목록은 처음 24개를 표시하고 스크롤 끝에서 24개씩 추가하며 수동 더 보기 버튼도 제공합니다. 이미 불러온 목록 행은 유지합니다. 명칭·가격의 WeakMap 캐시는 불변 개체 객체에만 연결하며 저장 데이터에는 쓰지 않습니다.

저장 v9, 개체 ID·유전형·표현형·혈통·가격 계산·게임 턴·교배·산란·부화 규칙은 기존 시스템을 그대로 사용합니다. UI 조건 변경과 페이지 이동만으로 게임 저장이 변경되지 않는지 전체 데이터 비교로 확인합니다. 기존 2열 보기/세로 더 보기 E2E는 새 실제 슬라이드·목록 조작으로 갱신했으며, 기존 검사를 삭제하거나 건너뛰지 않았습니다.
