# 8개 브리딩 도전

현재 도전 상태는 version 2, 외형 판정은 evaluatorVersion 3입니다. 원화·유전·외형 렌더러를 바꾸지 않고 현재 Forge의 실제 파이어 업 출력에서 측정합니다. 판정은 생물학적 품질 기준이 아닌 이 게임의 기준입니다.

## 인정 범위

색은 96×96 최종 RGBA에서 원화의 highlight/base/shadow를 한 번 역산해 측정합니다. 눈·윤곽 등 보호 영역과 검은 점은 체색 분모에서 제외합니다. 옆구리 면적은 원화의 좌우 옆구리 투영 영역(labels 3/4), 릴리의 흰 면적과 타이거의 줄 면적은 전체 보이는 몸 영역을 기준으로 합니다. 보이지 않는 반대쪽 몸이나 실제 전신 품질을 추정하지 않습니다.

- 밝기 Y = 0.2126R + 0.7152G + 0.0722B (0~255); 채도 S = (max−min)/max.
- 흰색: RGB 최솟값 ≥200, 채널 차이 ≤60.
- 빨강: 색상각 350~360° 또는 0~18°, S ≥35%, Y 60~200.
- 주황: 색상각 18~48°, S ≥40%, Y ≥80.
- 크림: 흰색 또는 색상각 18~70°·S <40%·Y ≥165. 주황과 크림을 같은 픽셀로 중복 계산하지 않습니다.
- 황금: 색상각 35~70°, S ≥35%, Y 95~210.
- 커피빛: 색상각 10~75°, S ≥8%, Y 80~205, 흰색 제외.
- 노출된 바탕: 실제 body 재질이고 핀·화이트·슈퍼스트라이프 밴드가 덮지 않은 픽셀.
- 선명한 검은 점: 최종 spotMask의 분리된 연결 성분에서 Y ≤70인 픽셀이 있고, 주변 2픽셀 이내의 실제 몸 픽셀보다 Y가 18 이상 낮을 것. 점 개수는 최대 48. 머리·몸·꼬리 분포는 실제 보이는 점 성분으로 셉니다.

| 목표 | 필수 조건 (모두 만족) |
|---|---|
| 릴리화이트 달마시안 | 릴리 발현, 베일 ≥90%, 흰색 ≥60%, 선명한 검은 점 ≥40개, 머리·몸·꼬리 각각 ≥3개 |
| 할로윈 | 릴리·아잔틱·복합 발현 없음, 어두운 옆구리(Y ≤75) ≥18%, 주황 ≥25%, 크림 ≤15%, 실제 주황/바탕 평균 밝기 차이 ≥40 |
| 레드 트라이컬러 할리퀸 | 릴리·아잔틱·복합 발현 없음, 옆무늬 ≥45%, 노출된 붉은 바탕 ≥12%, 주황 ≥16%, 크림 ≥16%, 실제 세 색 평균 RGB 사이 최소 거리 ≥35 |
| 세이블 릴리화이트 | 세이블 1사본·릴리 발현, C/H/아잔틱 제외, 짙은 옆구리(Y ≤190) ≥10%, 흰색 ≥25%, 흰색/비흰색 평균 밝기 차이 ≥45 |
| 골드 타이거 | 릴리·아잔틱·복합 발현 없음, 노출 황금 바탕 ≥40%, 실제 tiger 분류, 5픽셀 이상 트랙 ≥3개, 바탕보다 Y가 25 이상 어두운 최종 줄 면적 ≥4% |
| 레드 슈퍼달마시안 | 릴리·아잔틱·복합 발현 없음, 노출된 붉은 바탕 ≥55%, 선명한 검은 점 ≥40개, 머리·몸·꼬리 각각 ≥3개 |
| 프라푸치노 | C 1사본·릴리 발현, S/H/아잔틱 제외, 커피빛 옆구리 ≥10%, 흰색 ≥25%, 흰색/비흰색 평균 밝기 차이 ≥30 |
| 트라이컬러 슈퍼스트라이프 | 릴리·아잔틱·복합 발현 없음, 현재 렌더러의 연결/대비 슈퍼스트라이프 판정과 풀 핀, 노출 어두운 바탕(Y ≤100) ≥12%, 주황 ≥15%, 크림 ≥15%, 실제 세 색 평균 RGB 사이 최소 거리 ≥35 |

현재 슈퍼스트라이프 판정은 핀 연결 ≥90%, 밴드 ≥16픽셀, 중앙줄 피복 ≥85%, 최장 연결 ≥80%, 중앙줄과 양옆 대비 ≥30입니다. 기존 렌더러의 판정을 그대로 재사용합니다. 같은 시드나 모프 이름 문자열의 일치는 요구하지 않습니다. hidden carrier나 표시 명칭만으로 성공시키지 않습니다. 각 예시도 같은 판정기를 통과/탈락해야 표시됩니다.

## 보상과 기록

- 선택 후 실제로 부화한 성공 개체만 인정. 매물 구매·과거 개체 검색·수령은 새 달성이 아님.
- 최초 달성당 150,000원 + 사료 30개. 8개 완주 시 추가 300,000원. 전부 합하면 1,500,000원 + 사료 240개.
- 2/4/6/8개 누적 완료마다 무료 급여가 1/2/3/4마리분. 급여는 기존 하트 우선순위와 턴 시작 순서를 유지하므로 부화 턴에 소급 면제하지 않음.
- 칭호는 0~1 견습 / 2~3 모프 탐구가 / 4~5 혈통 설계자 / 6~7 모프 마스터 / 8 전설. 8개에만 완주 금색 표시.
- 부화·지급·달성·트로피 등록은 기존 한 번의 게임 저장에 포함. 실패한 저장이나 오래된 창의 CAS 충돌은 화면/보상에 반영하지 않음.
- 같은 클러치 두 알이나 다음 교배의 성공은 보상을 재지급하지 않고 알 ID만 성공 목록에 추가. 완료한 목표도 다시 선택 가능. 그 목록 중 대표를 선택하고 전체 성공 기록은 유지.
- 대표의 외형·부모·부화 당시 이름은 변경하지 않는 알 기록에서 조회. 보유 슬롯·급여 대상·복제 개체를 추가하지 않음. 판매·폐사에도 기록 유지.

## 이전 게임

사용자의 승인에 따라 이전 version 1 도전 상태만 production load/import에서 새 기본 목표 상태로 초기화합니다. 개체·알·혈통·자금·사료·턴·상점·Rush 등 다른 값은 그대로이며, 유전 정보나 배아를 다시 생성하지 않습니다. 원본 백업의 체크섬과 구조를 먼저 검증하고 초기화하며, 활성 IndexedDB 교체는 기존 트랜잭션/아카이브를 사용합니다. 원본 reader와 이전 5개 판정·테스트는 회귀 검증을 위해 남깁니다. 새 게임은 릴리화이트 달마시안이 기본 선택된 version 2 상태로 시작합니다. 기본 선택은 initialSelection=true이며 잠금이 없습니다. 다른 목표를 선택하면 initialSelection=false, 선택 턴+5까지 잠기고 성공 시 즉시 풀립니다. 같은 목표를 다시 누르거나 새로고침해도 잠금을 다시 시작하지 않습니다. 이전 미선택 게임은 기존 상태를 유지하다 새 목표 선택 시 version 2가 됩니다.
