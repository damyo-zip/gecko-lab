# 새 96px 게코 베이스 탐색

**`/lab/appearance/bases`**에서 비교합니다. 기존 `/lab/appearance` 상단에 진입 링크가 있습니다. 기존 원화 보강 후보 A/B/C와는 다른, 실루엣부터 새로 제작한 **base-study-1**입니다. 정식 게임과 이전 비교 화면은 유지합니다.

## 후보의 차이

| 후보 | 중심 디자인 | 작은 화면에서의 장점 | 남는 과제 |
|---|---|---|---|
| A · 동글 친화형 | 큰 눈과 둥근 머리, 짧은 몸통, 넓은 발, 감긴 꼬리 | 48px에서도 얼굴과 표정이 먼저 보임 | 큰 머리에 비해 몸통이 짧아 정교한 측면 무늬 공간은 작음 |
| B · 브리딩 감상형 | 옆모습, 넓고 긴 몸통, 분리된 사지, 완만한 꼬리 | 등·측면 무늬의 차이를 비교하기 편함 | 작은 표시에서는 A보다 눈과 발가락이 작음 |
| C · 자연 자세형 | 대각선 자세, 긴 팔다리와 펼친 접착 발가락, 긴 꼬리 | 세 마리를 함께 볼 때 자세만으로도 구별하기 쉬움 | 기울어진 몸에 맞춰 모프별 패턴 방향을 별도로 설계해야 함 |

세 후보를 모두 노멀 기본·밝은 개체·어두운 개체·패턴 적음·패턴 많음으로 표시합니다. 여기서 ‘노멀’은 기본 갈색 팔레트의 디자인 작업명이며, 실제 게임의 모프 판정을 실행한 결과가 아닙니다. 최종 후보를 자동 선택하지 않았습니다.

이번 시각 검토에서는 **A는 얼굴의 호감도, B는 브리딩 무늬 감상, C는 자세와 발가락의 개성**을 비교하는 데 유용했습니다. 이를 아름다움이나 수집 욕구의 객관적인 순위로 간주하지 않습니다.

## 최종 96×96 픽셀

- 기존 PNG를 변형하지 않고 새로운 아트 초안을 제작했습니다. [새 원화 초안](source-sheet.png)은 제작 출처를 남기는 자료이며 런타임에서 사용하지 않습니다.
- 원화의 세 개체를 독립된 실루엣으로 분리하고, 최근접 샘플링으로 96×96 안에 배치했습니다. 반투명 경계와 배경 잔여색을 제거한 뒤 제한 팔레트, 1px 윤곽, 수직 동공·눈 반사광을 네이티브 픽셀에서 정리했습니다.
- 최종 노멀 PNG는 **각각 정확히 96×96, 불투명 색 21개, 알파 0 또는 255**입니다. 밝기 변형까지 포함하면 최대 33색입니다. 블러·부드러운 보간·오차 확산 디더링을 사용하지 않습니다.
- 실제 화면은 고해상도 원화를 줄여 표시하지 않습니다. **완성된 96×96 인덱스 픽셀 데이터**를 출력합니다. 원본 96px를 항상 표시하고 확대는 최근접 3배입니다.
- 48·72·96px 축소 비교도 동일 픽셀을 보간 없이 샘플링합니다. 기존 성장 단계나 성장 이미지 코드는 수정하지 않았습니다.

## 표현형 확장 검토 범위

각 베이스는 고정된 실루엣·눈·어두운 구조 픽셀, 재질 팔레트, 몸통 패턴 영역을 분리했습니다. 머리 범위·등 경로도 자세별 데이터로 보관합니다. 밝기 변경은 피부색 단계만 바꾸며, 패턴 적음/많음은 몸통 피복을 바꿉니다. 어느 변형에서도 눈과 실루엣은 달라지지 않습니다. 패턴 배치 시드는 풍부한 패턴의 위치만 바꾸고 베이스 자체를 다시 생성하지 않습니다.

패턴 적음의 최초 시도에서 밝은 무늬가 지나치게 어두운 점 잡음으로 바뀌는 문제가 보여 중간 피부색 범위로 치환하도록 수정했습니다. A/B/C 모두 추가 무늬를 얹을 공간과 축소 시의 한계를 실제 이미지에서 확인했습니다.

릴리화이트 얼굴 확장, 아잔틱 재질, 카푸치노 꼬리 표식, 하이웨이 등 확장, 세이블 대비는 **아직 이 새 베이스에 구현하지 않았습니다**. 후보를 고른 다음 부위 마스크·재질/명암 분리·모프 조합·유전 표현을 검토해야 합니다. 현재의 밝기/피복 변형을 해당 모프 구현으로 대신하지 않습니다.

## 코드와 데이터 보호

- `public/lab/base-study/*`: 새 기본 PNG 3개와 출처·해시 manifest.
- `src/lab/appearance/base-study/art-data.ts`: 생성된 96px 인덱스 픽셀.
- `designs.ts`: 새 비율·자세별 주석과 비교용 변형 정의.
- `render.ts`: 디자인 검토용 팔레트/패턴 변형. 유전체·저장·개체 기록을 만들지 않음.
- `reference.ts`: 기존 원화/현재 v2를 읽기만 하는 참고 연결.
- `src/app/lab/appearance/bases/*`: 별도 비교 경로 및 배치 모형.
- `scripts/compile-base-study.mjs`, `scripts/base-study-report.mjs`: 전용 네이티브 내보내기와 비교 시트.

정식 `src/engine`, `src/game`, `src/genetics`, `src/storage`, 기존 PNG는 변경하지 않았습니다. 비교 화면은 IndexedDB를 열거나 local/session storage에 쓰지 않습니다. 유전 상속, 브리딩, 가격, 상점, 성장, 저장을 연결하지 않았습니다. 픽셀 캐시는 최대 48개이며 배치/확대 변경은 기존 결과를 재사용합니다.

## 검증과 재현

전체 단위 테스트 **398개**, 관련 모바일/데스크톱 브라우저 테스트 **34개** 통과. 타입 검사·프로덕션 빌드·새 베이스 재생성·기존 원화 해시 검사도 통과했습니다. 새 기능은 단위 7개와 브라우저 8개를 포함합니다.

새 아트 전용 단위 검사는 실제 PNG와 런타임 일치, 출처 파일에서의 재생성 일치, 서로 다른 실루엣, 15개 변형의 이진 알파·팔레트·눈 보호·여백, 밝기/피복의 실제 변화, 12개 시드 재현성, 게임 결과/백업 불변성과 프로덕션 import 차단을 확인합니다.

브라우저에서는 Canvas가 Node 픽셀과 일치하고, 48/72px 축소에서 원본에 없는 보간색이 생기지 않는지 검사합니다. 모바일 360·390·430px의 다섯 배치, 인큐베이터의 정확한 48px 표시, 터치 가로 슬라이드, 저장 접근 없음도 확인합니다. 배치 캡처는 390px CSS 화면, DPR 1의 Chromium에서 저장했습니다. 실제 터치 검사는 모바일 Chromium 에뮬레이션이며 Android 물리 기기 테스트는 아닙니다.

```sh
node scripts/compile-base-study.mjs --check
node scripts/compile-gecko-art.mjs --check
node scripts/base-study-report.mjs
npm run typecheck
npm test
npm run build
npm run test:e2e -- e2e/base-study.spec.ts e2e/appearance-candidates.spec.ts e2e/appearance-prototype.spec.ts e2e/sprite-lab.spec.ts
```

픽셀/몸통 피복의 보조 기록은 [measurements.json](measurements.json)에 있습니다. 심미적 품질 점수나 게임 판정 기준은 아닙니다. 이번 결과는 후보 방향을 고르기 위한 실험물이며 정식 엔진 교체나 기존 PR의 병합을 포함하지 않습니다.
