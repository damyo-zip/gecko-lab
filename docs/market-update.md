# 국내 시세 조사·수동 업데이트

현재 `market/prices.json`은 **전 항목 임시 게임 가격**입니다. 2026-10-13 조사 시도는 환경 프록시에서 403으로 차단되었고, 확인한 국내 매물·실거래 표본은 0개입니다. `market/sources.json`의 실패 기록은 가격 근거가 아닙니다. 희귀도를 실제 시세로 포장하지 않습니다.

## 주 1회 또는 관리자 수동 실행

1. 최신 main의 가격표와 `sources.json`을 읽고 조사 날짜(한국 시간)를 기록합니다. Codex에 이 문서를 지정하고 **공개 국내 자료를 조사해 가격 변경 제안 PR을 준비**하도록 요청합니다.
2. 접근이 허용된 국내 분양 플랫폼·전문 브리더의 공개 자료를 우선 확인합니다. 약관·robots·로그인·네트워크 제한을 존중합니다. 차단되면 우회하지 않고 미확인으로 남깁니다. 이번 앱은 수집 봇이나 외부 API를 사용하지 않습니다.
3. 표본마다 URL, 관찰 날짜, 매물 ID/중복 키, 모프·유전형/보인자 정보, 성별·나이, 혈통 확인 여부, 희망가/거래 완료가/낙찰가 구분, 원화 금액, 신뢰도와 비고를 `sources.json.observations`에 기록합니다. 판매 완료 표시만 있고 거래금액이 없으면 실거래가로 계산하지 않습니다. 개인정보는 수집하지 않습니다.
4. 동일 매물이 여러 사이트에 올라온 경우 한 표본으로 처리합니다. 이상치는 제외 사유를 남기고 별도로 보존합니다. 모프별 유효 표본 수, 최저·최고, 중앙값, 분포, 미확인 항목을 정리합니다. 표본 부족·해외 자료·환산 가격은 추정으로 표시합니다. 자료가 없는 복합 모프 가격을 단순 합산하지 않습니다.
5. 가격표 변경 제안과 근거를 PR 본문에 정리합니다. 이전 가격표·출처를 `market/history/<이전버전>-prices.json`, `<이전버전>-sources.json`으로 보관합니다. `version`과 `effectiveDate`를 갱신합니다. 기준가·외형/성별/성장 보정과 게임 매입·매도 배율을 구분합니다.
6. `npm run typecheck`, `npm test`, `npm run build`, 모바일 E2E를 수행합니다. 즉시 재판매 손실, 기준가/평가액 구분, 과거 판매 이력 불변을 확인합니다. **사람이 근거와 변경 금액을 검토·승인한 다음 PR을 main에 반영**합니다. Codex는 조사만으로 검증 완료·승인을 주장하지 않습니다.
7. Next.js 표준 Vercel 배포로 JSON을 포함한 새 번들을 배포합니다. 앱이 새 가격표를 읽으면 현재 매물·향후 견적에 적용하며, 이미 저장된 판매 날짜·금액·기준가·시장 버전을 수정하지 않습니다. 서버·관리자 계정은 필요하지 않습니다.

## 현재 평가 모델

기준 모프 1개를 선택합니다. 발색·크림 면적·등/측면 무늬의 연속 수치를 보정한 뒤, 같은 계통 Ax 보인자·성체에 공개된 성별·성장 단계·게임 내 부모 기록을 곱셈으로 반영합니다. 혈통명은 반영하지 않습니다. 현재 복합 Ax+Lilly 기준가와 모든 보정 계수는 임시 게임 추정입니다. 희망가 기준표가 확보되어도 실제 거래가와 같다고 주장하지 않습니다.

평가액 × 1.15 = 상점 판매가, 평가액 × 0.60 = 플레이어 즉시 분양가입니다. 원화 천원 단위 반올림을 사용합니다. 이 차이는 게임 경제의 가정이며 실제 시장의 매입 수수료를 재현한 것이 아닙니다. 같은 날짜의 같은 상태로 매입·즉시 재판매하면 손해를 보지만, 향후 시장 업데이트로 평가액이 바뀌는 것은 허용합니다.
