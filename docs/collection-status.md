# 컬렉션 상태·남은 턴·바로가기

기존 카드 크기, 대표 개체, 2/3열 전환, 세로 스크롤, 더 보기와 공통 상·하단을 유지합니다. 상태 계산은 `collection-status.ts`의 읽기 전용 함수이며 저장용 상태나 카운터는 추가하지 않았습니다.

## 표시와 우선순위

| 조건 | 표시 / 근거 | 터치 동작 |
| --- | --- | --- |
| 성장 중 | `성장 중 · N턴`: 기존 `adultAfter`와 출생 턴/현재 턴의 차이. v1.2는 정확히 12턴 성체 | 일반 개체 선택 |
| 산란 전 | `산란 대기 · N턴`: 해당 암컷의 진행 중 교배 `nextLayTurn`. 기한이 남지 않은 이전 일정은 `번식 진행 중` | 일반 개체 선택 |
| 산란 후 회복 | `휴식기 · N턴`: 실제 완료된 교배 기록과 `nextBreedTurn − 현재 턴` | 일반 개체 선택 |
| 교배 기록과 연결되지 않은 대기 | `교배 대기 · N턴` | 일반 개체 선택 |
| 인큐베이터 2칸 부족 | `공간 확보 필요`: 기존 `freeSlots`로 보유 개체와 모든 예약을 반영 | 기존 사료 및 사육장 관리 팝업 |
| 개체의 교배 조건과 공통 공간 충족 | `브리딩 가능` | 기존 교배 팝업 |

기존 우선순위인 은퇴 → 성장 → 낮은 컨디션 경고를 보존하고, 산란 전 일정과 완료 후 휴식을 구분한 뒤 배란·공간·기록 한도를 확인합니다. 따라서 성장/휴식과 공간 부족이 겹치면 남은 성장/휴식이 먼저 보이며 완료 턴에 조건을 다시 계산합니다. 기존 낮은 하트 안내는 유지하고 교배 엔진의 규칙은 바꾸지 않았습니다.

v1.2의 실제 교배 판정은 `nextBreedTurn`을 사용하므로 오래된 `recoverUntil` 날짜만으로 휴식을 늘리지 않습니다. 이전 일일 규칙은 날짜 기준 회복도 반영합니다. 조회·새로고침은 시간을 진행시키지 않으며 턴이 저장된 뒤 현재 데이터로 표시를 갱신합니다.

## 기존 팝업과 연결

사육 공간은 기존 공용 수용량이므로 별도 개체 배정이 필요하지 않습니다. 기존 `expand` 행동으로 가격을 차감하고 수용량을 늘리며 관련 상태를 즉시 다시 계산합니다. 관리 팝업에 실제 보유 금액을 추가 표시하고 기존 자금 부족·최대 수용량 제한은 그대로 사용합니다.

교배 바로가기는 개체 ID로 수컷 또는 암컷 슬롯만 채우고 반대쪽 슬롯을 비웁니다. 팝업을 여는 동작은 저장이나 교배를 실행하지 않습니다. 상대를 선택한 이후의 `breedingCheck`, 유전 예측, 근친/유전 위험 확인, 슬롯 검사와 실제 교배 실행은 기존 컴포넌트와 엔진을 그대로 사용합니다. 닫으면 컬렉션으로 돌아가고 실제 교배 성공 후에는 기존 동작대로 인큐베이터를 엽니다.

개체 선택 버튼과 상태 버튼은 형제 관계의 네이티브 버튼입니다. 44px 높이의 상태 터치 영역, 이름·모프의 선택 영역, 더보기 영역과 상태 글자의 터치 우선순위를 분리합니다. 상태 클릭은 이벤트 전파를 막고 저장/충돌 중에는 비활성화합니다. 기존 버튼 안에 새 버튼을 중첩하지 않습니다.

## 주요 파일

- `src/components/hardcore/collection-status.ts`: 기존 데이터로 상태·남은 턴·바로가기 판정.
- `collection.tsx`: 카드/대표 정보 표시, 독립 상태 버튼.
- `hub.tsx`: 기존 자원 팝업 연결 및 성별별 ID 사전 선택.
- `resources.tsx`: 실제 보유 금액 표시. 가격·구매 행동은 기존 구현 사용.
- `src/app/collection-status.css`, `layout.tsx`: 카드 치수를 유지하는 터치 스타일.
- `public/sw.js`: 셸 캐시 `shell-18`, 저장 v9 그대로.
- `tests/collection-status.test.ts`, `e2e/collection-status.spec.ts`, `e2e/fixtures/collection-status.ts`: 실제 턴/산란·저장·터치 검증.

게임·유전·렌더링·저장 코드는 변경하지 않았으며 기존 목록 팝업과 다른 탭도 유지합니다.
