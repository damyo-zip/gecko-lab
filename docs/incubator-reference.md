## 실제 슬롯과 부화

- 슬롯 총수는 `현재 공간 − 보유 생존 개체 수`이며 알·교배 예약·빈 공간이 이를 나눠 사용합니다. 별도의 알 보관함이나 인큐베이터 구매 규칙을 만들지 않습니다.
- 교배 시작 시 2칸 예약, +2턴에 2알 자동 배치·1회 산란 종료, 산란 +4턴 부화 판정·암컷 휴식 4턴을 유지합니다. 산란 전 예약 카드는 사용할 수 없습니다.
- 빈 카드의 +는 부모 선택으로 연결합니다. 인큐베이터를 구매하거나 공간을 추가하지 않습니다. 실제 빈 슬롯이 2개 미만이면 기존 교배 검사에서 부족 수를 안내하고 실행을 차단합니다.
- 알마다 저장된 산란/판정 턴으로 남은 턴·일수(1턴=7일)·진행률을 계산합니다. 화면의 턴 버튼도 기존 저장 완료·사료 부족 확인 흐름을 사용합니다.
- 95%는 수정란 조건부 부화율입니다. `?`에서 무정란 5%와 전체 알 기준 90.25%를 함께 안내합니다. 부화 전 수정 여부·유전형·성별은 공개하지 않습니다.
- 판정된 알은 실제 슬롯에서 빠지고 부화 결과·번식 기록에 남습니다. 실패 알은 공간을 해제하고 자손을 만들지 않으며, 성공한 자손은 컬렉션에 등록됩니다.
- 큰 사육장의 실제 슬롯은 6개씩 페이지로 표시합니다. 전체 수·빈 공간·예약은 페이지 수와 무관하게 실제 상태를 표시합니다. 긴 부모 이름은 터치하면 전체 이름·세대·알 ID를 볼 수 있습니다.

## 그래픽과 원본과의 차이

UI 전체를 스크린샷 배경으로 붙이지 않습니다. `public/ui/incubator/scene.png`는 UI·알·숫자가 없는 별도 생성 환경 원화입니다. 배경·인큐베이터·유리·조명·흙을 표현하며, 카드에는 같은 환경 에셋의 유리 내부 영역을 CSS로 사용합니다. 알은 독립 48×56 Canvas에 계단형 실루엣·체적 명암·국소 반점을 그리고 스무딩을 끕니다. 고유 알 시드는 장식만 결정하며 유전 결과를 변경하지 않습니다. 로고·DNA·알·하단 아이콘은 기존 픽셀 SVG를 재사용합니다.

분리된 원본 인큐베이터/알 아트가 제공되지 않았으므로 장면과 알의 세부 픽셀은 원본과 완전히 동일하지 않습니다. 레퍼런스와 같은 배치·비율·색감·프레임·조명을 목표로 새 환경 원화와 코드로 구현한 알을 사용합니다.

비교 fixture는 기존 엔진에서 서로 다른 두 암컷을 교배해 만든 실제 저장입니다. 서로 다른 시점에 산란한 **4알 / 사용 가능 총 6칸**이므로 원본의 예시 3/6과 다릅니다. 남은 7일/21일, 자금·먹이·성공률도 실제 데이터입니다. 원본의 “인큐베이터 추가하기”는 구매와 혼동되지 않도록 “빈 슬롯 / 교배로 알 배치”로 표시합니다. 재화 박스 두 번째 값은 기존 게임의 먹이 재고이며 새 보석 재화를 만들지 않습니다. 최소 터치 크기와 가독성 때문에 작은 화면의 버튼·글자 크기를 소폭 보정합니다. 실제 기록·교배 도구는 주 화면 아래에서 접근할 수 있습니다.

## 검증

기존 159개 단위 검사를 유지하고 실제 슬롯 분할·예약 전환·독립 부화 진행·실패 공간 해제·복원·큰 공간 수에 대한 5개 검사를 추가했습니다. 기존 E2E를 유지하며 레퍼런스 배치, 360/390/430px, 픽셀 스무딩·시드 재현, 직접 턴 진행, 무정란·부화 실패, 긴 이름·페이지, 오프라인 장면/저장 복원을 추가합니다.

타입 검사·프로덕션 빌드·기존 PNG/runtime 아트 해시 검사가 통과했습니다. 단위 **164개**(기존 159개 + 신규 5개), 전체 모바일/데스크톱 E2E **98개**(6.5분, 각 49개)가 통과했습니다. 최종 607px 스타일 보정 후 다시 빌드하고 관련 E2E **12개**를 재검사해 통과했습니다. 캡처 전후 저장 데이터 일치, 가로 넘침 없음, CTA/고정 탭 겹침 없음을 확인했습니다. 브라우저 검사는 Chromium 에뮬레이션이며 물리적 iPhone/Safari 검사는 포함하지 않습니다.
