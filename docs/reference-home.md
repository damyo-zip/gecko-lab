# 레퍼런스 홈 / 컬렉션 구현

이 문서는 PR #5·#6의 홈 UI 구현 기록입니다. 현재 v1.2의 7일 턴·자동 급여·고정 성장·수명과 최신 검증은 [v1.2 기록](v1.2-lifecycle.md)을 확인하세요. 아래 수동 급여·이전 일정 설명과 이미지 숫자는 당시 버전 기준입니다.

직접 구현 기준은 [새 홈 레퍼런스](../references/gecko-home-exact.jpg)입니다. 이전의 분위기 중심 테마를 넘어, **좌측 설정 → 중앙 로고/부제 → 우측 자원 2행**, **좌측 게코 + 우측 정보**, **3열 카드**, **큰 교배 CTA**, **4개 홈 탭**이라는 실제 배치와 비율을 옮겼습니다. 홈 기본 화면은 컬렉션입니다.

Chromium의 모바일 터치 컨텍스트에서 **실제로 작동하는 화면**을 캡처했습니다. 실물 휴대폰 촬영은 아닙니다. 비교 이미지는 원본 JPEG를 720×1280으로 디코딩하고 같은 크기의 실제 화면 PNG를 그대로 나란히 배치합니다. 확대·색칠·UI 재합성 없이 외부 여백에 라벨만 추가합니다.

기존 화면 기준 커밋은 `0738499`입니다. 전후의 동일한 6개체 게임 상태를 SHA-256으로 검사합니다. 리뷰용 검증 데이터는 모카·치즈·그레이·도트·할리·트리, 자금 12,450원·먹이 38개·사육장 20칸입니다. 기존 수치형 외형 모델을 사용하는 유효한 v5 백업을 정상 설정 화면에서 복원한 것이며, **플레이어 초기 보상이나 실제 저장에 이 데이터를 넣지 않습니다.**

## 구현과 동작

| 레퍼런스 요소 | 실제 구현 |
| --- | --- |
| 상단 구조 | 좌측 기어 설정, 굵은 픽셀 로고와 양쪽 잎, 부제, 자금/먹이 2행과 상점 연결 `+` |
| 큰 개체 영역 | 정글·나뭇가지·상부 조명 배경, 실제 Canvas 게코, 이전/다음 순환, 세대와 등록번호 |
| 우측 정보 | 실제 이름/공개 성별, 모프·세대·96×96 논리 크기·성장·브리딩 상태, 하트 5개와 관리 `?` |
| 보유 개체 | 실제 보유 수/사육장 정원, 모프 필터, 기본/이름/세대/하트 정렬, 2/3열 전환 |
| 카드 | 우측 세대 배지, 큰 썸네일, 공개 성별, 이름/모프/상태, 녹색 선택 프레임, 더보기 |
| 큰 CTA | 초록색 프레임·발광·배경 재질, DNA/하트 장식. 후속 변경으로 ‘턴 넘기기’가 하루 진행·자동 저장을 실행 |
| 홈 탭 | 컬렉션 / 인큐베이터 / 혈통도 / 상점 |

카드 본문을 누르면 위의 개체가 선택됩니다. 카드의 더보기 또는 큰 정보 패널의 이름/연필을 누르면 기존 상세 창이 열려 이름 수정·개별 급여·분양·유전 정보·혈통을 그대로 이용할 수 있습니다.

하트 옆 `?`는 컨디션 관리 창을 엽니다. 전체 급여, 기존 성장 단계 필터, 사육장 예약 수, 실제 날짜·DAY와 관리 설명을 여기에서 확인합니다. 홈의 생존/회복/배란/공간 상태는 실제 게임 데이터를 사용하며, 조합의 유전·근친 위험은 기존 교배 검사에서 추가 차단합니다.

**컬렉션의 큰 버튼은 ‘턴 넘기기’입니다.** 누르면 다른 화면으로 이동하지 않고 기존 공통 일일 규칙으로 하루를 진행합니다. 저장 중·저장 충돌·한국 자정 모드에서는 비활성화됩니다. 성체 상세의 ‘부모로 선택’과 인큐베이터의 교배 탭으로 기존 브리딩 화면에 들어갈 수 있고, 해당 화면의 ‘턴 마치기’도 유지합니다. 교배·오늘·인큐베이터 등 나머지 화면의 기존 6탭 구조와 테마는 유지하여 전체 앱 리디자인을 하지 않습니다. 조회·정렬·선택·보기 전환은 게임 상태를 저장하거나 시간을 진행하지 않습니다.

이 문서의 레퍼런스 비교 이미지는 PR #5 시점의 캡처로 ‘교배하러 가기’를 표시합니다. 후속 버튼 변경은 프레임·여백·레이아웃을 유지하고 문구와 기능을 변경했습니다.

## 실제 데이터 / 원본과 다른 부분

- 게코는 기존 **렌더러 2.0.1 / 96×96 / 고정 시드**의 실제 출력입니다. 레퍼런스의 고품질 게코를 잘라 썸네일에 넣지 않았습니다. 기존 아트의 실루엣·포즈·무늬가 레퍼런스와 다르며 이번 UI 작업은 이를 바꾸지 않습니다.
- 배경은 레퍼런스의 정글·갈색 가지·따뜻한 상부 조명을 기준으로 만든 **개체/텍스트/패널 없는 별도 환경 자산**입니다. 원본 배경 픽셀과 완전히 같은 자산은 아닙니다. 로고와 픽셀 아이콘도 기능별 SVG로 제작했습니다.
- 이름·모프·세대·자원·하트·상태·등록번호는 실제 데이터를 표시합니다. 리뷰용 할리는 실제 혈통이 없는 1세대이며, 레퍼런스의 Gen 2를 가짜로 표시하지 않습니다. 전체 고유 ID와 공개 유전 정보는 상세에서 확인합니다.
- 기존 모델에는 성격 값이 없으므로 해당 행에 **성장 단계**를 표시합니다. 자원 두 번째 행은 현재 게임에 있는 **먹이**이며 새 보석 재화를 추가하지 않습니다.
- 이미지 상단의 시계·배터리·통신 상태는 휴대폰 OS 영역입니다. 웹 게임에 가짜 상태 표시를 넣지 않고 실제 안전 여백을 사용합니다.
- 화면 높이가 긴 390×844에서는 세로 비율을 가용 높이에 맞춥니다. 360px에서는 CTA와 탭의 가림을 피하는 소폭 조정이 있습니다. 개체가 6마리보다 많거나 2열로 바꾸면 세로 스크롤을 사용합니다. 긴 이름/모프는 생략 표시와 상세 정보로 대응하며 큰 금액은 한국어 단위로 축약합니다.

## 검증

- `node scripts/compile-gecko-art.mjs --check`: 아트 PNG/런타임 해시 일치.
- `npm run typecheck`, `npm run build`: 통과.
- `npm test`: 기존 단위 테스트 109개 통과.
- `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e`: 전체 70개 통과 (모바일 35 / 데스크톱 35). 추가 보완 후 홈 6개도 재실행해 통과했습니다.
- 신규 홈 테스트: 레퍼런스 배치, 기본 3열·2열 전환, 필터/정렬, CTA 첫 화면 노출, 390×844·360×800 가로 넘침, 안전 여백, 빈 상태, 긴 이름/15개체 페이지 확장, 새끼 성별 비공개, 이름 변경·급여·턴 진행·새로고침 데이터 복원.
- 기존 테스트의 유전·부화·성장·다세대·위험 교배·근친·저장 손상·오프라인 검증을 유지했습니다. 테스트의 화면 진입 경로와 버튼 위치만 새 홈 동선에 맞췄습니다.

보고서를 다시 만들려면 전체 브라우저 테스트 후 `node scripts/render-home-report.mjs`를 실행합니다. 이 개발용 보고서 스크립트는 Next.js가 설치한 Sharp로 레퍼런스 JPEG를 디코딩하며 앱에 이미지 API를 추가하지 않습니다.
