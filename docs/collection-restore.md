# 컬렉션 UI 선택적 복구

복구 기준은 이번 작업 시작 직전 커밋 **`90bb366ea623e24fcf31b1d90b53b4e49a876272`**입니다. 전체 커밋을 되돌리거나 브랜치를 초기화하지 않고 `cda72cc`와 비교해 컬렉션 화면에 해당하는 부분만 복구했습니다.

## 복구한 부분

- `src/components/hardcore/collection.tsx`: 기존 대표 개체/정보 패널, 카드 마크업, 기본 3열·2열 전환, 세로 탐색, 처음 12마리 표시 및 12마리씩 더 보기를 복구했습니다.
- `src/app/collection-browser.css`: 홈 높이 고정·6마리 슬라이드·작아진 카드/대표 정보 스타일을 제거했습니다. 기존 `reference-home.css`와 `reference-chrome.css`를 그대로 사용하며 이 파일에는 목록 팝업 스타일만 남겼습니다.
- `src/components/hardcore/collection-pages.tsx`: 복구된 홈에서 사용하지 않는 6마리 페이지 UI를 제거했습니다.
- `public/sw.js`: 오래된 화면 캐시를 갱신하도록 셸 버전만 `shell-17`로 올렸습니다. 저장 버전은 v9 그대로입니다.

## 유지한 기능

**컨디션 관리 → 전체 개체 목록 · 검색 / 분양가**에서 새 목록 기능을 계속 사용할 수 있습니다. 홈의 기본순 오른쪽 버튼은 기존 2/3열 전환으로 돌아갔습니다.

- `collection-catalog.tsx`와 `collection-query.ts`는 그대로 유지했습니다. 실제 스프라이트·이름·분양 예상가, 이름/ID 검색, 모프·표현형·성장 단계·공개 성별 필터, 가격 등 정렬, 24마리씩 추가하는 목록과 기존 상세/확인 후 분양이 작동합니다.
- 명칭·가격 계산, 숨은 정보 보호, 불변 개체 기반 캐시와 대표 개체 스프라이트 메모이제이션을 유지했습니다.
- 공통 헤더·턴 버튼·하단 탭, 허브, 인큐베이터·혈통도·상점의 소스와 스타일은 바꾸지 않았습니다.
- 게임·유전학·렌더러·저장 코드에는 변경이 없습니다. 기존 턴·교배·부화·경제·혈통·저장/복원 동작을 재사용합니다.

기존 E2E의 탐색 경로는 복구된 버튼과 관리 창에 맞춰 수정했습니다. 6마리 슬라이드 검사는 복구된 세로 탐색·2/3열·더 보기 검사로 바꾸었으며, 목록·실제 분양가·필터·분양·저장 불변성 검사는 유지했습니다.

## 검증

타입 검사·아트 해시·프로덕션 빌드 통과. 단위 19개 파일 / 232개 통과. 모바일/데스크톱 전체 E2E **140개 통과**, 실패·건너뜀 0개입니다. [최종 검증 기록](collection-restore/test-report.json).

모바일 검증은 Chromium 터치 에뮬레이션이며 실물 기기나 Safari 검사는 포함하지 않습니다. 복구/조회만으로 게임 저장이 바뀌지 않는지와 분양 후 금액·부모·유전 기록, 새로고침, 다른 탭과 공통 턴 처리를 검증합니다.
