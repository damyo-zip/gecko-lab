# v1.2 턴·성장·번식·수명 검증

정식 `/` 게임은 저장 v6 / 규칙 버전 4를 사용합니다. 렌더링·유전학·모프·표현형·가격 공식·기존 혈통 탐색 코드는 보존합니다. 공통 자손 생성 함수로 기존 멘델 유전·가상 외형 대립유전자 상속을 그대로 호출합니다.

## 일정과 재현성

- 버튼 1회 = 7일 / 턴 1 증가. 기기 시간·재접속·새로고침은 정지 상태를 유지합니다.
- 부화 후 정확히 12턴 성체. 6턴 아성체는 표시용 구분이며 성장 난수를 사용하지 않습니다.
- 생존 보유 개체 전부 턴당 사료 1개, 알·판매·폐사 개체 제외. 새로 부화한 개체는 다음 턴부터 소비합니다.
- 사료 부족 시 턴 이전에 필요량/재고/부족량을 표시하고 취소·상점·진행 확인을 제공합니다. 하트가 적은 순/ID 순으로 부분 급여합니다. 미급여는 하트 −1, 하트 0 영구 폐사입니다. 급여는 하트 최대 5까지 1 회복합니다.
- 수정 성공 순간 교배의 2자손 유전형·잠재 외형·성별·고유 외형 시드를 저장합니다. 산란·부화에서 유전을 다시 생성하지 않습니다.
- 교배 +2턴에 한 번만 2알을 산란하고 일정이 종료됩니다. 각 알 +4턴 판정·암컷 산란 +4턴 휴식입니다. 빈 슬롯 2칸을 먼저 예약하고 산란 시 알 2개로 자동 전환합니다. 부족한 슬롯 수를 표시하고 예약된 공간의 구매·중복 교배 사용을 차단합니다.
- 무정란은 알별 5%, 수정란 부화는 95%. 서로 다른 RNG 도메인과 알별 시드를 사용합니다. 유전 건강 위험은 기존 교배 전에 차단합니다.
- 노령 50, 은퇴 60, 자연사 65~69 1% / 70~74 3% / 75~79 8% / 80~84 18% / 85~89 40% / 90 이상 100%. 65 이전 자연사 0%.
- 자연사는 `게임 시드 + 개체 ID`, `natural-death:나이`로 재현합니다. `lastProcessedTurn`과 산란 카운터·알 상태·관찰 ID로 동일 턴 반복 처리를 막습니다.
- 턴 시작 급여/미급여 감소/자연사 → 산란/부화 → 성장 → 상점 갱신 순서입니다. 암컷 사망 시 미래 산란만 취소하고 기존 알과 모든 기록을 남깁니다.

## 이전 저장

기존 저장의 구조·체크섬·유전체 검증은 유지합니다. v2→v5 또는 v3/v4→v5의 기존 유전 이전을 거친 뒤 v6를 적용합니다. `active` 변경은 원본 아카이브와 함께 원자적으로 저장합니다. JSON 복원은 기존 활성 저장도 별도 아카이브에 남깁니다.

게임 턴·현재 날짜·ID·부모·유전형·잠재 형질·외형 시드·가격/판매/완료 이력은 재추첨하지 않습니다. 이미 성체인 개체는 최소 12턴 나이로 부화 턴을 보정하여 성체를 유지합니다. 기존 출생 날짜는 보존합니다. 진행 중인 이전 교배는 1회만 산란하고, 이전 대기 알은 기존 유전 결과와 수정 사실을 유지한 채 4턴/28일 판정 간격으로 정규화합니다. 이전 즉시 과거 턴이나 자연사를 실행하지 않습니다.

이전 v6/규칙 3 저장도 원본 검증 후 규칙 4로 한 번만 이전합니다. 산란 전이면 첫 2자손·예정일을 유지하며 예약을 2칸으로 줄입니다. 이미 산란했으면 추가 산란을 종료하고 기존 알·자손·확정 유전·관찰 기록은 모두 보존합니다. 마지막 실제 산란 +4턴 휴식으로 맞추되, 같은 암컷의 더 최근 교배 휴식은 이전 기록으로 덮어쓰지 않습니다. 원본 `archive-v6-…`과 새 활성 저장은 같은 트랜잭션에 기록합니다. 실제 구버전 코드에서 생성한 산란 전/1·2·3회 산란 저장 fixture로 검증합니다.

기존 v5 일일 엔진·현실 시간 어댑터는 회귀/호환용으로 보존합니다. v1.2에서는 수동 턴만 허용하며 UI의 한국 자정 선택은 비활성화됩니다. 이전 단위 테스트의 legacy fixture는 이전 코드와 검증 경로를 실제 실행하며 테스트를 생략하지 않습니다. v1.2 실제 앱 E2E는 자동 급여·새 일정으로 전환했습니다.

## 실행 결과

- 아트 PNG/runtime 해시: 일치.
- TypeScript 검사·프로덕션 빌드: 통과.
- 단위 테스트: **159개 통과**, 기존 109개 + v1.2 38개 + 단일 산란·예약·이전 12개. 성장/수명/은퇴 경계, 균등 사료, 중복 방지, 2000개 첫 산란 알 시뮬레이션, 이전 저장과 체크섬 재계산 손상, 5세대 혈통, 상점 해칭의 12턴 교배 가능 시점을 포함합니다.
- 모바일/데스크톱 E2E: **86개 통과 (5.8분)**. 모바일 43개·데스크톱 43개, 브라우저 오류/가로 넘침 없음. 이전 76개를 유지하고 단일 산란·2슬롯 경계·실제 v6 IndexedDB 이전 10개를 추가했습니다. 최종 기록 검증 한도·안내 문구 수정 후 다시 빌드하고 관련 12개(모바일 6개·데스크톱 6개)를 재검사하여 통과했습니다.

실제 브라우저 검사는 production build와 IndexedDB를 사용합니다. 모바일은 360×800 Chromium 터치 에뮬레이션이며 물리적 휴대폰·iOS Safari 검사를 의미하지 않습니다.

## 한계와 후속 작업

성장·노령 단계별 새 아트, 질병·치료·돌연사는 구현하지 않습니다. 모든 생존/확률/시간 수치는 게임 규칙입니다. 자연사한 개체의 기록은 컬렉션 보유 수에서 제외하고 혈통도·상세에서 사망 원인과 유전 자료를 확인합니다. 초기 4칸 사육장에서 부모 2마리를 보유하면 확장 없이 첫 교배를 시작할 수 있습니다. 알·보유 개체·교배 예약은 기존 공용 공간 계산을 사용합니다.
