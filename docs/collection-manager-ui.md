# 전체 개체 팝업: 접는 필터와 브리딩 목표

메인 컬렉션과 카드 크기·3열 배열은 유지한다. 전체 개체 팝업에서 X 바로 왼쪽의 44px 화살표 버튼이 검색·필터 영역 전체를 접거나 펼친다. 기본값은 접힘이다.

## 관리 화면

- 검색·모프·정렬·성장/성별 조건은 같은 상태와 검색 함수로 동작한다. 폼을 언마운트하지 않고 `hidden`으로 접으므로 검색어/조건/상세 조건 펼침 상태를 유지하면서 높이를 반환한다. 개체 수와 초기화는 폼 밖에 두어 항상 접근할 수 있다.
- 상단 선택 개체 정보/하트/관리 버튼 묶음은 제거했다. 카드 선택·강조·상태·이미지와 분양 예상가는 그대로다. 선택이나 관리 작업을 해도 팝업이 닫히지 않는다.
- 상세·분양·이름 변경·혈통 조회는 **각 카드의 더보기**, 교배/공간 확보는 **카드의 기존 상태 버튼**에서 이용한다. 사료·사육장과 턴 넘기기는 기존 하단 버튼을 유지한다. 이전 수동 급여 세이브의 급여 버튼도 유지한다.

## 브리딩 도전 현황

같은 위치에 가로형 버튼을 표시한다. 왼쪽에는 현재 목표 표현형·완료 수·진행/달성 상태·남은 잠금 턴, 오른쪽에는 기존 `ChallengePreview`가 렌더링한 목표 게코를 표시한다. 카드 선택은 이 값과 무관하다.

- 미선택: `진행 중인 브리딩 도전 없음`, 이미지 없이 목표 선택 안내.
- 진행: 실제 활성 목표의 표현형·대표 외형과 남은 잠금 턴. 10턴 경과 후에도 목표를 유지하고 변경 가능으로 표시한다.
- 달성: 실제 완료 기록과 즉시 풀린 잠금 상태를 표시한다. 기존 성공 알림을 닫으면 관리자에서도 즉시 반영된다.
- 버튼을 누르면 **혈통도와 같은 전체 목표 팝업**을 위에 연다. 같은 유전체 레시피·고정 시드·Canvas·목표 선택 액션·완료/잠금 규칙을 사용한다. 닫으면 선택/필터/스크롤을 유지한 관리자에 돌아온다. 새 임시 목표나 저장 개체를 만들지 않는다.

목표 목록은 `BreedingChallengeGoals`로 추출해 공유하며, 미리보기 캐시를 그대로 재사용한다. 게임/유전/도전/급여 엔진 및 저장 형식은 변경하지 않았다.

## 모바일과 성능

팝업은 헤더 / 검색 도구·수량 / 도전 현황 / 개체 목록 / 기존 하단 버튼의 5행 grid다. 개체 목록만 남은 높이를 받아 스크롤한다. 필터를 접으면 폼 높이가 사라지고, 기존 `ResizeObserver`가 목록 높이를 감지해 가상화 범위를 갱신한다. 헤더·도전·하단은 목록 스크롤과 함께 움직이지 않는다.

기존 카드의 3열과 고정 행 높이·위아래 여유 행을 유지하여 전체 개체 수만큼 Canvas를 마운트하지 않는다. 검색 조건 변경 시 목록 맨 위로 이동하는 기존 동작을 유지하며, 단순 접기/펼치기와 중첩 관리 창 사용으로 검색 조건을 초기화하지 않는다. 극도로 낮은 화면에서 폼이 들어가지 않을 때만 필터 폼 안에 필요한 스크롤을 허용하며 팝업 전체가 이중으로 스크롤되지는 않는다.

공통 `Dialog`에는 선택적인 `headerActions` 슬롯만 추가했다. 이를 전달하지 않는 다른 팝업의 헤더 구조와 동작은 같다.

## 검증

- 타입 검사·프로덕션 빌드 통과. 관련 단위 **25개**(컬렉션 상태 8 / 기존 도전 11 / 목표 외형 6) 통과.
- 모바일/PC Chromium **46개 시나리오 통과**: 전체 개체 16 / 도전·미리보기 12 / 실제 급여 면제 6 / 교배·위험 경고 8 / 공통 UI·턴 4. 처음 실행에서 기존 검사 2개가 '처음부터 필터가 보임'을 전제했으므로 실제 펼치기 동작으로 바꿨고, 최종 관련 6개를 다시 통과했다. 다른 기존 검사 44개는 앞선 실행에서 통과했다.
- 기본 접힘, X 왼쪽 44px 버튼, 폼 높이 반환으로 목록 높이 증가, 모든 검색/필터/정렬 값과 상세 펼침 상태 유지, 접힌 상태의 수량·초기화, 미선택 목표 안내/이미지 없음, 개체 선택과 독립된 목표, 중첩 목표 팝업 닫기·스크롤 유지, 1턴 남은 잠금 만료와 실제 해칭 성공 후 즉시 해제/다음 목표 선택을 검사했다.
- **360×640 / 360×800 / 390×844 / 430×932**에서 헤더·도전·하단 고정, 개체 목록만 스크롤, 가로 넘침/팝업 높이 초과 없음 확인. 360×640에서도 활성 목표 이미지와 성장/성별 필터까지 펼친 전체 폼이 들어가며 폼 자체 스크롤은 발생하지 않았다. 극도로 낮은 가로 화면은 이 검사에 포함하지 않았다.
- 기존 관리자 기능의 개체명 변경·분양·혈통 조회·교배·위험 확인·자원 구입·자동 급여/턴·복원도 유지했다. 제거된 상단 관리 버튼 대신 실제 카드의 더보기/상태 버튼으로 기존 검사를 계속 실행한다. 게임 엔진과 저장 형식의 변경은 없다.
- 300마리에서 모바일/PC 모두 시작·끝에 **카드 15개만 마운트**, 카드 선택 시 카드 Canvas 추가 그리기 **0회**. 활성 목표를 둔 37마리 검사에서도 선택 변경 시 목표 Canvas 추가 그리기 **0회**를 확인했다. 실제 관리자 목표 Canvas의 PNG 데이터는 혈통도에서 같은 목표를 표시한 Canvas와 동일하다. [300마리 측정값](collection-manager-ui/performance.json).

390×844 실제 브라우저 캡처: [기본 접힘·활성 목표](collection-manager-ui/goal-390.png) / [모든 필터 펼침·목표 미선택](collection-manager-ui/filters-390.png). 실제 스마트폰 하드웨어와 Safari 검사는 수행하지 않았다.
