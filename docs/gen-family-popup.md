# Gen 전용 가족 혈통도 팝업

컬렉션과 전체 개체 카드의 Gen은 **가족 혈통도** 제목·닫기 버튼, 기존 3세대 가족도, 기존 **후손 N마리**만 표시합니다. 개체 정보·브리딩 도전·세대 비교·저장 안내는 이 전용 보기에서 렌더링하지 않습니다.

`Lineage`의 기존 트리·후손 검색·추가 표시·실제 부모 연결·개체 선택기를 `view="family"`로 재사용합니다. 부모·조부모·후손을 누르면 중심 개체가 바뀌며, **다른 개체 보기**에서 실제 보존 개체를 선택할 수 있습니다. 후손이 없을 때와 검색 결과가 없을 때의 기존 문구도 유지합니다. 조회는 게임 액션을 실행하지 않습니다.

기본 `view="full"`인 혈통도 탭과 상세 정보의 전체 혈통 기록은 기존 구성 그대로입니다. Gen 전용 보기에서는 불필요한 관심 혈통 요약 계산과 추가 스프라이트 렌더링도 생략합니다.

팝업은 `height:fit-content`로 내용에 맞춰 높이를 결정하고, `92dvh` 및 상하 안전 여백으로 최대 높이를 제한합니다. 내용이 넘칠 때만 팝업 내부가 스크롤되며, 닫기 버튼은 상단에 유지됩니다. 기존 가족도의 좌우 스크롤과 픽셀아트 패널 스타일은 유지합니다.

## 변경 파일

- `src/components/hardcore/hub.tsx`: Gen 전용·전체 보기 구분과 제목, 기존 중심 개체 ID 전달.
- `src/components/hardcore/lineage.tsx`: 같은 가족·후손 UI의 전용 보기. 기본 전체 화면 구성은 보존.
- `src/app/collection-browser.css`: 전용 팝업의 내용 기준 높이·최대 높이·고정 헤더.
- `e2e/gen-family-popup.spec.ts`, `e2e/collection-age-gen.spec.ts`: 전용 보기와 기존 화면 회귀 검증.

## 검증

2026-10-16: 혈통 단위 **9개**, 관련 모바일/PC E2E **42개**, 타입 검사·프로덕션 빌드 통과. 높이를 보정한 뒤 팝업·Gen 관련 **12개**를 재검증했습니다.

- 실제 교배로 생성한 자손의 부모·조부모, 판매된 부모, 실제 후손 수·검색·후손 이동·다른 개체 선택·취소와 부모 기록 없음 확인.
- 360·390·430px, 640~932px 높이에서 가로 넘침·배경 스크롤·불필요한 빈 공간이 없으며, 400px 높이에서는 필요한 내부 스크롤과 닫기 버튼 접근 확인.
- 컬렉션 선택·전체 개체 팝업·스크롤·기존 관리 기능 유지. 조회 전후 저장 데이터 동일, 브라우저 오류 없음.
- 기존 프로덕션 빌드의 혈통도 탭과 새 기본 전체 보기의 개체 정보·가족도·세대 비교 **마크업과 좌표·크기가 정확히 일치**함을 360·390·430px에서 확인. [모바일 기준값](gen-family-popup/full-before-mobile-chromium.json), [PC 기준값](gen-family-popup/full-before-desktop-chromium.json).
- 기존 전체 혈통 기록, 세대 비교 선택, 판매·폐사 기록, 저장 이전, 오프라인 혈통도, 턴 진행, 300마리 관리 목록도 통과. 모바일은 Chromium Android 에뮬레이션이며 실기기 검증은 아닙니다.
