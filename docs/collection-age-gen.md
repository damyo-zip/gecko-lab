# 컬렉션 나이·Gen 혈통 바로가기

선택 개체의 기존 `크기: 96×96 (성체)` 행만 `나이`로 변경했습니다. 기존 가족 앨범의 `recordedAge`가 반환하는 실제 턴 나이를 사용합니다. 현재 규칙의 1턴=7일을 **연출용 30일=1개월, 12개월=1년**으로 환산하며, 1년 미만은 `2개월`, 1년 이상은 `1년 8개월` 형식입니다. 부화일을 과거 달력에서 보존한 이전 개체도 현재 성장 엔진과 같은 턴 나이를 표시합니다. 바로 아래 성장 행과 기존 6/12턴 성장·50턴 노령·60턴 은퇴·수명·가격·저장 형식은 변경하지 않습니다.

Gen 배지는 기존 카드 선택 버튼의 형제인 독립 버튼입니다. 개체 ID로 기존 Hub의 혈통 기록 팝업(`Lineage`)을 열며, 부모·조부모 이동·판매 기록 조회는 기존 컴포넌트 그대로입니다. 메인과 전체 개체 관리가 같은 카드를 사용합니다. 배지 외형은 유지하고 보이지 않는 터치 여유만 추가했습니다. 배지를 눌러도 카드 선택과 게임 액션은 실행하지 않으며 전체 개체 창의 선택·스크롤을 유지합니다.

## 변경 파일

- `src/components/hardcore/collection.tsx`, `collection-query.ts`: 상단 나이 표시와 기존 나이 데이터의 표시용 환산.
- `collection-card.tsx`, `collection-catalog.tsx`, `hub.tsx`: Gen에서 기존 혈통 팝업으로 ID 전달.
- `src/app/reference-home.css`, `collection-browser.css`: 기존 배지 스타일을 독립 버튼에서도 그대로 적용. 카드 공통 버튼의 전체 너비·패딩이 배지를 확대하지 않도록 원래 스타일의 선택자 우선순위만 보정.
- `tests/collection-age.test.ts`, `e2e/collection-age-gen.spec.ts`: 나이 표시·실제 가족·독립 터치·저장 불변성·화면 치수 회귀 검증.

## 검증

2026-10-16: 관련 단위 11개, 모바일/PC E2E 22개, TypeScript 검사와 프로덕션 빌드 통과. E2E는 이번 기능과 기존 이름 수정·분양·컬렉션 회귀를 함께 실행했습니다.

기존 a964ae5의 프로덕션 빌드에서 먼저 확보한 치수와 새 빌드를 비교했습니다. 360·390·430px × 844px에서 정보 패널·5개 정보 행·6개 카드·스프라이트·Gen의 좌표·크기가 정확히 일치하고, 배지의 글꼴·줄 높이·글자색·배경·테두리·패딩도 일치합니다. 원본 기준값은 [모바일](collection-age-gen/before-geometry-mobile-chromium.json), [PC](collection-age-gen/before-geometry-desktop-chromium.json)에 있습니다.

월·년 경계, 이전 출생일과 턴 나이의 차이, 턴 진행 후 월 표시 갱신, 성장 규칙·유전형 보존과 저장 재접속을 확인했습니다. 실제 교배로 생성한 3세대 자손의 Gen에서 정확한 부모·조부모 7노드와 판매된 아버지를 표시하고, 가족 탐색 뒤 컬렉션 선택과 전체 개체 창이 유지되는지 검증했습니다. 조회 전후 저장 데이터는 동일하며 브라우저 오류는 없습니다. 모바일은 Chromium Android 에뮬레이션이며 실기기 검증은 아닙니다.
